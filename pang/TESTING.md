## 자동 검증

`node --test --test-isolation=none pang/tests/*.test.cjs` — 15개 성공, 0개 실패.

검증 범위:

- 전체 10단계 초기 배치 및 30초 물리 진행 후 벽/바닥 경계 유지
- 대형 분열, 자식 반대 방향 이동, 벽 근처 생성 범위 보정
- 줄 몸통 충돌 및 한 줄당 한 버블만 처리
- 겹친 버블 피격 1회 처리와 무적 시간
- 더블 줄 한도, 붙는 줄의 천장 유지/소멸, 무기 만료
- 아이템 획득 및 8초 소멸
- 일시정지 중 물리/시간/무기 동결, 이어하기, 새로운 경기 초기화
- 제한시간 패배 및 큰 프레임 시간 제한
- 마지막 줄 명중의 성공 우선 처리와 마지막 생명 소진 패배
- 실제 발사/분열 규칙을 통한 10단계 연속 클리어, 1회 보너스, 독립 난이도 진행도
- 손상된 저장 필드의 기본값 및 범위 제한
- 실제 `game.js` 이벤트를 실행하는 DOM 경계 테스트: 10단계 다음 버튼과 완주 화면, 일시정지/포커스 이탈/탭 숨김, 입력 초기화, 재도전, 짧은 키 입력, 여러 포인터 취소, 저장소 예외

캠페인 자동 테스트는 조준 위치와 무적 시간을 테스트 fixture로 제어합니다. 사람의 회피 난이도나 실제 브라우저 UI 완료를 증명하는 테스트는 아닙니다.

## 브라우저 수동 검증

1. 실제 키보드 연속 발사로 1단계를 클리어하고 2단계 준비/시작 및 일시정지 화면으로 진행했다.
2. 360px 프레임에서 문서 폭과 스크롤 폭이 모두 360px이며 시작 버튼이 오버레이 안에 표시되는 것을 확인했다. 이동 버튼 72×64px, 발사 버튼 120×64px이다.
3. 360px 화면의 발사 버튼을 길게 눌러 버블 분열과 점수 350점을 확인하고 일시정지했다.
4. 새 페이지 로딩 후 1단계 최고 기록 2,330점과 2단계 해금이 복원되는 것을 확인했다.
5. 1280×720 데스크톱에서 전체 게임판과 시작 버튼이 화면 안에 들어오도록 배치를 조정하고 확인했다.
6. 홈의 실제 카드로 진입하고 홈으로 돌아오는 링크, SVG 아이콘과 미리보기, 하위 경로 `/sion-world/pang/`를 확인했다. 게임을 직접 조작한 브라우저 탭의 오류/경고 로그는 없었다.

전체 10단계의 UI 연결과 최종 화면은 자동 테스트로 검증했다. 사람이 모든 단계를 완주한 것은 아니며 실제 스마트폰의 두 손가락 동시 조작과 스피커 음량은 별도 하드웨어 검증 대상이다. 터치 취소·저장 차단 등 경계 조건은 실제 이벤트 핸들러를 호출하는 자동 테스트로 확인했다.

Web Audio와 localStorage는 실패를 방어하며 외부 의존성은 없습니다. 최신 Canvas 2D `roundRect` 지원 브라우저를 대상으로 합니다.
