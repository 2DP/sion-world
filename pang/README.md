# 버블 팡 · Bubble Pang

통통 튀는 버블을 별빛 줄로 나누고 모두 없애는 1인용 Canvas 게임입니다. 외부 패키지, 이미지, 폰트, 서버 API 없이 동작합니다.

## 실행

저장소 루트에서 `node bomberman/serve.cjs`를 실행하고 터미널에 표시된 주소의 `/pang/`을 엽니다. `pang/index.html`을 직접 열어도 플레이할 수 있습니다. 모든 자원과 홈 링크는 상대 경로입니다.

## 조작

- 이동: ← / → 또는 A / D
- 발사: Space 또는 J (누르고 있으면 반복 발사)
- 일시정지/이어하기: P 또는 Escape, 상단 버튼
- 터치: 좌우 버튼과 발사 버튼을 동시에 누를 수 있습니다.
- 창 포커스 이탈 또는 탭 숨김 시 자동 일시정지합니다.

10개 스테이지와 쉬움/일반 난이도를 제공합니다. 각 스테이지는 생명 3개로 시작합니다. 대형은 중형 둘로, 중형은 소형 둘로 분열합니다. 소형까지 제거하면 클리어합니다. 4번째 명중부터 4회마다 더블 줄과 붙는 줄 아이템이 번갈아 등장합니다. 더블 줄은 최대 두 줄, 붙는 줄은 천장에 2초 머무릅니다. 두 무기 모두 획득 후 10초 지속합니다.

단계별 최고 점수, 난이도별 해금 단계, 선택 난이도와 음소거 설정을 `sion-world-bubble-pang-v1`에 저장합니다. 저장소 사용이 차단되면 현재 세션에서 계속 플레이합니다. 진행 중 경기 자체는 저장하지 않습니다.

## 구성

- `engine.js`: DOM 없는 결정적 규칙, 브라우저 `PangEngine` 및 Node CommonJS 내보내기
- `game.js`: Canvas 렌더링, UI, 키보드/멀티터치, 오디오, 저장 연결
- `styles.css`: 반응형 화면, 포커스 표시, 움직임 감소 대응
- `assets/`: 직접 제작한 SVG 아이콘과 미리보기
- `tests/engine.test.cjs`, `tests/lifecycle.test.cjs`: 게임 규칙과 실제 UI 이벤트에 대한 Node 기본 테스트

물리는 최대 1/240초 단위로 계산하고 한 번의 갱신은 0.1초로 제한합니다. 쉬움은 기본 80% 속도, 1단계는 추가 85% 속도입니다. 시간은 쉬움 150초, 일반 110초입니다. 수치 및 스테이지 목록은 `engine.js`에 모여 있습니다. 음향은 사용자 입력 뒤 Web Audio로 합성합니다.

테스트: `node --test --test-isolation=none pang/tests/*.test.cjs`
