# 버블 팡 — 게임 기획서

작성일: 2026-10-18 · 프로젝트: SION WORLD · 구현 경로: `pang/`

## 1. 게임의 목표

통통 튀는 버블을 별빛 줄로 쪼개고 모두 없애는 1인용 아케이드 게임이다. Pang의 공 분열과 회피라는 핵심 재미를 참고하되, 캐릭터·이름·그래픽·음향·스테이지는 새로 만든다. 설치나 로그인 없이 링크를 누르면 즉시 시작할 수 있다.

- 제목: 버블 팡 / BUBBLE PANG
- 한 줄 소개: 통통 튀는 버블을 톡! 작은 별 사냥꾼과 열 번의 모험.
- 대상: 짧은 시간에 즐기는 가족용 웹게임, 처음 플레이하는 사용자.
- 목표 플레이 시간: 한 스테이지 30~90초, 전체 약 10~20분.
- 출시 범위: 1인 플레이, 10개 스테이지, 무기 3종, 난이도 2종, 최고 기록과 스테이지 해금 저장.

## 2. 플레이 흐름

홈 아이콘 → 게임 시작 화면 → 해금된 스테이지/난이도 선택 → 준비 안내 → 이동·발사·회피 → 모든 버블 제거 → 점수와 다음 단계 → 10단계 완료 화면.

시작 화면에서 조작법과 목표를 바로 보여준다. 각 단계는 독립된 도전으로 생명 3개로 시작하며, 실패하면 같은 단계 재도전 또는 선택 화면으로 돌아갈 수 있다. 다음 단계는 클리어해야 열린다. 마지막 단계에서 다시 도전하거나 SION WORLD로 돌아갈 수 있다.

## 3. 조작과 접근성

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 좌우 이동 | ←/→ 또는 A/D | 좌우 버튼 누르기 |
| 발사 | Space 또는 J 누르기/길게 누르기 | 발사 버튼 누르기/길게 누르기 |
| 일시정지/이어하기 | Escape 또는 P | 상단 일시정지 버튼 |
| 음소거 | 화면 소리 버튼 | 동일 |

이동과 발사를 동시에 입력할 수 있다. 버튼 밖에서 손을 떼거나 포인터가 취소되어도 입력이 남지 않도록 한다. 창이 포커스를 잃거나 탭이 숨겨지면 입력을 초기화하고 진행 중 게임을 일시정지한다. 게임 조작에만 스크롤 방지를 적용한다. 메뉴와 버튼에는 키보드 초점 표시와 한국어 접근성 이름을 제공한다.

게임판의 논리 좌표는 960×540이며 반응형으로 축소한다. 360px 폭 모바일에서도 가로 스크롤 없이 게임판·HUD·터치 버튼을 사용할 수 있어야 한다. 터치 버튼은 최소 48px 이상이며 실제 사용 영역은 64px 이상을 권장한다. 움직임 감소 설정에서는 화면 흔들림과 장식 입자를 줄인다.

## 4. 버블과 충돌 규칙

- 플레이어는 경기장 바닥에서 좌우로 이동한다. 점프는 없다.
- 버블 크기는 대·중·소 세 단계다. 대는 중 두 개로, 중은 소 두 개로 나뉘고 소는 사라진다.
- 버블은 중력에 따라 떨어지며 바닥과 좌우 벽에서 튕긴다. 크기가 클수록 높게 튀고 작은 버블은 낮고 빠르게 이동한다.
- 분열한 두 버블은 충돌 위치 근처에서 반대 방향으로 이동한다. 새 버블이 벽이나 바닥 밖에 생성되지 않도록 보정한다.
- 발사체는 플레이어 위치에서 위로 뻗는 수직 줄이다. 줄의 몸통과 끝 모두 버블과 충돌한다. 한 줄은 가장 먼저 맞힌 버블 하나만 처리하고 사라진다.
- 기본 동시 발사 한도는 1개이며 발사 간격을 둔다. 버튼을 누르고 있으면 가능한 시점에 반복 발사한다.
- 플레이어의 판정은 그림보다 조금 작게 잡는다. 피격하면 생명 1개를 잃고 약 2초간 무적이 된다. 겹친 여러 버블에 같은 순간 여러 번 피해를 받지 않는다.
- 피격 시 발사체와 가까운 위험을 정리하거나 버블을 밀어내어 즉시 다시 맞는 상황을 방지한다. 반짝임/실드로 무적 상태를 표시한다.
- 발사체의 명중을 먼저 처리한 뒤 남은 버블과 플레이어 충돌을 판정한다. 마지막 버블이 사라지면 성공, 생명이 0이거나 제한시간이 다하면 실패한다.
- 고정 시간 간격 또는 세분화한 갱신으로 빠른 버블의 벽·줄 관통을 막는다. 탭 복귀 후 누적 시간을 한꺼번에 진행하지 않는다.

## 5. 무기와 아이템

| 종류 | 효과 | 유지 |
| --- | --- | --- |
| 별빛 줄 | 기본 무기, 한 줄 발사 | 기본 상태 |
| 더블 줄 | 발사 한도 2개, 명중 기회를 늘림 | 10초 |
| 붙는 줄 | 천장에 도달한 줄이 약 2초 남음, 한도 1개 | 10초 |

특수 무기를 획득하면 현재 무기를 바꾸고 지속시간을 갱신한다. 만료 후에는 기본 무기로 돌아간다. 현재 무기와 남은 시간을 HUD에 표시한다. 아이템은 바닥으로 내려와 획득할 수 있고 8초 뒤 사라진다. 처음 특수 무기가 등장할 때 짧은 설명을 표시한다. 시작 직후 무조건 아이템이 쏟아지지 않도록 분열/제거 횟수 또는 고정된 조건에 따라 드롭한다. 테스트에서는 시드나 주입 가능한 난수로 재현할 수 있어야 한다.

## 6. 스테이지와 난이도

| 단계 | 이름 | 초기 버블 | 학습 포인트 |
| --- | --- | --- | --- |
| 1 | 솜사탕 첫걸음 | 중 1개 | 이동·발사·분열 익히기 |
| 2 | 둘이서 통통 | 중 2개 | 반대쪽 버블 확인 |
| 3 | 커다란 선물 | 대 1개 | 세 단계 분열 |
| 4 | 별빛 교차로 | 대 1개 + 소 2개 | 낮게 튀는 버블 회피 |
| 5 | 민트빛 오후 | 중 3개 | 더블 줄 활용 |
| 6 | 구름 위 소동 | 대 1개 + 중 2개 | 밀집 구간 탈출 |
| 7 | 무지개 파도 | 대 2개 | 발사 위치 선택 |
| 8 | 반짝이는 소나기 | 중 4개 + 소 2개 | 붙는 줄 활용 |
| 9 | 달빛 대행진 | 대 2개 + 중 1개 | 버블 수 관리 |
| 10 | 버블 페스티벌 | 대 3개 | 전체 규칙 종합 |

초기 버블은 플레이어와 떨어진 위쪽에 배치한다. 첫 단계는 충분히 느린 속도와 넉넉한 제한시간으로 시작한다. 일반 난이도는 기본 속도, 쉬움은 약 80% 속도와 더 긴 제한시간을 제공한다. 제한시간·중력·튕김 높이·속도는 실제 플레이 후 조정 가능한 데이터로 분리한다. 각 난이도에서 진행도와 기록을 별도로 저장한다.

## 7. 점수와 저장

- 명중 점수: 대 100점, 중 150점, 소 200점.
- 클리어 보너스: 남은 시간과 남은 생명에 비례. 결과 확정 시 한 번만 합산한다.
- 각 단계의 최고 점수, 최고 해금 단계, 난이도, 음소거 설정을 `sion-world-bubble-pang-v1`에 저장한다.
- 현재 플레이 중인 버블 위치와 타이머는 저장하지 않는다. 재접속 시 시작 화면으로 이동한다.
- 손상된 JSON·차단된 저장소·누락된 필드를 만나도 기본값으로 정상 플레이한다. 기록과 해금 수치는 유효 범위로 제한한다.

## 8. 화면과 시각 방향

크림색 배경, 하늘색·코랄·라벤더 버블, 둥근 윤곽선, 반짝이는 천체 장식을 사용한다. 작은 후드 캐릭터가 별빛 줄을 쏘는 독자적인 디자인으로 구성한다. SVG 아이콘과 미리보기, Canvas 게임 그래픽은 외부 이미지 없이 직접 제작한다.

- 상단: SION WORLD 돌아가기, 게임명, 소리, 일시정지.
- HUD: 단계/이름, 생명, 남은 시간, 점수, 무기 상태.
- 중앙: 게임판과 준비/일시정지/결과 오버레이.
- 하단 또는 옆: 짧은 조작법, 최고 기록, 모바일 터치 조작.
- 안내는 한국어 중심으로 작성한다. 장식적인 영어는 보조 표기로만 쓴다.
- 오디오: 사용자 입력 후 시작하는 Web Audio 효과음. 발사·분열·피격·클리어 소리를 구분하고 음소거를 제공한다.

## 9. 기술 구성과 연결

기존 저장소처럼 설치 없는 HTML/CSS/JavaScript로 구현한다. `index.html`, `styles.css`, `engine.js`, `game.js`, `assets/icon.svg`, `assets/preview.svg`, `README.md`, `TESTING.md`, `tests/*.test.cjs`를 둔다. 엔진은 DOM 없이 Node 테스트와 브라우저 양쪽에서 사용 가능한 형태로 분리한다. 외부 CDN·API·서버 저장은 사용하지 않는다.

홈 `index.html`에 미리보기·아이콘·소개·`./pang/` 링크를 추가한다. 게임의 홈 링크는 `../index.html`이며 GitHub Pages 하위 경로에서도 작동하도록 모든 경로를 상대경로로 작성한다. 기존 5개 게임은 그대로 유지하며 땅따먹기와 함께 총 7개로 갱신한다.

## 10. 완료 기준

1. 시작부터 10단계 완료까지 중단 없이 플레이할 수 있다.
2. 분열, 줄 명중, 벽·바닥 반사, 피격 무적, 특수 무기, 타임아웃, 재시작을 자동 테스트한다.
3. 일시정지 중 물리·타이머·무기 지속시간이 흐르지 않는다. 재도전 때 남은 입력·줄·아이템·타이머가 초기화된다.
4. 데스크톱과 모바일 화면에서 실제 시작·이동·발사·일시정지·재도전을 검증한다.
5. 홈 아이콘 및 게임 왕복 링크, 정적 자원 경로, 콘솔 오류를 점검한다.
6. 검증 결과와 실행 방법을 기록하고, 두 게임과 홈 변경을 함께 Git 커밋·원격 푸시한다.
