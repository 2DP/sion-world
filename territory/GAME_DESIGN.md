# 별빛 땅따먹기 — 게임 기획서

작성일: 2026-10-18 · 프로젝트: SION WORLD · 구현 경로: `territory/`

## 1. 게임의 목표

작은 별 탐험가가 안전한 영역에서 출발해 선을 긋고 돌아오면, 닫힌 공간이 파스텔 정원으로 바뀌는 1인용 영역 점령 게임이다. QIX의 선 긋기와 위험 회피를 참고하되 모든 화면·캐릭터·음향·스테이지는 새로 제작한다.

- 제목: 별빛 땅따먹기 / STAR GARDEN
- 한 줄 소개: 별빛으로 선을 잇고, 나만의 정원을 넓혀요.
- 대상: 간단한 조작으로 짧은 전략과 긴장감을 즐기는 사용자.
- 목표 플레이 시간: 한 단계 1~3분.
- 출시 범위: 6개 스테이지, 난이도 2종, 터치 조작, 단계 해금, 최고 기록, 완주 화면.

## 2. 플레이 흐름

홈 아이콘 → 목표와 조작법 → 난이도/해금 단계 선택 → 안전한 테두리에서 이동 → 그리기를 켜고 미점령 공간 진입 → 적을 피해 안전 영역으로 귀환 → 영역 점령 → 목표 비율 달성 → 다음 정원.

스테이지 시작 때 생명 3개를 제공한다. 실패하면 같은 단계 재도전 또는 선택 화면으로 돌아간다. 6단계를 모두 클리어하면 완주 결과와 다시 하기/홈 이동 버튼을 제공한다. 최초 단계는 느린 적과 낮은 점령 목표로 학습할 수 있게 한다.

## 3. 게임판과 영역 판정

- 논리 게임판: 48×32칸. 각 칸은 미점령/안전 영역으로 표현하고 현재 그리는 선은 별도 경로로 저장한다.
- 바깥 1칸 테두리는 시작부터 안전 영역이며 시작 위치는 위쪽 테두리 중앙이다.
- 점령률은 초기 테두리를 제외한 내부 칸 중 안전 영역이 된 칸의 비율이다. 처음에는 0%이며 목표를 HUD와 진행 막대에 표시한다.
- 플레이어는 상하좌우 한 칸씩 움직인다. 안전 영역에서는 자유롭게 움직일 수 있다.
- 그리기를 켠 상태에서 미점령 칸으로 들어가면 선을 남긴다. 선을 긋기 시작한 뒤에는 그리기 버튼을 놓아도 경로가 유지되며 안전 영역에 도달할 때까지 계속 그려야 한다.
- 그리기를 끄고 안전 영역에서 미점령 칸으로 이동하려 하면 경계에서 멈춘다.
- 진행 중인 자신의 선에 다시 닿으면 생명 1개를 잃는다. 시작 칸을 제외한 경로 되짚기도 같은 규칙이다. 방향 전환 시 즉시 역주행해 뜻하지 않게 피해를 보지 않도록 입력 처리와 안내를 명확하게 한다.
- 안전 영역에 다시 닿으면 선을 안전 영역으로 확정한다. 모든 내부 적이 있는 칸에서 동시에 flood fill을 실행하고, 적이 도달할 수 없는 미점령 칸을 점령한다.
- 여러 적이 서로 다른 공간에 남으면 그 공간들은 모두 미점령으로 남는다. 단순히 작은 쪽을 무조건 채우지 않는다.
- 닫힌 경로와 새 점령 면적을 한 번만 계산한다. 이미 점령한 칸을 중복 점수로 더하지 않는다.
- 점령 직후 적이 새 벽에 갇히거나 벽 속에 위치하지 않도록 이동/경로 충돌/영역 확정 순서를 일관되게 적용한다.
- 목표 비율 이상이면 바로 클리어하며 이후 이동·충돌·타이머는 멈춘다.

## 4. 위험과 생명

내부 적은 미점령 영역을 튕겨 다니는 작은 구름 생물이다. 안전 영역 안으로 들어오지 못하지만, 플레이어가 그리는 선 또는 미점령 영역에 있는 플레이어에 닿으면 피해를 준다. 적 이동은 이전 위치부터 새 위치까지 검사하거나 작은 단위로 나누어 빠른 이동이 선을 통과하지 않게 한다.

3단계부터 바깥 테두리만 따라 도는 반딧불 1개가 등장한다. 안전 영역에 머물러도 바깥 테두리에서 기다리는 것에는 위험이 생긴다. 반딧불은 점령으로 복잡해진 내부 경계를 추적하지 않고 바깥 사각형 테두리만 돈다. 내부 적과 외곽 적의 그림과 안내를 구분한다.

피격 시 다음을 순서대로 처리한다.

1. 생명을 1개만 줄인다.
2. 미완성 선을 지우고 이미 점령한 영역은 유지한다.
3. 마지막 출발 안전 칸 또는 검증한 안전한 시작 위치로 복귀한다.
4. 약 2초간 무적과 눈에 보이는 보호막을 제공한다. 같은 갱신에서 중복 피해를 주지 않는다.
5. 생명이 0이면 실패 화면으로 이동한다.

시간이 다해도 실패한다. 피격 무적·내부 적·외곽 적·제한시간은 일시정지 중 모두 멈춘다. 시간 경계에서 성공 조건을 만족한 캡처가 있으면 클리어를 우선해 결과를 한 번만 확정한다.

## 5. 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | 방향키 또는 WASD | 상하좌우 패드 |
| 그리기 준비 켜기/끄기 | Space | 그리기 버튼 |
| 일시정지/이어하기 | Escape 또는 P | 상단 일시정지 버튼 |
| 음소거 | 화면 소리 버튼 | 동일 |

그리기 버튼은 토글이다. 실제 선을 긋는 도중에는 끄기로 취소할 수 없으며 안전 영역으로 돌아와야 한다. 경로를 완성하거나 피해를 받으면 준비 상태를 끈다. 현재 상태를 `안전하게 이동`, `그리기 준비`, `선을 잇는 중`처럼 명확히 표시한다. Space 길게 누르기의 키 반복으로 여러 번 토글하지 않는다. 방향은 한 번에 하나만 적용하며 가장 최근 누른 방향을 우선한다.

초기 안내: “안전한 테두리에서 이동 → Space로 그리기 켜기 → 안쪽으로 들어가기 → 안전한 곳까지 선 잇기”. 색뿐 아니라 플레이어 모양·점선·패턴으로도 구분한다. 조작 버튼 포인터 해제/취소, 창 포커스 상실, 숨겨진 탭에 대한 입력 초기화와 자동 일시정지를 제공한다.

## 6. 스테이지와 난이도

| 단계 | 이름 | 점령 목표 | 내부 적 | 외곽 적 | 제한시간(보통) |
| --- | --- | ---: | ---: | ---: | ---: |
| 1 | 첫 번째 별밭 | 50% | 1 | 0 | 180초 |
| 2 | 민트빛 산책 | 55% | 2 | 0 | 180초 |
| 3 | 반딧불 손님 | 60% | 2 | 1 | 180초 |
| 4 | 라벤더 오솔길 | 65% | 2 | 1 | 165초 |
| 5 | 구름의 숨바꼭질 | 70% | 3 | 1 | 165초 |
| 6 | 나의 별빛 정원 | 75% | 3 | 1 | 180초 |

쉬움은 적 속도 약 75%, 제한시간 +45초로 시작한다. 보통에서도 플레이어의 세로 횡단이 첫 단계 적 회피를 배우기에 충분한 속도로 조정한다. 적의 초기 위치는 출발 위치와 떨어진 내부로 배치한다. 이동 속도와 단계 설정은 데이터로 분리한다. 실제 플레이 난이도를 확인하고 지나치게 오래 걸리거나 안전하게 성공할 방법이 없는 경우 조정한다.

## 7. 점수와 저장

- 새로 점령한 내부 칸 수에 비례해 점수를 준다.
- 클리어 보너스는 남은 시간과 생명에 비례한다. 결과 확정 후 반복 합산하지 않는다.
- 스테이지별 최고 점수·최고 점령률, 난이도별 최고 해금 단계, 음소거/마지막 난이도를 `sion-world-star-territory-v1`에 저장한다.
- 중도 이탈한 판의 영역은 저장하지 않는다. 기록은 확정된 결과를 기준으로 갱신한다.
- 저장 오류나 손상 데이터에도 시작 화면과 게임은 정상 작동한다. 기록과 해금 값은 검증·보정한다.

## 8. 화면과 시각 방향

크림색 페이지에 짙은 청록색 미점령 게임판을 배치하고, 점령한 영역은 민트·살구·라벤더 정원 무늬로 채운다. 미점령 영역과 안전 영역은 밝기와 패턴으로 구별한다. 플레이어는 별 모양, 내부 적은 보랏빛 구름, 외곽 적은 코랄 반딧불, 진행 중 경로는 밝은 점선이다.

- 상단: SION WORLD 돌아가기, 제목, 음소거, 일시정지.
- HUD: 점령률/목표, 단계, 남은 시간, 생명, 점수.
- 게임판: 선의 연결과 점령 순간을 짧은 반짝임으로 표현.
- 옆/아래: 조작 순서, 현재 그리기 상태, 단계 진행, 터치 패드.
- 시작·일시정지·실패·단계 클리어·완주 화면을 제공한다.
- 가로 360px에서도 가로 스크롤 없이 플레이한다. 터치 버튼은 누르기 쉽고 게임판 아래에 배치한다.
- 효과음은 Web Audio로 제작하고 사용자 입력 이후에만 활성화한다. 그리기 시작·점령·피격·클리어를 구분한다.
- 움직임 감소 환경에서는 장식 애니메이션을 줄인다. 알림은 필요할 때만 읽히도록 하고 매 프레임 화면 읽기를 유발하지 않는다.

## 9. 기술 구성과 홈 연결

기존 저장소와 같은 정적 HTML/CSS/JavaScript + Canvas로 구현한다. `index.html`, `styles.css`, `engine.js`, `game.js`, `assets/icon.svg`, `assets/preview.svg`, `README.md`, `TESTING.md`, `tests/*.test.cjs`를 둔다. 순수 게임 규칙과 브라우저 렌더링을 분리한다. 외부 CDN·로그인·서버 저장·온라인 멀티플레이는 범위에 없다.

홈 카드에는 정원 타일과 별빛 경로가 보이는 미리보기, 별 아이콘, 한국어 소개, `./territory/` 링크를 추가한다. 게임에서는 `../index.html`로 돌아간다. `/sion-world/` 같은 하위 경로에서도 자원과 링크가 정상 작동하도록 상대경로를 사용한다. 팡 카드와 함께 게임 개수를 7개로 갱신한다.

## 10. 완료 기준

1. 안전 영역 이동 → 그리기 시작 → 귀환 → 적이 없는 영역 점령 → 다음 단계 흐름이 실제 플레이에서 동작한다.
2. 여러 적이 각기 다른 구역에 있을 때 점령 판정, 자기 선 충돌, 적의 선 충돌, 무적, 피격 복귀, 타임아웃, 승리, 재도전을 자동 테스트한다.
3. 초기 테두리를 점령률에 포함하지 않고, 동일 영역에 중복 점수를 주지 않는다.
4. 그리기 토글과 방향 입력, 일시정지, 포커스 상실, 모바일 터치를 실제 브라우저에서 확인한다.
5. 홈 아이콘/미리보기와 왕복 링크, 하위 경로 정적 자원, 모바일 레이아웃 및 콘솔 오류를 점검한다.
6. 실행 방법과 검증 결과를 저장하고 두 게임 및 홈 변경을 함께 커밋·푸시한다.
