# 첨벙클럽

귀여운 사람 선수와 함께하는 성장형 리듬 수영 웹게임. 외부 패키지 설치 없이 실행합니다.

## 실행

`index.html`을 더블클릭하면 서버 없이 바로 실행됩니다. `style.css`와 `game.bundle.js`를 같은 폴더에 유지하세요.

웹서버로 실행할 수도 있습니다.

```sh
node server.mjs
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 같은 주소와 브라우저를 사용해야 저장을 이어갈 수 있습니다.

직접 연 파일(`file://`)과 웹서버(`http://`)의 저장 공간은 별개입니다. 직접 열기 방식의 저장은 브라우저 설정과 파일 위치에 따라 달라질 수 있습니다.

## 코드 수정 후

`core.js`, `character.js`, `app.js`를 수정했다면 `node build.mjs`로 실행용 `game.bundle.js`를 다시 생성하세요. 생성된 파일을 함께 배포합니다. `npm start`는 빌드 후 서버를 실행합니다.

## 플레이

- 새로 하기에서 이름과 수영복 색을 선택합니다. 기존 저장이 있으면 이어서 하기를 사용할 수 있습니다.
- 집: 저장, 수영모·수영복·물갈퀴·수영안경 구매·장착.
- 연습장: 혼자 25m 수영 후 경험치·코인 획득.
- 경기장: AI 4명과 50m 경기. 선수 레벨에 따라 패턴과 AI가 어려워집니다.
- Q 왼팔 / W 왼다리 / O 오른팔 / P 오른다리. 노트가 초록 선에 닿을 때 누릅니다.
- 콤보당 속도 +0.5%, 40콤보 이상 +20%. ESC로 일시정지합니다.
- 저장 슬롯은 localStorage의 `splash-club-save-v1`입니다. 경기 중에는 진행도를 저장하지 않습니다.

## 검증

```sh
node --test --test-isolation=none tests/*.test.mjs
```

현재 버전은 SVG/CSS 캐릭터와 수영장, 합성 박자음을 사용한 플레이 가능한 프로토타입입니다. 온라인 대전과 정식 배경 음악은 포함하지 않습니다. Google Fonts를 사용할 수 없는 환경에서는 시스템 글꼴로 표시됩니다.
