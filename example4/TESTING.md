## 브라우저 확인

Codex 내장 브라우저에서 실제 UI로 확인했습니다.

- 신규 저장 없이 시작 시 이어서 하기 비활성화.
- 새 선수 생성 → 마을 → 집 → 수영모 구매. 120 → 40코인, 장착 상태 표시.
- 새로고침 → 이어서 하기에서 코인·구매·장착·장소 복원.
- 25m 단독 연습 완주 → 25XP / 15코인 지급 및 새로고침 후 보존.
- 50m 경기에서 서로 다른 수영복 색의 사람 선수 5명 표시.
- 경기 일시정지와 재개 시 기록 유지.
- 대회 완주 → 순위표, 기록과 45XP / 25코인 지급 확인. 이는 무입력 5위 테스트 결과입니다.
- 새로 하기에서 기존 저장 덮어쓰기 안내, 취소 후 저장 보존.
- 좁은 화면과 PC 너비의 레이아웃 확인. 브라우저 실행 오류 로그 없음.
