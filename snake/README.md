# 냠냠 스네이크

SION WORLD의 고전 스네이크(지렁이) 게임. 외부 패키지나 빌드 없이 동작하는 HTML, CSS, Canvas JavaScript 게임입니다. 홈의 전용 아이콘·미리보기 카드에서 `./snake/`로 이동합니다.

## 실행

저장소 루트에서 `node bomberman/serve.cjs`를 실행하고 `http://127.0.0.1:8134/sion-world/snake/`를 여세요. GitHub Pages에서는 `/sion-world/snake/`로 접근합니다. `snake/index.html`을 직접 열어도 플레이할 수 있습니다.

## 조작과 규칙

- **시작 / 계속:** 화면 버튼 또는 Space
- **이동:** 방향키, WASD, 모바일 방향 버튼 또는 게임판 스와이프
- **일시정지:** Space, P, Escape 또는 상단 일시정지 버튼. 다른 창·탭으로 이동하면 자동 정지하며 직접 계속해야 합니다.
- **새 게임 준비:** 현재 라운드를 끝내고 모드·속도를 다시 선택합니다.
- **클래식:** 벽이나 자신의 몸에 닿으면 종료합니다.
- **산책:** 벽을 지나면 반대편으로 이어집니다. 몸에 닿으면 종료합니다.
- 사과 한 개당 **10점**, 몸 길이 **1칸** 증가. 사과 3개마다 조금씩 빨라집니다. 20×20칸을 모두 채우면 승리합니다.
- 이동은 화면 프레임마다 보간하여 부드럽게 표시합니다. 몸통·고개 회전·경계 통과를 함께 보간하며, 일시정지 시 현재 위치를 그대로 유지합니다. 충돌 판정은 격자 기준입니다.
- 최고 점수는 모드·속도 조합별로 `localStorage`에 저장됩니다. 저장소가 차단되어도 게임은 동작하며 해당 세션의 기록을 유지합니다.
- 소리는 기본 꺼짐이며 버튼으로 켤 수 있습니다. 외부 음원 없이 짧은 합성 효과음을 사용합니다.

## 검증

```sh
node --test snake/tests/*.test.cjs
```

`engine.js`는 DOM 없는 규칙과 이동 처리를, `game.js`는 입력·화면·사운드·저장을 담당합니다. 두 SVG는 직접 작성한 벡터 에셋입니다.
