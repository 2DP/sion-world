# 별빛 비트 검증 기록

검증일 2026년 10월 18일. 자동 테스트는 Node.js 24.19.0에서 실행했습니다.

## 자동 테스트

```powershell
node --test --test-isolation=none tests/*.test.cjs
```

25개 테스트가 통과했습니다.

- Perfect·Great·Good 판정의 양수·음수 경계와 범위 밖 입력.
- 한 노트의 중복 득점과 중복 Miss 방지.
- 입력 보정 −250·0·+250ms에서 성공 판정과 자동 Miss의 동일한 기준.
- 동시 노트의 입력 순서와 부분 실패, 서로 겹친 판정 구간의 콤보 순서.
- 만점, 전부 Miss, 기획서의 905,000점 예시, 정확도 등급 경계.
- 정수 가중치 누적으로 소수 오차에 의한 등급 하락 방지.
- 동일한 입력 시각에서 30·60·144fps로 갱신해도 동일한 결과.
- 본편 6개와 튜토리얼 채보의 유효 레인, 최소 간격, 동시 입력 수, 재현성 및 완주.
- 세 곡의 음악 이벤트 시간 범위와 멜로디·화음·베이스·드럼 구성.
- 음악 시작 전 카운트, 정지, 재개 카운트 중 시간 고정, 기존 재생 소스 정리.
- 기록과 설정 복원, 최고 기록과 달성 배지 보존, 손상되거나 차단된 저장소 처리.
- HTML의 로컬 자산과 JavaScript에서 참조하는 화면 요소 존재 여부.

JavaScript 구문 검사와 `node build.cjs`도 통과했습니다. 초기 실행 환경에서 테스트 파일별 자식 프로세스 생성이 제한되어, 격리 프로세스 없이 실행하는 Node 옵션을 사용했습니다.

## 브라우저 검증

로컬 HTTP 서버와 Codex 내장 브라우저에서 다음 흐름을 확인했습니다.

- 곡 선택과 난이도 변경, 각 난이도에 맞는 노트 수 표시.
- 튜토리얼 음악 준비, 네 박자 카운트, 12노트 완주 및 결과 화면.
- Esc 일시정지와 3초 카운트 후 같은 위치에서 재개.
- 별빛 산책 쉬움의 음악 준비부터 62노트 완주와 0점 결과.
- 구름 위 점프 보통에서 실제 키보드 입력과 패드 클릭에 따른 점수 증가.
- 구름 위 점프 보통의 170노트 결과에서 15,294점, Great 2개, Good 2개, Miss 166개, 최대 콤보 3 확인.
- 은하수 축제 보통의 음악 준비부터 227노트 완주와 결과 화면.
- 결과에서 곡 선택으로 돌아왔을 때 최고 점수 반영.
- 페이지를 새로고침한 뒤 구름 위 점프 보통 최고 점수 15,294점 복원.
- 입력 보정 +35ms 저장과 새로고침 후 복원, 기본 설정 복귀.
- 박자 맞춰보기와 Space 입력 시 빠름·늦음 피드백.
- 1120px PC와 360px 모바일 너비의 곡 선택 화면에 가로 넘침 없음.
- 360px 연주 화면의 네 레인 표시와 1120px로 크기 변경 시 자동 일시정지.
- 검증 중 브라우저 오류·경고 로그 없음.

## 추가 확인이 필요한 환경

실제 iPhone·iPad Safari와 Android 터치 기기에서의 오디오 지연, 두 손가락 동시 입력, 백그라운드 복귀는 별도로 확인해야 합니다. 내장 브라우저의 좁은 화면과 마우스 클릭 검증을 실제 모바일 기기 검증으로 간주하지 않습니다.

30·60·144fps 비교는 판정 엔진의 시뮬레이션입니다. 실제 기기별 프레임 성능과 청각적으로 느끼는 박자 정렬까지 측정한 결과는 아닙니다. 자동 테스트의 채보 완주는 모든 노트를 정확한 시각에 넣은 계산 검증이며, 사람이 여섯 난이도를 모두 연주한 난이도 평가를 대신하지 않습니다.

## 2026-10-18 댄스 편곡 업데이트

- 자동 테스트 26개 통과. 기존 여섯 채보의 노트와 시각이 이전 버전과 완전히 동일함을 비교했습니다.
- 세 곡 모두 실제 브라우저의 OfflineAudioContext로 전체 음원을 생성했습니다. 2채널, 비정상 샘플 0, 스테레오 차이 존재, 최대 진폭 0.88 이하를 확인했습니다.
- 별빛 산책: 80.80초, peak 0.7079, RMS 0.0511, 준비 5.44초.
- 구름 위 점프: 96.80초, peak 0.6956, RMS 0.0518, 준비 7.31초.
- 은하수 축제: 96.80초, peak 0.6918, RMS 0.0530, 준비 7.73초.
- 4마디 단위로 생성하고 잔향을 겹쳐 합산해 준비 시간을 줄였습니다. 준비 시간은 이 검증 기기에서의 측정이며 기기마다 달라집니다.
- 브라우저 오류와 경고 없음. tests/music.html에서 전체 음원 검사와 후렴 12초 미리 듣기를 재현할 수 있습니다.

## 새 곡 및 롱노트 업데이트

- 자동 테스트 37개 통과: 본편 10개 난이도와 튜토리얼 완주, 롱노트 종료·조기 해제·중복 판정 방지·보정·새 곡 기록 복원.
- tests/holds.html에서 실제 게임 DOM/입력 핸들러와 가상 음악 시계를 사용하여 키보드 완주, 조기 해제, 합성 터치 이벤트, 일시정지 후 재입력/미입력 5개 시나리오 통과. 합성 터치는 실제 모바일 기기 검증을 대신하지 않습니다.
- 실제 Web Audio로 다섯 곡 모두 렌더링 통과. 네온 드라이브: 90.80초, peak 0.6947, RMS 0.0516. 혜성 익스프레스: 90.40초, peak 0.6946, RMS 0.0528. 비정상 샘플 0, 스테레오 채널 정상.
- 기존 탭 전용 기록은 보존하며 새 롱노트 채보 기록은 -holds 접미사로 구분합니다.
