# 별빛 비트 리듬게임 기획서 초안

버전 v0.1 · 작성일 2026년 10월 18일 · 단계 기획

**별빛 비트**는 위에서 내려오는 음표를 음악에 맞춰 누르며 밤하늘의 별자리를 완성하는 4레인 리듬게임이다. 한 곡을 끝까지 즐기고, 같은 곡에 다시 도전하며 정확도와 콤보를 높이는 재미에 집중한다.

첫 버전은 PC 키보드와 모바일 터치를 지원하는 한국어 웹게임으로 만든다. 오리지널 연주곡 3개, 곡마다 쉬움과 보통 난이도, 튜토리얼, 결과 화면, 개인 기록을 제공한다. 게임명과 테마, 곡 구성 및 아래 수치는 구현을 시작하기 위한 제안이며, 판정과 패턴은 플레이 테스트로 조정한다.

## 게임의 목표와 분위기

리듬게임을 처음 접하는 사람도 조작을 바로 이해하고 첫 곡을 완주할 수 있어야 한다. 실수해도 음악이 끊기지 않고, 잘 맞추면 소리와 빛이 즉시 반응해야 한다. 반복 플레이에서는 이전보다 높은 정확도와 풀 콤보가 도전 목표가 된다.

배경은 작은 별들이 모이는 밤하늘 무대다. 안내 캐릭터인 별 요정 루미가 첫 조작을 알려주고, 곡을 끝내면 완성된 별자리 옆에서 축하한다. 긴 이야기나 육성 요소 없이 음악과 연주에 집중한다.

| 항목 | 첫 버전의 방향 |
| --- | --- |
| 장르 | 1인용 4레인 리듬 액션 |
| 실행 환경 | PC, 태블릿, 스마트폰의 웹브라우저 |
| 한 판 길이 | 음악 약 80~100초, 별도로 준비와 결과 화면 제공 |
| 조작 | 키보드 D F J K 또는 화면 하단의 레인별 터치 패드 |
| 핵심 목표 | 곡 완주, 정확도 향상, 최고 점수 갱신, 풀 콤보 |
| 미술 방향 | 남색 무대에 라벤더, 민트, 분홍, 노란색 포인트 |
| 음악 방향 | 멜로디와 박자가 분명한 밝은 오리지널 연주곡 |
| 저장 | 같은 브라우저에 개인 기록과 설정 저장 |
| 배포 형태 | 저장소의 독립 폴더에서 실행하는 정적 웹게임 |

## 한 판의 진행

1. **곡 선택:** 곡 이름, 분위기, 길이, 빠르기, 개인 최고 기록을 확인한다. 처음부터 모든 곡을 선택할 수 있다.
2. **난이도 선택:** 쉬움 또는 보통을 고르고, 필요하면 음량과 노트 속도를 조절한다.
3. **준비:** 시작 버튼을 누르면 음악을 준비한다. 처음에는 짧은 조작 연습을 제안하며 건너뛰기도 가능하다.
4. **연주:** 네 박자 카운트 후 시작한다. 노트가 판정선에 닿을 때 해당 레인을 누른다.
5. **완주:** 마지막 노트의 판정과 음악의 끝부분까지 처리하고 결과 화면으로 이동한다.
6. **결과와 재도전:** 점수, 등급, 정확도, 최대 콤보, 판정별 개수를 확인한다. 같은 곡 재시작과 곡 선택 버튼을 제공한다.

첫 진입 시 소리는 자동 재생하지 않는다. 사용자가 시작 버튼을 눌렀을 때 소리를 활성화하고, 준비가 완료된 뒤 카운트다운을 시작한다.

## 조작과 노트 규칙

### 네 개의 레인

| 왼쪽부터 | PC 입력 | 색과 보조 표식 |
| --- | --- | --- |
| 1번 레인 | D | 라벤더와 원 |
| 2번 레인 | F | 민트와 삼각형 |
| 3번 레인 | J | 분홍과 마름모 |
| 4번 레인 | K | 노랑과 별 |

PC에서는 두 손의 검지와 중지로 조작한다. 모바일에서는 각 레인 아래의 큰 패드를 누르며, 손가락 두 개의 동시 입력을 지원한다. 패드에 숫자와 표식을 함께 표시해 색상만으로 구분하지 않도록 한다.

- 첫 버전의 노트는 한 번 눌러 처리하는 **탭 노트**다.
- 키를 누르는 순간과 터치가 시작되는 순간을 판정한다. 키를 계속 누르고 있을 때 발생하는 자동 반복 입력은 무시한다.
- 한 번의 입력은 해당 레인에서 판정 범위 안에 있는 가장 이른 미처리 노트 한 개에만 적용한다.
- 판정 대상이 없는 입력은 패드만 반응하고 점수와 콤보를 바꾸지 않는다.
- 쉬움은 한 번에 한 노트만 사용한다. 보통은 최대 두 노트를 동시에 사용하되 왼쪽 두 레인 중 하나와 오른쪽 두 레인 중 하나를 짝짓는다.
- 모바일에서 손가락을 옆으로 끌어도 다른 레인이 자동 입력되지 않는다. 다시 누를 때 새 입력으로 처리한다.
- 키를 누른 채 화면을 벗어나거나 터치가 취소되면 입력 상태를 해제한다.

### 쉬움과 보통

쉬움은 주로 한 박자 단위의 노트와 충분한 쉼표로 구성한다. 보통은 반 박자 단위의 교차 입력과 두 레인 동시 입력을 추가한다. 음악의 속도는 난이도에 따라 달라지지 않으며 노트 배치만 달라진다.

같은 레인에는 최소 300ms 간격을 둔다. 모든 난이도에서 노트를 무작위 생성하지 않고 음악과 함께 설계한 고정 패턴을 사용한다. 같은 곡을 연습하면 다음 패턴을 익힐 수 있어야 한다.

## 판정과 점수

### 시간 판정

목표 시각과 보정된 입력 시각의 차이를 기준으로 판정한다. 아래 값은 첫 플레이 테스트의 출발값이다.

| 판정 | 시간 차이의 절댓값 | 정확도 가중치 | 콤보 처리 |
| --- | --- | --- | --- |
| Perfect | 50ms 이하 | 1.0 | 유지 및 증가 |
| Great | 50ms 초과, 100ms 이하 | 0.8 | 유지 및 증가 |
| Good | 100ms 초과, 140ms 이하 | 0.5 | 유지 및 증가 |
| Miss | 보정된 현재 시각이 목표 시각을 140ms 초과할 때까지 미처리 | 0 | 초기화 |

너무 이른 입력은 노트를 소비하지 않는다. 늦은 노트는 Miss로 한 번만 처리하고, 이후 입력으로 다시 득점할 수 없다. Perfect 이외의 성공 판정에는 선택적으로 ‘조금 빨라요’ 또는 ‘조금 늦어요’를 표시한다.

동시에 등장하는 두 노트의 점수는 각각 계산한다. 콤보는 그 시각의 노트 판정이 모두 끝났을 때 갱신한다. 모두 성공하면 노트 수만큼 더하고, 하나라도 Miss이면 0으로 만든다. 서로 다른 시각의 판정이 겹치면 콤보 갱신은 노트 목표 시각 순서로 확정한다. 따라서 입력 처리 순서에 따라 콤보가 달라지지 않는다.

### 점수와 등급

곡별 노트 수가 달라도 만점은 1,000,000점이다. 콤보는 도전 기록과 연출에 사용하며 점수 배수를 추가하지 않는다.

- 최종 정확도 = 판정 가중치의 합 ÷ 전체 노트 수 × 100.
- 최종 점수 = 판정 가중치의 합 ÷ 전체 노트 수 × 1,000,000을 반올림한 정수.
- 연주 중 점수도 전체 노트 수를 분모로 사용해 누적 표시한다. 연주 중 정확도는 판정이 끝난 노트만 기준으로 표시하며, 시작 전에는 대시로 표시한다.
- 예를 들어 노트 100개에서 Perfect 80개, Great 10개, Good 5개, Miss 5개라면 정확도는 90.5%, 점수는 905,000점이다.
- 등급은 반올림 전 최종 정확도로 결정하며 조건을 만족하는 가장 높은 등급을 적용한다. S는 97% 이상, A는 90% 이상, B는 80% 이상, C는 65% 이상, D는 65% 미만이다.
- 모든 노트를 성공하면 **풀 콤보**, 모든 노트를 Perfect로 처리하면 **올 퍼펙트**를 별도로 표시한다.

실수에 따른 중도 게임오버는 없다. 곡이 끝나면 누구나 완주 결과를 받으며, 직접 중단한 플레이는 기록에 저장하지 않는다.

## 첫 버전의 곡 구성

곡명과 구성은 제작 목표다. 세 곡 모두 멜로디, 화음, 베이스, 드럼을 갖춘 오리지널 연주곡으로 제작한다.

| 곡 이름 | 빠르기 | 목표 길이 | 분위기 | 쉬움 노트 수 | 보통 노트 수 |
| --- | --- | --- | --- | --- | --- |
| 별빛 산책 | 96 BPM | 약 80초 | 부드러운 벨과 가벼운 드럼 | 60~80 | 100~130 |
| 구름 위 점프 | 120 BPM | 약 96초 | 통통 튀는 신스와 선명한 베이스 | 90~110 | 150~190 |
| 은하수 축제 | 140 BPM | 약 96초 | 밝은 칩튠 멜로디와 풍성한 후렴 | 100~130 | 190~230 |

곡은 도입, 기본 구간, 변형 구간, 후렴, 마무리로 구성한다. 노트는 주로 들리는 멜로디와 드럼의 강조 지점에 배치하며, 후렴에서 더 풍부한 패턴을 제공한다. 첫 8박은 단순하게 시작하고 새 패턴 사이에는 짧은 휴식을 둔다.

음악과 채보는 같은 BPM, 박자 위치, 시작 오프셋을 사용한다. 채보는 각 노트의 레인과 목표 박자, 음악 시작 기준 시각을 가진 데이터다. 곡별로 쉬움과 보통 채보를 각각 검토한다.

튜토리얼은 본편과 별개인 약 20초의 연습이다. 메트로놈에 맞춰 레인별 단일 노트, 좌우 교대 입력을 익힌다. 일시정지 버튼을 안내하고 곡 선택으로 연결하며 튜토리얼 점수는 저장하지 않는다.

## 화면 구성과 연출

### 곡 선택 화면

상단에 게임명과 설정 버튼을 배치한다. 중앙에는 곡 카드 3개를 보여주고, 선택한 카드 아래에 난이도와 시작 버튼을 둔다. 최고 점수, 최고 정확도, 풀 콤보 달성 여부는 곡과 난이도별로 구분한다. 튜토리얼은 항상 다시 실행할 수 있다.

### 연주 화면

화면의 중심을 네 개의 레인이 차지한다. 상단에는 곡 이름, 진행 막대, 점수, 일시정지 버튼을 표시한다. 판정선 위에는 현재 판정과 콤보를 짧게 표시하고, 판정선 아래에 입력 패드를 고정한다.

PC에서는 무대 양쪽에 별자리와 루미를 배치한다. 모바일 세로 화면에서는 장식을 줄여 레인과 패드가 화면 너비를 충분히 사용하도록 한다. 터치 패드는 각각 최소 48 CSS px의 너비와 72 CSS px의 높이를 목표로 하며 기기 하단 안전 영역을 확보한다.

성공 시 해당 레인에 작은 별빛이 퍼진다. 25콤보 단위로 짧은 축하 효과를 보여주고, 음악의 진행률에 따라 배경의 별자리가 채워진다. 노트와 판정선 위에 큰 캐릭터나 불투명한 연출을 겹치지 않는다. 화면 전체의 강한 점멸은 사용하지 않는다.

### 결과 화면

곡과 난이도, 등급, 점수, 정확도, 최대 콤보, Perfect·Great·Good·Miss 개수를 표시한다. 이전 최고 점수와 차이, 새 기록, 풀 콤보, 올 퍼펙트를 각각 구분해 보여준다. 최대 콤보는 전체 노트 수와 함께 표시한다.

하단의 주요 행동은 ‘다시 하기’와 ‘곡 선택’이다. 결과를 닫지 않아도 다음 행동이 보이도록 배치한다. 미완주로 나간 경우에는 결과 등급 대신 곡 선택으로 돌아간다.

## 설정과 중단 처리

| 설정 | 초기값과 범위 | 효과 |
| --- | --- | --- |
| 음악 음량 | 70%, 0~100% | 배경 음악의 크기 |
| 효과음 음량 | 50%, 0~100% | 입력과 결과 효과음의 크기 |
| 노트 속도 | 보통, 느리게·보통·빠르게 | 판정선까지 보이는 시간 2.4초·1.8초·1.3초 |
| 입력 보정 | 0ms, −250~+250ms, 5ms 단위 | 기기와 청취 환경에 따른 입력 시간 보정 |
| 시각 보정 | 0ms, −250~+250ms, 5ms 단위 | 노트와 들리는 박자의 시각적 정렬 |
| 효과 줄이기 | 기기의 동작 줄이기 설정을 초기값에 반영 | 배경 움직임과 입자 효과 최소화 |

노트 속도는 시야에 보이는 시간만 바꾸며 음악, 판정 시각, 점수에는 영향을 주지 않는다. 보정 화면은 반복되는 박자음, 판정선, 연습 입력으로 구성한다. 입력 보정은 ‘계속 늦게 눌린 것으로 나올 때 +’, 시각 보정은 ‘노트가 소리보다 먼저 도착할 때 +’로 안내하고 초기화 버튼을 제공한다. 첫 버전은 수동 보정 방식이다.

Esc 또는 일시정지 버튼으로 멈춘다. 탭을 벗어나거나 화면이 숨겨질 때도 자동으로 멈추며 음악, 노트, 점수와 입력 상태를 함께 정지한다. 사용자가 재개를 선택하면 정지 화면에서 3초를 센 뒤 정확히 같은 곡 위치에서 이어진다. 카운트 중에는 노트를 판정하지 않는다.

일시정지 메뉴에서 재시작과 곡 선택을 제공한다. 재시작 시 이전 음악과 예약된 소리를 종료한 뒤 점수와 판정을 초기화한다. 플레이 중 화면 회전이나 큰 크기 변경이 발생하면 자동으로 멈추고 화면을 다시 배치한다.

## 구현 구조와 동기화 원칙

첫 구현은 HTML, CSS, JavaScript와 Canvas, Web Audio API를 사용한다. 별도 서버 계정이나 외부 음원 서비스 없이 정적 파일로 배포하며, 기존 게임과 독립된 `rhythm-game` 폴더에서 개발한다.

음악의 재생 시각을 게임 시간의 기준으로 삼는다. 화면 프레임을 세어 곡 시간을 늘리지 않고, 매번 기준 시각으로 노트 위치를 계산한다. 입력도 같은 시계로 환산해 판정하며 프레임이 늦어져도 음악과 노트의 관계가 누적해서 틀어지지 않게 한다.

- 판정 오차 ms = 입력 시점의 곡 시간 ms − 노트 목표 시각 ms − 입력 보정 ms.
- 자동 Miss도 현재 곡 시간에서 입력 보정을 뺀 시각으로 결정한다. 입력 보정이 양수일 때 실제로 누를 수 있는 구간이 끝나기 전에 노트를 Miss로 처리하지 않도록 한다.
- 시각 목표 시각 ms = 노트 목표 시각 ms + 시각 보정 ms. 시각 보정은 판정 계산에 다시 더하지 않는다.
- 일시정지는 곡 위치를 저장하고 재생 소스를 정지한다. 재개할 때 저장 위치부터 재생하고 같은 위치를 기준으로 곡 시계를 다시 설정한다.
- 선택한 곡의 음악만 준비해 재생 가능한 버퍼로 유지한다. 다른 곡을 선택할 때 이전 곡의 자원을 해제해 메모리 사용량을 제한한다.
- 음악 준비 중에는 진행 상태를 표시한다. 준비에 실패하면 재시도와 곡 선택으로 돌아가는 버튼을 제공한다.
- 한 노트는 대기, 성공, Miss 중 하나의 상태만 가지며 완료된 판정은 다시 처리하지 않는다.
- 게임 상태는 곡 선택, 음악 준비, 시작 카운트, 연주, 일시정지, 재개 카운트, 결과로 구분한다. 각 상태에서 허용되는 입력만 받는다.

곡마다 음악 길이와 마지막 노트 판정 종료 시각 중 더 늦은 시각까지 처리한 후 결과를 확정한다. 채보는 음악 범위, 유효 레인, 같은 레인 최소 간격, 동시 입력 제한을 사전 검증한다.

## 저장과 기록

저장 키는 이 게임 전용 이름으로 구분한다. 데이터에는 저장 형식 버전, 설정, 튜토리얼 완료 여부, 곡과 난이도별 최고 점수·최고 정확도·최대 콤보·풀 콤보·올 퍼펙트 달성 여부를 포함한다.

기록은 각 항목의 최고값을 독립적으로 보존하며 이전 달성을 낮은 결과로 덮어쓰지 않는다. 곡이 끝났을 때 한 번 저장하고, 설정은 변경 시 저장한다. 저장 공간을 사용할 수 없거나 데이터가 손상된 경우 기본값으로 게임을 실행하고 현재 실행 중의 기록은 유지한다. 영구 저장에 실패한 경우에만 짧게 안내한다.

첫 버전의 기록은 해당 기기와 브라우저에 남는다. 로그인, 기기 간 동기화, 온라인 순위표는 후속 범위다.

## 개발 순서와 완료 조건

| 단계 | 제작 내용 | 완료 조건 |
| --- | --- | --- |
| 1 기본 연주 | 임시 박자음, 4레인, 키보드와 터치, 시간 판정 | 같은 채보에서 정상 입력과 Miss가 각각 한 번만 처리됨 |
| 2 한 곡 완성 | 별빛 산책 음악, 쉬움 채보, 점수, 결과, 재도전 | 시작부터 결과와 재시작까지 한 흐름으로 플레이 가능 |
| 3 핵심 안정화 | 일시정지, 재개, 자동 중단, 보정, 기록 저장 | 중단과 반복 재시작으로 소리가 겹치거나 판정이 밀리지 않음 |
| 4 콘텐츠 제작 | 나머지 두 곡, 보통 채보, 튜토리얼 | 3곡과 6개 채보를 끝까지 플레이하며 난이도를 검토함 |
| 5 화면과 출시 준비 | 별자리 연출, 루미, 모바일 조정, 게임 목록 연결 | 지원 환경에서 주요 흐름 검증 후 실행 안내와 함께 배포 가능 |

단계별 완료를 기준으로 다음 범위를 확장한다. 음악과 판정이 맞는 한 곡을 먼저 완성한 뒤 곡 수와 장식을 늘린다.

### 기능 검증

- 50ms, 100ms, 140ms 경계의 양쪽 값과 정확한 경계에서 판정이 명세와 일치한다.
- 한 입력의 중복 득점, 미처리 노트의 중복 Miss, 키 자동 반복의 득점이 발생하지 않는다.
- 동시 노트의 입력 순서를 바꾸어도 최종 점수와 콤보가 같다.
- 전부 Perfect이면 1,000,000점이며, 예시인 80·10·5·5개 판정은 905,000점이다.
- 모두 놓쳐도 곡이 끝나고 0점 결과를 확인할 수 있다.
- 중간 위치에서 정지하고 재개해도 기존 판정은 유지되고 카운트다운 동안 추가 Miss가 생기지 않는다.
- 재시작, 곡 변경, 탭 전환, 화면 회전 이후 이전 소리나 눌림 상태가 남지 않는다.
- 새로고침 후 설정과 기록이 복원되고, 저장을 사용할 수 없는 환경에서도 완주할 수 있다.

### 플레이와 화면 검증

PC Chrome·Edge, iPhone·iPad Safari, Android Chrome을 검증 대상으로 삼는다. 개발자 도구의 화면 크기 변경에 더해 실제 터치 기기에서 동시 입력, 오디오 시작, 백그라운드 복귀를 확인한다.

가로 360 CSS px 화면에서 주요 버튼과 패드가 잘리지 않고 연주 중 페이지가 스크롤되지 않아야 한다. 목표는 60fps이며, 인위적으로 렌더링을 30fps로 낮춰도 같은 곡 시각에서 판정 결과와 노트 위치가 일치해야 한다. 최종 프레임 성능과 체감 지연은 테스트한 기기별로 기록한다.

각 채보를 최소 한 번씩 끝까지 연주해 음악과 패턴의 대응, 무리한 손 이동, 쉬움과 보통의 난이도 차이를 확인한다. 안내 문구가 노트 읽기를 방해하지 않고 효과를 줄여도 필요한 판정 정보가 남아 있어야 한다.

## 후속 확장

첫 버전 완성 후 길게 누르는 롱 노트, 어려움 난이도, 곡 추가, 키 변경, 구간 연습, 테마 보상을 순서대로 검토한다. 롱 노트는 시작과 유지 및 해제 판정을 별도로 설계한 뒤 추가한다.

사용자 음원 불러오기, 자동 채보 생성, 온라인 순위표와 대전은 별도의 확장 기획이 필요하다. 첫 버전의 완성 기준은 **세 곡을 안정적으로 연주하고, 결과를 저장하며, 다시 도전할 수 있는 것**이다.
