# 별빛 비트

음악에 맞춰 내려오는 음표를 누르는 한국어 4레인 리듬게임입니다. PC 키보드와 모바일 터치를 지원하며, 직접 합성하는 오리지널 연주곡 3개와 쉬움·보통 채보 6개를 제공합니다.

## 실행

`index.html`을 브라우저에서 열면 실행됩니다. 외부 라이브러리, 계정, 외부 음원 다운로드가 필요하지 않습니다. 처음 소리를 내기 위해 시작 버튼을 눌러 주세요.

로컬 HTTP 미리보기는 이 폴더에서 실행합니다.

```powershell
node serve.cjs
```

브라우저에서 `http://127.0.0.1:8137/`을 엽니다. 서버는 이 컴퓨터에서만 접근할 수 있으며 Ctrl+C로 종료합니다. 포트를 바꾸려면 `PORT` 환경 변수를 지정합니다.

정적 호스팅에서는 저장소의 `/rhythm-game/` 경로로 제공합니다. 저장소의 게임 놀이터에도 바로가기를 추가했습니다.

## 조작

- 왼쪽부터 **D F J K**를 누르거나 화면 하단의 패드를 터치합니다.
- 노트가 레인의 아래쪽 판정선에 닿을 때 한 번 누릅니다. 키를 누르고 있는 동안 자동으로 연주되지 않습니다.
- 보통 난이도에는 좌우 두 레인의 동시 입력이 등장합니다.
- **Esc** 또는 일시정지 버튼으로 멈춥니다. 재개하면 3초 카운트 후 같은 위치에서 이어집니다.
- 탭 전환, 창의 포커스 이탈, 큰 화면 크기 변경 시 자동으로 멈춥니다.
- 실수로 중도 탈락하지 않습니다. 곡이 끝나면 점수와 정확도, 판정별 개수, 최대 콤보가 나옵니다.

## 음악과 기록

| 곡 | BPM | 연주 길이 | 쉬움 | 보통 |
| --- | --- | --- | --- | --- |
| 별빛 산책 | 96 | 약 80초 | 62노트 | 107노트 |
| 구름 위 점프 | 120 | 약 96초 | 94노트 | 170노트 |
| 은하수 축제 | 140 | 약 96초 | 110노트 | 227노트 |

세 곡 모두 멜로디·화음·베이스·드럼을 함께 합성하며, 선택한 곡만 메모리에 준비합니다. 각 곡의 첫 한 마디는 박자를 듣는 도입부입니다. 루미의 튜토리얼은 약 20초, 12노트입니다.

배경음악은 댄스 편곡으로, 4박 킥·박수 소리·엇박 베이스·코드 스타브와 후렴 아르페지오를 사용합니다. 도입, 벌스, 빌드업, 후렴, 브레이크, 마지막 후렴으로 구성을 바꾸며 드럼 필인과 상승 효과음으로 구간을 연결합니다. 별빛 산책은 밝은 댄스팝, 구름 위 점프는 신스 리드, 은하수 축제는 칩튠 훅을 중심으로 연주합니다. 좌우 악기 배치와 박자에 맞춘 짧은 에코를 더하고, 렌더링 후 최대 진폭을 제한합니다.

Perfect는 ±50ms, Great는 ±100ms, Good은 ±140ms 이내입니다. 가중치는 각각 1, 0.8, 0.5이며 Miss는 0입니다. 노트 수로 정규화해 만점은 항상 1,000,000점입니다. S·A·B·C 등급은 각각 정확도 97·90·80·65% 이상이며 그 미만은 D입니다.

최고 점수, 최고 정확도, 최대 콤보, 풀 콤보와 올 퍼펙트 달성 여부를 곡과 난이도별로 보관합니다. 저장 키는 `sion-starbeat-v1`이며 다른 게임의 저장 데이터와 분리됩니다. 튜토리얼과 중단한 플레이는 곡 기록에 포함하지 않습니다. 저장 공간 사용이 차단되어도 현재 실행 중에는 플레이할 수 있습니다.

## 설정

음악·효과음 음량, 노트 속도, 입력·시각 보정, 효과 줄이기를 제공합니다. 노트 속도는 음악이나 판정을 바꾸지 않습니다.

‘박자 맞춰보기’를 켜고 들리는 박자에 맞춰 버튼이나 Space를 누릅니다. 계속 늦다고 나오면 입력 보정을 + 방향으로 조절합니다. 노트가 들리는 소리보다 먼저 판정선에 도착하면 시각 보정을 + 방향으로 조절합니다. 장치나 헤드폰을 바꿨을 때 다시 맞출 수 있습니다.

## 개발과 검증

Node.js 24 환경에서 별도 패키지 설치 없이 실행합니다.

```powershell
node --test --test-isolation=none tests/*.test.cjs
node --check game.js
node build.cjs
```

`build.cjs`는 배포에 필요한 파일만 `dist/`에 복사합니다. `tests/preview.html`은 로컬 서버에서 PC·모바일·태블릿 레이아웃을 확인하기 위한 페이지이며 배포에는 포함하지 않습니다.

- `engine.js`: 브라우저와 분리된 시간 판정·점수·콤보 계산.
- `charts.js`: 음악 구성과 고정 채보, 튜토리얼.
- `audio.js`: Web Audio 합성, 음악을 기준으로 한 시계와 재생 제어.
- `game.js`: 화면 전환, 입력, Canvas, 설정과 결과.
- `storage.js`: 저장 데이터 검증과 기록 보존.
- `lumi.svg`, `cover.svg`: 이 게임을 위해 제작한 벡터 아트.
- `GAME_DESIGN.md`: 게임 기획과 확장 범위.

검증 결과와 아직 확인하지 않은 환경은 `TESTING.md`에 기록합니다.
