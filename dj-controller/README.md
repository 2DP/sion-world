# MIXROOM DJ Studio

실제 PCM 음원을 조작하는 2덱 DJ 컨트롤러 웹게임입니다. 설치해야 하는 npm 의존성 없이 정적 파일로 실행합니다.

[GitHub Pages에서 바로 플레이](https://2dp.github.io/sion-world/dj-controller/)

이 게임은 `2DP/sion-world` 저장소의 기존 GitHub Pages로 배포합니다. 별도 Sites 배포는 사용하지 않습니다.

## 실행

```powershell
cd E:\workspace\sion-world\dj-controller
node serve.cjs
```

[로컬 스튜디오](http://127.0.0.1:8142/)를 열고 **스튜디오 입장**을 누릅니다. 기본 곡 두 개가 준비되며 자동으로 음악을 재생하지 않습니다. `file://`로 직접 열면 AudioWorklet이 작동하지 않으므로 HTTP localhost 또는 HTTPS를 사용합니다.

## 사용할 수 있는 기능

- 독립적인 A/B 덱, 재생과 Cue 미리 재생, 덱별 Hot Cue 8개, 전체 및 확대 파형 탐색
- 실제 원본 음원을 앞뒤로 읽는 스크래치, 조그 테두리의 피치 벤드, Vinyl 모드
- ±8/16/50% 템포, 박자 Sync, Shift+Sync로 BPM만 맞추기, 음높이를 유지하는 Key Lock
- Trim, HIGH/MID/LOW EQ, 양방향 필터, 채널 페이더, 두 가지 크로스페이더 곡선과 리버스
- 1/4~32박 루프, IN/OUT 수동 루프, 절반과 두 배, Reloop, Beat Jump 길이 선택
- Quantize, 샘플러 8슬롯의 원샷과 반복 및 개별 음량, Pad FX
- 채널별 FX와 마스터 FX, Echo/Delay/Reverb/Flanger, 박자 길이와 강도 조절
- 채널 Cue, 큐/마스터 비율, 헤드폰 음량, 단일 출력 전환과 Split Cue
- 마스터 녹음, 재생 미리보기, 지원 MIME 형식으로 다운로드
- 오리지널 16곡, 샘플 8개, 로컬 파일 가져오기, BPM 추정과 수동 그리드 보정
- 단계별 버튼 강조와 위치 찾기를 제공하는 DJ 아카데미 8단계, 클럽 미션 4개, 결과 및 개인 기록, 세션과 핫큐 저장, 키 매핑 변경
- Studio / Club / Battle 3종 컨트롤러 배치 선택과 선택 저장
- PC 컨트롤러 배치와 작은 화면에서 세로로 재배치되는 반응형 UI

음악은 브라우저 내부에서 처리하며 업로드하지 않습니다. 가져온 음원의 원본은 재접속 시 다시 선택합니다. 파일 해시를 기준으로 저장한 큐와 분석값을 연결합니다. 샘플러에서 Shift+패드를 누르면 재생 중인 샘플을 모두 정지합니다.

## 첫 믹싱

1. A의 재생을 누릅니다. 크로스페이더를 왼쪽으로 놓습니다.
2. B의 Sync를 누르고 원하는 첫 박에서 B를 재생합니다.
3. B의 LOW를 줄이고 크로스페이더를 중앙으로 옮겨 두 곡을 섞습니다.
4. LOW를 교대하고 크로스페이더를 오른쪽으로 이동합니다.
5. REC를 눌러 녹음을 시작하고 다시 눌러 파일을 저장합니다.

기본 키는 A Cue/Play가 Z/X, B Cue/Play가 N/M입니다. A 패드는 1234QWER, B 패드는 7890UIOP, 크로스페이더는 좌우 화살표입니다. 검색창과 설정 입력 중에는 연주 단축키를 처리하지 않습니다.

## 구현 범위와 제약

이 버전은 기획서의 2덱 플레이 버전을 중심으로 구현했습니다. 4덱, 스템 분리, 실제 MIDI 장치 연결, 별도 오디오 장치로의 헤드폰 출력, Slip과 Loop Roll은 후속 범위입니다. Hot Cue는 숫자 슬롯을 사용하며 이름과 색상 편집은 아직 없습니다.

Key Lock은 AudioWorklet 안의 상관 정렬 및 overlap-add 방식입니다. 일반 믹싱의 ±8%에서 사용하도록 권장하며, 상용 DJ 소프트웨어의 DSP와 같은 품질을 보장하지 않습니다. 테스트 음의 음높이 보존과 오디오 경로는 검증했지만 장치별 실제 출력 지연, 30분 연주 안정성, 모든 브라우저 조합의 청취 검증은 별도로 필요합니다.

클럽 미션은 검증된 제공곡을 사용합니다. 두 곡이 들리는 동안 비트 정렬을 평가하고, 프레이즈 진입·피크 및 무음·미션 동작을 합산합니다. B를 4마디 이상 출력하고 A를 내린 전환만 완료로 계산합니다. 원본 기획서의 세밀한 구간별 예외 처리는 향후 조정할 수 있으며 현재 점수는 연습용입니다.

녹음은 브라우저의 MediaRecorder 지원 형식(WebM/Opus 등)을 사용합니다. 녹음 시간은 최대 30분이며 이때 저장 창을 엽니다. 외부 폰트를 불러올 수 없으면 시스템 글꼴을 사용합니다.

## 검증과 빌드

```powershell
node --test --test-isolation=none tests/audio.test.js
node build.cjs
```

빌드 결과는 `dist/`입니다. 현재 저장소에서는 `index.html`의 게임 카드에서 `dj-controller/`로 직접 이동해도 됩니다.

`tests/audio.test.js`는 PCM 재생, 예약 명령, 루프 드리프트, 역방향 스크래치, Key Lock, 종료 처리, 크로스페이더, 동기화, 점수, 음원 파일을 검사합니다. `tests/integration.html`은 브라우저에서 버튼을 눌러 실제 Web Audio 그래프, EQ, 큐 격리, Sync, 녹음을 검사합니다. 통합 검사에서는 테스트 신호를 스피커에 출력하지 않습니다.

음원 생성 방법과 검증 메타데이터는 `tools/music-README.md`와 `tools/music-validation.json`에 있습니다. 전체 음악 파일은 약 80MiB이며 모두 외부 샘플 없이 합성했습니다.
