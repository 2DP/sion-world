# 아이돌 키우기

귀여운 다섯 친구와 연습생에서 월드스타까지 성장하는 한국어 웹 게임. 리더의 활동을 직접 고르고, 동료 네 명은 하루가 끝날 때 함께 자란다. 실제 결제와 서버 계정은 없다.

## 실행

**파일로 바로 실행:** 이 폴더의 `index.html`을 브라우저로 열면 된다. 저장소 맨 위의 `index.html`에서 아이돌 키우기를 골라도 된다. 제공된 `game.bundle.js`, CSS, `src`, `assets`를 함께 보관한다. 플레이할 때 서버나 Node.js, 패키지 설치가 필요하지 않다.

**서버로 실행:** Node.js가 있으면 다음 명령을 사용한다.

```powershell
cd E:\workspace\sion-world\idol-maker
node build.mjs
node server.mjs
```

브라우저에서 <http://127.0.0.1:4180/idol-maker/>를 연다. npm이 설치된 환경에서는 `npm start`로 묶음 파일 생성과 서버 실행을 함께 할 수 있다. 외부 패키지 설치는 필요 없다. 현재 서버는 이 PC에서만 접근 가능한 로컬 미리보기다.

다시 접속할 때 같은 브라우저와 같은 파일 위치 또는 서버 주소를 사용한다. 파일 실행과 서버 실행의 저장 공간은 별개이므로 기존 서버 저장이 파일 실행에서 자동으로 나타나지는 않는다. 파일 주소의 로컬 저장 지원은 브라우저에 따라 다르며, 저장이 허용되지 않으면 게임에 실패 안내가 표시된다.

## 플레이

1. 새로운 이야기 → 비어 있는 저장 칸 → 이름·외모·성격을 정한다.
2. 오늘 화면에서 장소와 활동을 고른다. 하루에 최대 7칸이며 모두 채울 필요는 없다.
3. 일반 활동은 버튼을 직접 세 번 누른다. 모든 활동에서 일반 활동과 미니게임 중 선택한다. 하루 7칸 모두 미니게임을 할 수 있으며, 진행 중에도 서로 전환할 수 있다.
4. 레벨 3, 노래와 춤 각각 15를 모으면 소속사에서 데뷔 오디션에 도전한다.
5. 성장 기록에서 다음 단계와 네 가지 경력 목표를 확인한다. 돈과 체력이 부족하면 무료 휴식 또는 오늘 마치기를 사용한다.

- 노래 리듬게임은 전용 120 BPM 음악에 맞춰 진행한다. 반짝이는 종소리와 음표의 중앙 도착이 같은 박자이며, 음악·음표·판정은 함께 일시정지하고 재개한다. 소리 크기는 설정의 배경 음악을 따른다.
- PC는 클릭, Tab·Enter로 조작한다. 리듬은 Space, 춤은 방향키, 카드 선택은 숫자키를 쓴다.
- iPad용 큰 터치 버튼과 가로·세로 반응형 화면이 있다. 실제 iPad Safari에서의 소리·터치·홈 화면 설치 검사는 아직 필요하다.
- 설정에서 음악·효과음, 쉬운 미니게임, 움직임 줄이기를 바꿀 수 있다. 소리는 첫 사용자 조작 뒤 시작한다.
- 월드스타 뒤에도 작품, 팬, 전문가 별과 해마다의 트로피를 쌓을 수 있다. 게임 오버는 없다.

## 구현한 콘텐츠

| 분야 | 내용 |
| --- | --- |
| 육성 | 다섯 능력, 레벨·에너지·그룹 스트레스, 성격 4개, 네 동료 자동 성장 |
| 활동 | 오디션, 연습·수업, 운동·미용·식사·휴식, 방송·인터뷰·광고·행사·스트리밍, 영화·음원·자작곡, 콘서트·3도시 투어 |
| 미니게임 | 리듬, 방향 춤, 안무 기억, 영화 장면 퍼즐, 제시어 퀴즈, 화장, 작곡, 멀리뛰기, 거품 세안, 도시락, 구름 휴식, 카드 짝 맞추기, 별 받기, 과일 쌓기, 해변 보물 찾기 |

| 꾸미기 | 기본 의상 3벌 + 상점 24벌, 신발 6종, 소품 6종, 머리 7종·앞머리·눈·눈썹·입·얼굴형·안경·주근깨·자유 색상·화장, 분야별 연습 장비 3등급 |
| 이야기 | 조건에 따라 발생하는 짧은 사건 13종, 선택 결과 표시, 성격별 대사, 팬 반응, 멤버 배경 이야기 |
| 기록 | 작품·관객·음원 재생·팬·팔로워, 일기, 첫 활동 기념 의상, 84일마다 연말 시상식 |
| 화면·소리 | 연습실·숙소·소속사·무대·촬영장, SVG 캐릭터·간단한 동작, 직접 합성하는 음악과 효과음 |

의상은 전신 의상·신발·소품을 조합하며 다섯 멤버가 리더의 의상을 함께 입는다. 피부·머리·눈 색은 색상 선택기로 자유롭게 정할 수 있다. 장비는 가장 높은 등급 하나가 자동 적용되며 3등급은 대형 소속사 오디션 합격 후 열린다. 연기 활동은 승인한 영화 중심 기획에 맞췄다.

## 저장과 오프라인

10개 슬롯은 각각 독립된 이야기다. 하루를 마치면 현재 슬롯에 정식 자동 저장하고, 상단 저장하기로 수동 저장한다. 확정된 활동·구매·꾸미기·선택은 중간 복구 기록에도 남는다. 활동 도중 다시 열면 같은 활동 시작 상태로 이어지며 비용이나 완료 보상을 중복 지급하지 않는다.

정식 저장과 더 최근의 복구 기록이 모두 있으면 불러올 시점을 고를 수 있다. 다른 창에서 같은 슬롯을 변경한 경우 충돌 안내와 다른 칸 저장 기능을 제공한다. 저장 실패나 손상된 기록은 성공으로 표시하지 않는다. 다른 기기와 자동 동기화하지 않으며 브라우저 데이터를 삭제하면 기록도 사라진다.

파일 실행은 게임 폴더의 자료를 바로 사용하며 manifest나 Service Worker를 요청하지 않는다. 서버 실행은 처음 게임 자료를 모두 준비한 뒤 같은 주소를 오프라인으로 열 수 있다. PC 로컬 미리보기에서는 서버를 끈 상태의 재시작·활동·저장·복원을 확인했다. iPad에서 설치해 사용하려면 정적 파일을 HTTPS 주소로 제공해야 한다. 현재 웹 배포는 하지 않았다.

## 개발과 검증

```powershell
node build.mjs
node --test --test-isolation=none tests/*.test.mjs
```

`src/*.js`를 수정한 뒤 `node build.mjs` 또는 `npm run build`로 `game.bundle.js`를 다시 만든다. 이 파일도 배포·복사에 포함한다. 테스트가 소스와 묶음 파일의 일치를 확인하므로 생성 누락을 찾을 수 있다. npm이 있으면 `npm test`도 사용할 수 있다.

[검증 기록](TESTING.md)에 자동 검사, 브라우저 검사, 남은 실기기 검증을 기록했다. 미니게임을 개별 확인하려면 실행 중인 서버에서 `/idol-maker/tests/minigames.html`을 연다. 이 검증 화면은 저장 슬롯을 읽거나 쓰지 않는다.

| 파일 | 역할 |
| --- | --- |
| `src/core.js`, `src/data.js` | 육성 규칙, 성장 조건, 경제, 사건과 콘텐츠 |
| `src/main.js`, `styles.css` | 게임 화면, 활동 진행, 상점·기록·설정 |
| `src/minigames.js`, `src/extra-minigames.js`, `src/minigames.css` | 미니게임, 입력·일시정지·완료 처리 |
| `src/storage.js` | 슬롯 저장, 복구, 버전 검사, 충돌 감지 |
| `src/character.js`, `src/audio.js` | 원본 SVG 그림과 Web Audio 합성음 |
| `sw.js`, `manifest.webmanifest` | 게임 범위의 오프라인 캐시와 앱 정보 |
| `build.mjs`, `game.bundle.js` | 소스 모듈을 일반 스크립트로 묶어 파일·서버 실행 지원 |
| `server.mjs` | PC 로컬 미리보기 서버 |

외부 CDN·폰트·이미지·음원·분석 서비스를 호출하지 않는다. 그림과 합성 멜로디는 이 게임을 위해 코드로 만들었다. 기존 게임 두 개는 유지하고 루트 게임 목록에 새 카드만 추가했다.

기획과 구현 계획은 [게임 기획서](GAME_DESIGN.md), [개발 계획](DEVELOPMENT_PLAN.md)을 참고한다. 성장 기간·글 읽기 속도·반복 활동의 재미는 실제 아이의 첫 체험 후 조정할 항목이다.
