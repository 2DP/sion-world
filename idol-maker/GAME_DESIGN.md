# 아이돌 키우기 게임 기획서

> 버전: v0.1 · 작성: 2026-10-03 · 상태: **사용자 검토 완료 · 구현 승인됨 · 로컬 체험판 구현**
> 확정된 사용자 요구와 이를 구현하기 위한 설계 제안을 함께 정리했다. 아래의 새 이름·수치·공식·해금 조건은 모두 초기 제안이며, 실제 플레이로 검증하지 않았다.
> 이 문서는 게임 규칙과 완성 목표를 다룬다. 개발 구조와 작업 순서는 [개발 계획](DEVELOPMENT_PLAN.md)에서 다룬다.

## 1. 한 페이지 요약

내가 만든 아이돌이 다섯 명 그룹의 리더가 되어, 오늘 할 일을 직접 고르며 연습생에서 월드스타까지 성장하는 한국어 1인용 육성 게임이다. 무대에 집중해도, 영화배우나 예능인 또는 싱어송라이터로 활약해도 그룹의 성장이 이어진다. 월드스타가 된 뒤에도 새 작품, 의상, 팬 반응과 기록을 계속 모은다.

| 항목 | 제안하는 플레이 경험 |
| --- | --- |
| 대상·기기 | 9세 어린이가 혼자 즐기는 iPad·PC 브라우저 게임 |
| 한 번의 플레이 | 약 15분에 게임 속 2~3일 진행. 언제든 저장하고 종료 |
| 하루 | 일정 7칸을 직접 선택하고 하나씩 실행. 남은 칸을 쓰지 않고 마쳐도 됨 |
| 직접 키우는 대상 | 이름·외모·성격을 정한 리더 1명. 동료 4명은 하루 끝에 자동 성장 |
| 주요 성장 | 노래·춤·연기·예능감·매력, 공통 레벨, 그룹 팬·인지도, 리더 SNS 팔로워 |
| 편안한 관리 | 매일 에너지 회복. 공통 스트레스는 휴식·놀이·먹기 등으로 쉽게 해소 |
| 활동과 조작 | 직접 선택한 훈련·일·휴식 + 가끔 등장하는 20~45초 미니게임 |
| 큰 목표 | 데뷔, 첫 콘서트, 흥행 영화, 연말 연기 대상, 많은 팔로워, 월드스타 |
| 분위기 | 라벤더·민트·크림·하늘색 중심의 귀엽고 밝은 세계, 간단한 애니메이션 |
| 진행·저장 | 접속 중 직접 실행한 행동만 진행. localStorage 독립 저장 슬롯 10개 |
| 결제·연결 | 현금 결제 없음. 필요한 파일을 처음 받은 뒤 실제 플레이는 오프라인 |

**검토가 필요한 핵심 선택**

1. 하루 7칸은 고정하고 에너지 상한을 60→100으로 올린다. 레벨 상승은 칸 추가 대신, 회복 없이 할 수 있는 고강도 활동을 늘린다.
2. 10개 슬롯은 독립된 육성 기록이다. 자동저장이 별도 슬롯을 차지하지 않으며, 현재 슬롯에 하루 한 번 저장한다.
3. ‘하루’는 게임 날짜다. 실제 자정이나 접속하지 않은 시간 때문에 일정·성장·연말 행사가 진행되지 않는다.
4. 연기 활동은 우선 영화만 제작한다. 활동 예시에 함께 제시된 드라마는 이번 설계에서 보류한다.
5. 첫 다운로드·오프라인 준비에는 연결이 필요할 수 있다. 준비가 끝난 뒤의 플레이·저장에는 연결을 요구하지 않는다.
6. 리더의 전문 분야가 그룹의 성장에 기여한다. 동료를 따로 훈련시키거나 모든 능력을 골고루 올리는 일은 필수가 아니다.

## 2. 게임의 기본 약속

- 육성 흐름은 프린세스 메이커에서 참고하되, 배경·캐릭터·의상·음악·화면은 새로 만든다.
- 일정 선택 → 활동 → 결과와 보상 → 성장 확인·휴식 → 다음 날을 반복한다.
- 실패는 다음 도전을 알려주는 짧은 결과다. 능력치 하락, 팬 이탈, 해고, 게임오버는 없다.
- 접속 보상이나 실제 시간 대기는 없다. 일주일 뒤 돌아와도 마지막 장면에서 이어진다.
- 연애·친밀도 수치는 두지 않는다. 멤버와의 대화는 이야기·그룹 활동·성장 안내에 사용한다.
- SNS, 영상 스트리밍, 음원 재생, 영화 관객, 팬은 모두 게임 속 수치다. 실제 서비스 계정은 연결하지 않는다.
- 자유 육성을 위해 추천 목표는 제시하되, 추천을 따르지 않아도 불이익을 주지 않는다.

## 3. 세계와 다섯 명의 멤버

### 3.1 배경과 리더 만들기

밝은 해안 도시 ‘소리별시’의 작은 ‘구름다락 기획사’에서 다섯 연습생이 만난다. 기본 그룹명은 ‘루미데이’이며 플레이어가 바꿀 수 있다. 데뷔 후 ‘오로라 엔터’ 오디션에 도전해 더 큰 무대와 작업실을 연다.

- 리더 이름과 그룹 이름은 각각 1~12자로 입력한다. 빈 이름은 기본 이름으로 안내한다.
- 리더 기본 이름은 ‘하루’. 피부색, 얼굴, 눈, 머리 모양·색을 직접 고른다.
- 시작 의상 3벌과 기본 헤어·색상은 무료다. 외모 선택은 능력치나 합격률에 영향을 주지 않는다.
- 생성 직후 5명이 함께 인사하고, 매니저 ‘다온’이 첫 무료 훈련과 쉬는 법을 안내한다.
- 보컬 트레이너 ‘보라’와 댄스 트레이너 ‘도윤’은 짧은 조언과 다음 도전 목표를 제공한다.

### 3.2 동료 구성

| 멤버 | 특기·외형 방향 | 짧은 배경과 역할 |
| --- | --- | --- |
| 나래 | 보컬, 민트 단발 | 동네 합창단 출신. 리더와 노래를 맞추며 음원 활동을 응원 |
| 루아 | 춤, 하늘색 포니테일 | 학교 댄스 모임 출신. 기억하기 쉬운 동작을 만들어 줌 |
| 소미 | 연기, 크림색 반묶음 | 작은 연극 무대를 좋아함. 촬영 대사를 함께 읽어 줌 |
| 유리 | 예능·진행, 라벤더 웨이브 | 친구들 앞에서 이야기하기를 좋아함. 인터뷰와 팬 소식 담당 |

- 동료의 일정은 조작하지 않는다. 리더가 하루를 마칠 때 한 번 성장하고 한 줄 소감을 말한다.
- 동료 레벨은 리더 레벨과 같다. 별도 경험치·장비·돈 관리 화면은 만들지 않는다.
- 동료의 기본 숙련도는 `리더의 가장 높은 능력치 × 0.9`를 반올림한 값이며, 최저 10이다.
- 특기 숙련도는 기본 숙련도보다 3 높되 리더의 가장 높은 능력치를 넘지 않는다. 하루 끝에 목표값까지 맞춘다.
- 따라서 동료가 리더의 최고 전문성을 앞지르거나, 뒤처져서 활동을 막는 일이 없다. 서로 다른 특기는 대사와 지원 연출에 반영한다.
- 그룹 활동 판정은 리더 능력을 기준으로 한다. 동료 능력치를 별도 합격 조건으로 요구하지 않는다.

### 3.3 리더 성격

처음 하나를 고르며 숙소에서 무료로 바꿀 수 있다. 변경은 다음 날부터 적용한다. 특정 경력·사건·의상을 성격으로 잠그지 않는다.

| 성격 | 작은 보너스 | 대사·사건 표현 |
| --- | --- | --- |
| 차근차근 | 훈련 완료 시 선택한 능력 경험치 +1 | 준비물을 확인하고 한 번 더 연습하는 제안 |
| 반짝반짝 | 공개 활동 완료 시 공통 경험치 +2 | 먼저 인사하고 적극적으로 도전하는 제안 |
| 다정다정 | 휴식 활동의 그룹 스트레스 감소량 +2 | 멤버의 이야기를 듣고 함께 쉬는 제안 |
| 호기심 가득 | 각 게임 날짜의 첫 창작·촬영 활동에서 능력 경험치 +2 | 새로운 표현을 시험해 보는 제안 |

성격 보너스는 결과 점수에 직접 더하지 않는다. 모든 성격에서 같은 활동과 선택지를 사용할 수 있다. 사건에는 작은 추가 결과도 적용한다. 예를 들어 ‘나래의 메모’에서 차근차근이 함께 읽으면 노래 경험치 +2, 다정다정이 함께 쉬면 스트레스 −2를 더하며 선택 전에 표시한다.

## 4. 하루 7칸과 게임 달력

### 4.1 하루의 진행

1. 아침에 날짜, 에너지, 그룹 기분, 새 소식과 오늘의 추천 목표 하나를 확인한다.
2. 7칸 일정표에 원하는 활동을 넣는다. 한꺼번에 채우거나 한 칸씩 고를 수 있다.
3. ‘이 활동 시작’을 누른 칸만 실행한다. 아직 시작하지 않은 칸은 비용 없이 교체한다.
4. 짧은 활동 장면 또는 미니게임 후, 바뀐 능력·돈·팬을 한 화면에서 확인한다.
5. 남은 칸에 훈련·일·휴식을 이어서 고른다. 실행 결과를 보고 계획을 바꿀 수 있다.
6. ‘오늘 마치기’를 누르면 하루 요약, 동료 성장, 정식 자동저장을 처리하고 다음 날로 간다.

- 활동은 기본적으로 1칸이다. 여러 회차가 필요한 작품도 회차마다 1칸씩 직접 실행한다.
- 에너지가 모자라면 해당 활동을 시작할 수 없다. 부족한 양과 무료 휴식 버튼을 함께 보여준다.
- 남은 칸을 채우지 않고 하루를 마칠 수 있다. 빈 칸은 보상 없이 지나가며 자동 훈련으로 바뀌지 않는다.
- 7칸을 모두 쓴 뒤에도 상점·꾸미기·기록·저장은 이용할 수 있다. 성장 활동은 다음 날에 가능하다.
- ‘오늘 마치기’는 돈·에너지·스트레스와 관계없이 무료로 사용할 수 있다.
- 다음 아침 에너지는 상한까지 회복하고 그룹 스트레스는 15 감소한다. 남은 에너지는 이월하지 않는다.
- 자동으로 다음 날을 실행하거나, 같은 훈련을 계속 반복하는 기능은 없다.

### 4.2 시간과 달력

- 간단한 게임 달력으로 1년은 12개월, 한 달은 7일로 한다. 시작은 1년 1월 1일이며 84일째가 연말이다. 현실 달력과 다르다고 안내한다.
- 날짜는 하루 마치기를 완료할 때만 1일 증가한다. 실제 날짜는 저장 시각 표시에만 사용한다.
- 연말 시상식은 84일째 하루 결산에 열린다. 15분에 2~3일 진행하면 약 28~42회 플레이 뒤 첫 연말을 맞는다. 놓친 현실 날짜를 소급 처리하지 않는다.
- 창 전환·화면 잠금 때 미니게임과 음악을 멈추며, 돌아오면 재개를 눌러 이어간다.
- 프로젝트 마감이나 행사 제안은 게임 날짜로 표시한다. 기본 제안은 기한이 없어 천천히 도전할 수 있다.

## 5. 능력치·레벨·자원

| 값 | 시작·범위 | 역할과 증가 방법 |
| --- | --- | --- |
| 노래·춤·연기·예능감·매력 | 각각 10, 0~100 | 활동 판정에 사용하는 다섯 능력. 해당 능력 경험치를 모아 상승 |
| 능력 경험치 | 능력별 0부터 | 다음 능력치 +1에 `20 + 현재 능력치 × 2` 필요. 남는 경험치 이월 |
| 공통 레벨·경험치 | Lv.1, 경험치 0 | 완료한 성장 활동에서 획득. 다음 레벨에 `100 + (레벨−1) × 20` 필요 |
| 에너지 | 60/60 | 오늘 행동에 쓰는 체력. 상한은 `60 + (레벨−1) × 2`, 최대 100 |
| 그룹 스트레스 | 0, 0~100 | 다섯 명이 공유하는 기분 부담. 활동으로 조금 증가하고 휴식으로 감소 |
| 돈 | 300코인, 최저 0 | 수업·의상·장비·제작비에 사용. 방송·영화·무대·영상 활동으로 획득 |
| 그룹 팬 | 0명, 누적 | 그룹의 성장 단계와 공연 규모를 여는 팬 수 |
| 리더 SNS 팔로워 | 0명, 누적 | 개인 활동의 인기를 보여 주는 별도 기록과 목표 |
| 그룹 인지도 | 0, 0~100 | 공개 활동으로 쌓이는 유명세. 비공개 훈련만으로 오르지 않음 |

- 공통 레벨 상승은 다섯 능력치를 자동으로 올리지 않는다. 어떤 능력을 키울지는 행동 선택에 달려 있다.
- 레벨업 때 에너지 상한 증가분만 현재 에너지에 더한다. 상한이 100이면 추가 회복은 없다.
- 에너지 20인 활동은 처음에는 회복 없이 3번, Lv.21부터는 5번 할 수 있다. 하루 7칸은 그대로다.
- 그룹 스트레스 0~59는 점수 영향 없음, 60~79는 −3점, 80~100은 −5점이다. 활동을 막지는 않는다.
- 스트레스 60부터 ‘함께 쉬면 더 즐거워요’ 안내를 한다. 공개 실패 자체에는 추가 스트레스를 주지 않는다.
- 인지도는 공개 활동의 기본 완료 +1, 결과 점수 85 이상이면 +2다. 같은 활동의 연출을 다시 보아도 증가하지 않는다.
- ‘개인 팬 수’는 별도로 만들지 않는다. 화면에는 항상 ‘그룹 팬’과 ‘내 SNS 팔로워’를 구분해 표시한다.
- 개인 영화·방송의 보상에도 그룹 팬 증가를 포함한다. 아래 활동표의 팬 보상이 이미 그룹 기여분이며 추가 환산하지 않는다.
- 현금 결제, 대출, 정기 유지비가 없다. 모든 성장 필수 조건은 무료 활동으로도 준비할 수 있다.

### 능력 상한 뒤에도 이어지는 성장

능력치 100 이후의 해당 경험치는 ‘전문가 기록’에 쌓이며, 1,000마다 별 배지 하나를 받는다. 배지는 기록·칭호·의상 색상 해금에 사용하고 판정 점수는 더 올리지 않는다. 레벨은 계속 오르지만 에너지 상한은 100이며, 팬·팔로워·작품·관객·공연 기록은 계속 누적한다.

## 6. 활동 목록과 초기 보상

아래 비용은 한 칸 기준이다. 능력 경험치와 공통 경험치는 서로 다른 보상이다. 금액의 ‘−’는 시작 비용, ‘+’는 완료 수입이다. 팬·팔로워는 범위 내에서 결과 점수가 높을수록 증가하며 임의 추첨하지 않는다.

### 6.1 언제든 선택하는 훈련과 회복

| 활동 | 해금 | 돈 / 에너지 | 능력 경험치 / 공통 경험치 | 기타 효과 |
| --- | --- | --- | --- | --- |
| 보컬·댄스 기본 연습 | 처음 | 0 / −8 | 선택 능력 +16~24 / +15 | 스트레스 +3 |

무료 기본 연습은 매번 플레이어가 직접 시작한다. 일반 연습은 5~8초의 짧은 상호작용이고, 등장 조건을 만족할 때만 미니게임으로 바뀐다. 같은 연습을 여러 번 골라도 별도의 자동 반복은 하지 않는다.

### 6.2 데뷔와 공개 활동

표의 팬·팔로워·수입은 데뷔 규모의 기본값이다. 활동 규모는 현재 도달한 단계 이하에서 고르며, 선택한 규모에 따라 데뷔 1배·인기 5배·톱스타 50배·월드스타 100배를 적용한다. 큰 배수는 무대 규모와 작품 노출 확대를 표현하는 조정값이다. 능력 경험치·공통 경험치·인지도에는 이 배수를 적용하지 않는다.

| 활동 | 해금·필요 준비 | 돈 / 에너지 | 능력 경험치 / 공통 경험치 | 기본 완료 보상 |
| --- | --- | --- | --- | --- |
| 데뷔 오디션 | Lv.3, 노래·춤 각각 15 | 0 / −20 | 노래·춤 각 +8 / +30 | 합격 1회만 팬 +100, 데뷔 의상·공개 활동 |

- 공개 활동의 스트레스는 방송·영상·광고 +4, 행사·영화 +5, 오디션·콘서트 +6, 음원·작곡 회차 +3이다.
- 콘서트의 제작비·수입·팬·팔로워는 선택한 활동 규모 배수를 적용한다. 시작 전에 총비용과 예상 범위를 확인한다.
- 영화 캐스팅은 독립된 1칸 활동이다. 돈 0, 에너지 10, 연기 경험치 +10·공통 경험치 +15이며 팬·수입은 없다.
- 영화 완료 기본 보상은 돈 +300~700, 팬 +150~350, 팔로워 +100~250, 관객 +5천~2만 명이다.
- 음원 완료 기본 보상은 돈 +120~250, 팬 +100~200, 팔로워 +50~120, 재생 +1천~5천 회다. 자작곡은 이 값의 1.5배다.
- 영화 관객과 음원 재생에는 선택 규모별로 데뷔 1배·인기 5배·톱스타 20배·월드스타 50배만 적용한다. 팬·수입의 배수를 추가로 곱하지 않는다.
- 선택 규모와 배수는 활동·프로젝트 시작 시 고정한다. 진행 도중 승급하거나 저장을 다시 불러도 바뀌지 않는다.
- 영화·음원·자작곡은 종류별로 1개씩 진행 중일 수 있다. 중간에 쉬거나 다른 일을 해도 회차를 잃지 않는다.
- 프로젝트의 최종 점수는 완료한 회차 점수의 평균이다. 관객·재생·수입은 마지막 회차에서 한 번 확정하고, 이후 날짜 경과만으로 늘지 않는다.
- 영화·음원·자작곡의 인지도와 공개 활동 횟수도 작품 발표 때 한 번만 증가한다. 회차별 능력·공통 경험치는 각 회차 완료 때 받는다.
- 새 작품에는 별도 이름과 기록 번호를 부여한다. 이전 작품을 다시 보는 기능에서는 보상이 나오지 않는다.

### 6.3 상점과 외형 반영

- 의상은 시작 3벌 외에 24벌을 목표로 한다. 상의·하의 또는 원피스, 신발, 소품으로 조합하며 가격은 부위당 80~300코인이다.
- 구매 전에 내 캐릭터에게 미리 입혀 본다. 구매와 착용은 구분하며 이미 산 물건은 다시 구매하지 않는다.
- 선택한 머리·화장·의상은 숙소, 연습, 무대, 촬영, 대화 초상화에 반영한다. 가능한 모든 기본 동작에 같은 외형을 유지한다.
- 의상은 취향과 수집용이며 능력·매력 점수나 성공률을 높이지 않는다. 더 비싼 옷이 더 아름답다는 평가도 없다.
- 연습 장비는 마이크·연습 매트·대본·카메라 각 3등급, 150/400/900코인이다. 해당 노래·춤·연기·예능 연습 경험치에 +1/+2/+3만 준다.
- 같은 장비 종류는 가장 높은 보너스 하나만 적용한다. 장비 없이도 전 경력·월드스타 조건을 달성할 수 있다.
- 상점 구경·구매·옷 갈아입기에는 일정 칸과 에너지를 쓰지 않는다. 화장 성장 보상은 ‘화장 연습’ 칸을 완료할 때만 준다.

## 7. 성공 판정과 재도전

### 7.1 결과를 만드는 세 요소

`결과 점수 = 반올림(능력 준비도 × 0.8 + 직접 활동 점수 × 0.2) − 스트레스 감점`, 최종 범위는 0~100이다.

- 능력 준비도는 `활동에 쓰는 능력의 가중 평균 ÷ 권장 능력 × 100`이며 최대 100이다.
- 직접 활동 점수는 미니게임이면 0~100, 일반 활동이면 선택한 준비 방식에 따라 60 또는 80이다.
- 일반 활동에서는 ‘기본 진행 60’과 ‘목표에 맞춰 준비 80’을 모두 보여 준다. 목표 문장에 맞는 선택을 하면 80이며 추가 비용은 없다.
- 모든 범위형 기본 보상은 `최소값 + 반올림((최대값−최소값) × 결과 점수 ÷ 100)`이다. 이후 적용 대상에만 선택한 활동 규모 배수를 곱한다.
- 예를 들어 +16~24인 무료 훈련에서 75점이면 능력 경험치 +22를 받는다. 공통 경험치는 표의 고정값이며, 성공 여부는 별도로 추첨하지 않는다.
- 연습 권장 능력은 20이다. 방송·공연·촬영·음원·작곡 등 공개 활동은 선택한 규모에 따라 데뷔 25, 인기 40, 톱스타 60, 월드스타 80이다. 오디션·캐스팅의 예외는 아래 표를 따른다.
- 성장 단계가 올라가도 기존 소규모 활동을 선택할 수 있다. 활동 카드에서 규모·권장 능력·배수를 미리 보여 준다.

| 활동 | 능력 가중치 | 합격·성공 기준 |
| --- | --- | --- |
| 기본·전문 연습 | 선택한 능력 100% | 권장 20, 합격·불합격 없이 성장 |
| 데뷔 오디션 | 노래 40% + 춤 40% + 매력 20%, 권장 20 | 65점 이상. 참가비 없이 새 일정 칸으로 재도전 |
| 대형 소속사 오디션 | 가장 높은 능력 80% + 매력 20%, 권장 35 | 70점 이상. 재도전 제한 없음 |
| 노래·춤 중심 활동 | 선택 전문 능력 80% + 매력 20% | 60점 기본 완료, 85점 이상 특별 반응 |
| 영화 캐스팅·촬영 | 연기 80% + 매력 20% | 캐스팅은 권장 25·65점, 촬영은 60점 이상 성공 기록 |
| 예능·인터뷰·광고 | 예능감 또는 매력 80% + 보조 능력 20% | 예능 보조는 매력, 광고 보조는 예능감. 60점 기본 성공 |
| 음원·자작곡 | 노래 100% | 60점 발매 성공 기록, 85점 이상 화제작 |

- 일반 공개 활동은 60점 미만이어도 완료 수입·성장·팬을 표의 공식대로 받고, 성공 횟수 목표에만 더하지 않는다.
- 오디션 불합격은 능력·공통 경험치만 받는다. 데뷔 해금·합격 의상·합격 팬은 최초 합격에만 준다.
- 데뷔 최소 조건인 노래·춤 15와 초기 매력 10에서, 스트레스가 낮고 일반 준비 80이면 72점이므로 통과할 수 있다.
- 실패 화면은 부족한 능력 하나와 무료 연습·휴식 바로가기를 보여 준다. 재도전은 새 일정 칸을 사용한다.
- 시작할 때 칸·돈·에너지를 확정하고, 완료 결과에 고유 기록 번호를 붙인다. 결과 재표시·연타·불러오기로 보상이 중복되지 않는다.

## 8. 가끔 등장하는 일곱 가지 미니게임

### 8.1 빈도와 난이도

- 대상은 노래·춤·연기·예능·화장·작곡 활동이다. 대상 활동을 3회 시작할 때마다 세 번째 활동에 미니게임을 제안하며 하루 최대 2회다.
- 일반 오디션도 관련 대상 횟수에 포함한다. 콘서트에서는 선택 전문 분야에 맞는 노래 또는 춤 게임을 사용한다.
- 첫 보컬 훈련에만 연습용 미니게임을 한 번 소개하고 그날의 2회 한도에 포함한다. 예고는 일정표에 표시한다.
- 제안을 받은 뒤에는 대상 횟수를 0으로 되돌린다. 첫 보컬 소개도 동일하며, 한도 소진 뒤에는 횟수를 쌓지 않는다. 다음 아침에는 횟수·한도를 초기화한다.
- 미니게임을 원하지 않으면 ‘일반 활동으로 하기’를 고른다. 일반 준비 점수로 진행하며 모든 단계·경력을 달성할 수 있다.
- 일반 활동과 미니게임은 서로 다른 자동화 방식이 아니다. 둘 다 플레이어가 각 활동을 직접 시작하고 마친다.
- 기본은 쉬움이다. Lv.1~5는 짧은 패턴, Lv.6~15는 입력 수 소폭 증가, Lv.16 이상은 기억 길이 한 단계 증가에서 멈춘다.
- 언제든 ‘더 편하게’를 고르면 처음 난이도·넓은 판정·도움말을 사용한다. 보상 배수나 경력 조건에 불이익을 주지 않는다.

| 안무 기억 | 25~40초, 2→3→4동작을 보여 준 뒤 3회 반복 | 방향키 / 같은 방향 버튼 | 전체 정답 동작 비율. 순서 다시 보기 가능 |
| 영화 장면 연기 | 약 30초, 상황 3개에 어울리는 감정·대사 선택 | 숫자 1~3·클릭 / 카드 탭 | 상황과 맞는 선택 100, 다른 해석 60. 읽기 제한 시간 없음 |
| 예능 이야기 잇기 | 약 30초, 주제에 맞는 말 카드 3장 고르기 | 숫자 1~3·클릭 / 카드 탭 | 주제에 맞는 선택 100, 다른 선택 60. 정답 힌트 제공 |
| 화장 꾸미기 | 보통 20~45초, 색과 소품을 자유 조합 | 클릭 / 탭 | 완료하면 80. 색·모양·조합의 미학 점수 없음 |
| 멜로디 만들기 | 보통 20~45초, 네 마디에 음표·악기 선택 | 클릭·숫자키 / 탭 | 끝까지 만들고 들어 보면 80. 특정 멜로디 강요 없음 |

- 리듬은 정확 ±180ms, 가까움 ±320ms부터 시험한다. ‘더 편하게’는 ±250/450ms와 느린 노트를 쓴다.
- 방향 입력은 다음 화살표를 충분히 보여 주고 2초씩 기다린다. 기억 게임은 틀려도 남은 동작을 계속할 수 있다.
- 화장·작곡은 권장 체험 시간이 있을 뿐 자동 종료하지 않는다. 다시 듣기·되돌리기는 추가 보상을 주지 않는다.
- 화장의 80은 공통 활동 처리를 위한 내부 완료값이다. 화면에는 외모 점수·등급 없이 완성한 모습과 매력 경험치 보상만 보여 준다.
- 읽기·기억 도움과 소리 없이 보는 박자 표시를 제공한다. 색만으로 정답을 구별하지 않는다.
- 중단 메뉴의 ‘일반 활동으로 마치기’는 시작 시 선택한 일반 준비 점수로 정산한다. ‘취소’는 비용과 칸을 되돌리되 보상이 없다.
- 취소한 미니게임의 제안·패턴은 해당 칸에 유지한다. 미니게임 도중 새로고침해도 다른 문제를 뽑아 유리하게 바꾸지 않는다.
- 일시정지는 현재 상태를 유지한다. 창을 닫은 뒤 복구는 같은 활동의 시작으로 돌아가며 이미 차감된 비용을 재차 차감하지 않는다.

## 9. 성장 단계와 서로 다른 경력

아래 소요일은 능력 경험치·경제·활동 횟수를 실제로 검증하기 전 목표다. 날짜가 지났다고 자동 승급하지 않으며, 천천히 즐겨도 압박이나 마감은 없다.

| 단계 | 제안 조건 | 해금 | 목표 도달 시기 |
| --- | --- | --- | --- |
| 연습생 | 새 게임 | 무료 기본 연습·꾸미기·멤버 대화 | 1일째 |
| 데뷔 | Lv.3, 노래·춤 15, 데뷔 오디션 합격 | 음원·방송·영화·스트리밍·공개 팬 반응 | 6~10일째 |
| 인기 아이돌 | Lv.8, 팬 3,000, 인지도 20, 공개 활동 10회 | 중형 무대·새 촬영장·의상 | 20~35일째 |
| 톱스타 | Lv.15, 팬 50,000, 인지도 55, 아래 경력의 중간 목표 하나 | 대형 공연·대표작 소개·해외 소식 | 60~100일째 |
| 월드스타 | Lv.25, 팬 1,000,000, 인지도 90, 아래 최고 목표 하나 + 해외 소개 활동 | 월드 무대·특별 의상·계속되는 기록 | 160~260일째 |

첫 콘서트는 15~30일째를 중간 목표로 삼는다. 15분 세션 기준 데뷔 약 2~5회, 첫 콘서트 약 5~15회, 월드스타 약 54~130회를 예상하며, 활동 선택·읽기 속도에 따라 달라지는 검증 전 목표다.

| 육성 방향 | 중간 목표: 하나로 톱스타 진입 | 최고 목표: 하나로 월드스타 진입 |
| --- | --- | --- |
| 무대형 | 노래 또는 춤 45, 성공 콘서트 3회 | 노래 또는 춤 80, 성공 콘서트 15회, 투어 3개 도시 공연 |
| 배우형 | 연기 45, 영화 3편, 누적 관객 30만 | 연기 80, 영화 10편, 누적 관객 500만 |
| 예능형 | 예능감 45, 성공 예능·인터뷰 10회 | 예능감 80, 성공 예능·인터뷰 40회, SNS 팔로워 100만 |
| 싱어송라이터형 | 노래 45, 자작곡 3곡, 누적 재생 10만 | 노래 80, 자작곡 10곡, 누적 재생 300만 |

- 네 방향은 선택 화면의 직업 고정이 아니라 현재 활동으로 생기는 기록이다. 중간에 바꾸거나 여러 목표를 함께 채울 수 있다.
- 데뷔 때 필요한 기본 노래·춤 15 이후에는 다른 능력의 높은 최소값을 요구하지 않는다. 배우도 영화 활동으로 그룹 팬을 키운다.
- 해외 소개는 톱스타에서 무료로 열리는 1칸·에너지 10 활동이다. 내 주력 분야를 소개하면 완료하며 추가 합격 판정은 없다.
- 투어는 톱스타에서 열리고, 서로 다른 세 도시의 콘서트를 직접 한 번씩 완료한다. 비용·판정은 해당 규모 콘서트와 같다.
- 대형 소속사 합격은 작업실과 이야기 확장이다. 불합격하거나 작은 소속사에 남아도 월드스타를 막지 않는다.
- 첫 콘서트·첫 영화·첫 자작곡·팬과 팔로워의 1천/1만/10만/100만 달성은 각각 한 번만 기념 의상 또는 장식을 준다.
- 월드스타 달성에는 짧은 축하 장면을 보여 준다. 엔딩·초기화 없이 다음 날 일정으로 돌아간다.

### 연말과 장기 목표

- 해마다 84일째, 그해 발표한 작품과 활동을 정리하는 시상식을 연다. 참가 비용이나 필수 미니게임은 없다.
- 첫 영화에서 60점 이상이면 ‘첫 연기 도전상’을 즉시 받아 작은 성공을 기념한다. 연말 대상과 별개인 일회성 중간 목표다.
- 연말 연기 대상은 그해 영화 3편 이상, 그중 상위 3편 평균 85점 이상, 해당 연도 관객 100만 이상이면 받는다. 무작위 경쟁으로 탈락시키지 않는다.
- 무대·예능·창작에도 그해 성공 활동 10회와 평균 85점이면 분야별 대상을 준다. 모든 상을 받는 것은 필수가 아니다.
- 연도가 바뀌면 시상식 집계만 새로 시작한다. 능력·팬·관객 누적·이전 트로피·경력 조건은 유지한다.
- 월드스타 뒤에는 해마다 새 주제의 작품·도시·의상 색상을 조합한다. 준비된 사건이 소진되면 새 대본이 무한 생성되는 것처럼 표현하지 않는다.

## 10. 짧은 사건과 팬 반응

- 하루 아침 또는 결과 직후 사건은 최대 1개, 읽는 시간은 약 15~30초다. 미니게임과 동시에 띄우지 않는다.
- 처음 이틀에는 안내 사건만 제공한다. 이후 2일마다 사건 후보를 확인하며 조건에 맞는 미열람 사건을 우선한다.
- 같은 일반 사건은 10일 동안 반복하지 않는다. 데뷔·첫 작품·첫 콘서트 사건은 한 번만 발생한다.
- 선택 전에 ‘돈 +30’, ‘그룹 스트레스 −10’처럼 직접 결과를 보여 준다. 선택 후 내용과 대사는 달라지되 경력을 영구적으로 닫지 않는다.
- 선택하지 않고 닫으면 다음 아침까지 보관한다. 다른 사건을 밀어내며 계속 쌓이지 않도록 대기 사건은 1개로 제한한다.
- 팬 반응은 공개 결과마다 짧게 1~2개 표시하고 일지에 남긴다. 응원·기억에 남는 장면 중심이며 팔로워 수와 내용이 어울리게 한다.

| 사건 | 등장 조건 | 선택 A | 선택 B |
| --- | --- | --- | --- |
| 나래의 연습실 메모 | 3일째 이후, 첫 등장 | ‘같이 읽어 보기’: 노래 경험치 +8, 다정한 대화 | ‘쉬며 이야기하기’: 스트레스 −10, 숙소 대화 |
| 작은 영화의 캐스팅 제안 | 데뷔 후 연기 20 | ‘대본 받아 보기’: 무료 캐스팅을 일정 후보에 추가 | ‘나중에 도전하기’: 제안을 활동 목록에 보관 |
| 인터뷰 한마디가 화제 | 예능 결과 85점 이상, 최초 1회 | ‘짧은 후속 영상’: 팔로워 +100, 스트레스 +2 | ‘멤버들과 감사 인사’: 그룹 팬 +80, 스트레스 −5 |

사건 보상은 선택 확정 시 한 번만 지급한다. 일부 사건이 활동을 제안하더라도 실제 촬영·훈련에는 별도 일정 칸이 필요하며 사건 대화만으로 완료하지 않는다.

## 11. 필수 화면과 조작 흐름

시작 화면 → 10슬롯 선택 → 이어하기 또는 리더 만들기 → 오늘 화면 → 활동 선택·실행 → 결과 → 오늘 화면 → 하루 결산으로 연결한다.

| 화면 | 꼭 보여 줄 내용 |
| --- | --- |
| 시작·저장 슬롯 | 리더 초상화·이름·그룹·단계·게임 날짜·저장 시각, 빈 슬롯, 새로 시작 |
| 리더 만들기 | 이름·그룹명·얼굴·머리·색상·시작 의상·성격, 5명 전체 미리보기 |
| 오늘·일정 | 7칸과 남은 칸, 에너지, 그룹 기분, 돈, 다음 목표, 활동 시작·오늘 마치기 |
| 장소 선택 | 연습실·숙소·소속사·무대·촬영장. 현재 가능한 활동으로 바로 이동 |
| 활동 선택 | 해금 조건, 칸·돈·에너지 비용, 권장 능력, 예상 성장·수입, 미니게임 예고 |
| 활동·미니게임 | 내 캐릭터와 상황, 큰 조작 안내, 일시정지·일반 활동으로 마치기 |
| 결과·하루 결산 | 이번 변화량, 새 해금, 멤버 소감, 자동저장 상태, 다음 날 |
| 옷장·상점 | 착용 미리보기, 보유·착용 표시, 가격, 장비 효과, 되돌리기 |
| 성장·기록·소식 | 다섯 능력, 경력별 목표, 작품·관객·팬·팔로워, 연말 트로피, 사건 일지 |
| 설정·저장 | 소리·도움말·움직임 줄이기, 수동 저장·불러오기, 현재 슬롯 표시 |

- iPad는 가로·세로 모두 버튼이 잘리지 않게 배치한다. 작은 화면에서는 일정과 상세 정보를 순서대로 보여 준다.
- 주요 터치 버튼은 최소 48px, 설명은 짧은 문장과 아이콘을 함께 사용한다. 드래그는 선택 사항이며 탭만으로 모든 활동이 가능하다.
- PC는 클릭과 Tab·Enter로 기본 화면을 조작하고, 미니게임에는 해당 키를 표시한다. Esc는 일시정지 또는 이전 화면이다.
- 숫자 전체를 항상 펼치지 않는다. 기본 화면에는 오늘 필요한 자원, 상세 화면에는 경험치·판정 근거를 보여 준다.
- 색상은 라벤더·민트·크림·하늘색을 중심으로 하고 핑크는 작은 장식에만 사용한다. 성공·부족 상태는 글자와 아이콘으로도 구분한다.
- 리더와 멤버는 대기·연습·노래·춤·촬영·휴식·기쁨 동작을 간단히 움직인다. 의상은 움직임에도 유지한다.
- 장소마다 짧고 밝은 BGM, 클릭·성장·합격·응원 효과음을 제공한다. 음악·효과음 음량을 따로 조절하고 음소거를 저장한다.

## 12. 15분 플레이 예시

| 경과 | 플레이어의 행동 | 얻는 경험 |
| --- | --- | --- |
| 0~2분 | 이어하기, 멤버의 한마디, 오늘 노래·춤·휴식 등 7칸 고르기 | 오늘의 작은 목표를 이해 |
| 2~6분 | 보컬 2회, 댄스 1회, 리듬 게임 1번, 무료 휴식과 남은 활동 | 직접 조작과 능력 성장, 스트레스 회복 |
| 6~7분 | 하루 결산과 자동저장, 다음 날짜로 이동 | 동료 성장·새 옷 또는 콘텐츠 조건 확인 |
| 7~12분 | 다음 날 방송 또는 오디션 준비, 미니게임 1~2번, 결과와 팬 반응 | 내 선택이 경력과 그룹 팬으로 이어짐 |
| 12~15분 | 옷을 바꾸고 목표 확인, 수동 저장 후 종료 | 외형 변화와 다음에 할 일 확보 |

첫날 예시 일정은 보컬 2회 → 댄스 1회 → 휴식 → 댄스 1회 → 연기 1회 → 균형 식사다. 정확히 7칸이며 에너지는 60→36→60→44→54, 스트레스는 처음 9까지 오른 뒤 휴식·식사로 0이 된다. 리듬 게임은 해당 훈련 안에 포함되어 칸을 추가로 쓰지 않는다.

15분에 정확히 특정 날짜를 마치도록 강제하지 않는다. 읽기·꾸미기를 오래 즐겨도 안전하게 중간 저장하며, 빠르게 진행하면 3일 정도를 목표로 한다.

## 13. 저장 10개와 중간 복구

- 1~10번은 각각 독립된 리더·그룹·진행 기록이다. 슬롯 하나에 외모·의상·성격·자원·일정·작품·기록·설정을 함께 저장한다.
- 자동저장은 ‘오늘 마치기’ 결산을 확정한 직후 다음 날 시작 상태로 **현재 슬롯에 게임 날짜당 한 번** 수행한다.
- 수동 저장은 현재 슬롯 또는 다른 슬롯에 가능하다. 다른 슬롯에 저장하면 이후 진행과 자동저장 대상도 그 슬롯으로 바뀐다.
- 기존 슬롯을 새 게임이나 복사 저장으로 바꿀 때는 리더 이름과 날짜를 보여 주고 덮어쓰기를 확인한다. 빈 슬롯은 즉시 사용한다.
- 슬롯의 현재 진행을 수동 저장하는 것은 덮어쓰기 확인을 매번 띄우지 않는다. 저장 완료 시각을 표시한다.
- 새 게임 생성 직후와 하루 중에는 별도의 ‘중간 복구 기록’을 갱신한다. 이는 11번째 슬롯이나 하루 자동저장 횟수에 포함하지 않는 내부 복구용 사본이다.
- 중간 복구에는 확정된 활동·구매·착용·사건 선택과 진행 중인 활동의 시작 상태를 남긴다. 결과 지급과 지급 완료 표시는 함께 확정한다.
- 정식 저장 성공 시 해당 시점까지 복구 기록을 정리한다. 시작할 때 더 새로운 복구 기록이 있으면 ‘최근 진행 복구 / 저장 시점으로’ 중 선택한다.
- 예전 정식 저장으로 돌아가면 이후 진행은 그 육성 기록에서 되돌린다. 다른 분기의 보상을 합치지 않으며 복구 기록도 선택한 시점에 맞춘다.
- 미니게임 중 수동 저장 요청은 일시정지 후 해당 활동의 시작 상태를 저장한다고 안내한다. 완료 보상은 아직 지급하지 않는다.
- 저장 실패는 ‘이 기기에 저장하지 못했어요’와 재시도 버튼으로 알리고, 성공했다고 표시하지 않는다. 가능한 경우 현재 플레이는 유지한다.
- 저장은 같은 기기·브라우저·사이트 주소에서 이어진다. iPad와 PC의 자동 동기화는 없고, 브라우저 데이터 삭제 시 기록이 사라질 수 있다.
- 손상된 슬롯은 다른 슬롯과 분리하고 바로 삭제하지 않는다. 복구 가능한 직전 기록을 제시하며, 기술적인 복구 방식은 개발 계획에서 확정한다.

## 14. 오프라인과 완성 목표

### 첫 플레이 검토 빌드

5명 소개·리더 생성·7칸 하루·다섯 능력과 자원·기본 노래/춤/휴식·노래와 방향/기억 춤 미니게임·데뷔 오디션·10슬롯 저장·기본 의상 구입/착용·BGM/효과음·오프라인 기본 플레이를 연결한다. 이 빌드에서는 첫 15분의 이해도와 성장 속도를 검토한다.

### 완성 목표 전체 기능

일곱 미니게임, 영화·예능·광고·콘서트·음원·자작곡·스트리밍, 네 육성 경로, 모든 성장 단계, 대형 소속사, 연말 시상식, 사건과 팬 반응, 전체 장소·의상·장비·애니메이션·음향·접근성·저장 복구를 포함한다. 첫 빌드에서 일부만 연결하는 것은 단계적 구현이며, 나머지 요구를 삭제하는 것이 아니다.

게임 파일·그림·소리를 처음 내려받거나 오프라인용으로 준비하는 과정에는 인터넷이 필요할 수 있다. 준비 후에는 외부 로그인·서버·실시간 통신 없이 플레이·저장·재실행해야 한다. iPad와 PC의 설치·캐시 유지 차이 및 최초 실행 방법은 개발 계획에서 구체화하고 실제 기기로 확인한다.

### 완성 판단 기준

- 처음 접하는 어린이가 설명을 길게 읽지 않고 활동 선택·결과·휴식·다음 날을 진행한다.
- 하루 7칸, 에너지 상한, 레벨 경험치, 능력 경험치를 서로 혼동하지 않는다.
- 돈 0·에너지 0·스트레스 100에서도 무료 회복과 다음 날로 진행할 수 있다.
- 노래·춤 외 경력에 집중해도 각 경로의 최고 목표와 월드스타 도달이 가능하다.
- 미니게임을 틀리거나 일반 활동으로 진행해도 성장·데뷔·경력 달성이 막히지 않는다.
- 10슬롯의 분리·수동 저장·하루 자동저장·중간 복구가 외형과 보상을 정확히 복원하고 중복 지급하지 않는다.
- 의상·화장이 각 활동 화면에 보이며, 외모의 예쁨을 점수로 평가하지 않는다.
- 실제 기기의 비행기 모드에서 재실행·성장·저장을 확인하고, 탭을 닫아 둔 시간에는 게임 날짜가 변하지 않는다.
- 데뷔까지와 네 경로의 중간·최고 목표까지 모의 진행해 수치·돈·필수 활동의 막힘을 확인한 뒤 목표 기간을 조정한다.
