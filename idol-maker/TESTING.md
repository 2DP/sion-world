# 구현 및 검증 기록

검증일: 2026-10-03. 로컬 체험판이며 외부 웹 배포는 하지 않았다.

## 자동 검사

`node --test --test-isolation=none tests/*.test.mjs` — **25개 통과, 실패 0개**.

- 제공된 `game.bundle.js`와 소스 일치, 모듈 없는 일반 스크립트 문법 검사.
- 실제 묶음 파일을 `file:` 환경의 DOM 모형에서 실행해 첫 화면 렌더링 확인. manifest·Service Worker·Web Locks 접근이 없음을 검사.
- `http:` 환경의 동일한 화면 렌더링과 manifest 연결, HTML에서 모듈·정적 manifest 요청 제거 확인.

- 실제 활동을 통한 네 경력의 월드스타 도달, 무료 훈련만으로 성장 가능 여부.
- 하루 일곱 칸, 무료 회복, 동료 성장, 날짜 수동 진행, 미니게임 하루 제안 제한.
- 활동 취소 시 정확한 비용 반환, 저장 후 같은 활동 재개, 완료·사건 보상 중복 방지.
- 작품 진행 중 규모 고정, 최종 회차에서만 수입·관객·인지도·연말 실적 반영.
- 연말 시상식과 연간 집계 초기화, 전체 경력 보존, 잘못된 저장 값 거부.
- 사건 미열람 우선·10일 반복 제한·읽지 않은 사건 유지·일기 기록.
- 대형 소속사 장비 해금, 장비 최고 등급만 적용, 재구매 차단.
- 10개 슬롯 분리, 정식 저장과 중간 복구, 오래된 쓰기 충돌 거부, 저장 실패·손상 복구.
- 리듬 판정 경계와 쉬운 모드, 캐릭터 문자열·색상 처리, 화장 없음, 의상 모양 구분.
- 모든 초기 자원과 ES 모듈을 오프라인 캐시에 포함하고 게임 경로로 범위 제한.

## 브라우저 검사

Codex 내장 Chromium 브라우저에서 확인했다.

- 새 리더·그룹 생성 → 활동 선택 → 리듬 진입·일시정지 → 일반 활동 전환 → 결과.
- 직접 세 번 누르는 일반 노래·춤·연기 활동, 무료 휴식, 날짜 넘기기, 사건 선택.
- 화장 색 없음 선택과 완료, 의상 미리보기·구매·착용, 장비 구매·자동 적용·해금 안내.
- 다음 날 자동 저장, 수동 저장, 새로고침 뒤 복구, 리더·외형·날짜·자원 복원.
- 검증 화면에서 리듬·영화·예능·작곡·방향 춤·안무 기억의 완료와 결과 콜백 확인. 화장은 실제 게임에서 완료했다. 일부러 틀린 춤·카드 답과 리듬 0점도 끝까지 진행된다.
- PC 1366×900, iPad 세로 768×1024·가로 1024×768 크기에서 가로 넘침 없음. 검사 중 브라우저 오류·경고 로그 없음. [PC 화면 캡처](artifacts/game-preview.jpg).
- 서버를 완전히 중단하고 새로고침 → 게임 열기 → 저장한 리더 복원 → 무료 활동 → 수동 저장 → 다시 새로고침 → 일정 사용량 유지 확인.
- 파일 실행 대응 후 루트 게임 목록의 아이콘·바로가기 → 게임 첫 화면 → 기존 저장 슬롯 표시를 HTTP 브라우저에서 재검증했다. 실제 로딩 스크립트는 `game.bundle.js`이며 검사 중 CORS·JavaScript 오류가 없었다.

오프라인 검사는 해당 기기에서 첫 실행과 자원 캐시가 완료된 뒤 진행했다. 처음부터 인터넷과 설치 자료가 전혀 없는 새 기기의 최초 설치를 보장하는 검사는 아니다.

## 성장 속도 모의 진행

공통 전략은 무료 노래·춤 연습으로 데뷔한 뒤 주력 능력을 먼저 80까지 올리고, 하루 슬롯과 에너지를 사용하며 한 경력에 집중한다. 미니게임 직접 점수 80, 유료 수업·장비 없음. 사건 선택은 하지 않는다.

| 경력 | 데뷔 | 월드스타 | 수행 활동 수 |
| --- | --- | --- | --- |
| 무대 | 4일째 | 64일째 | 410 |
| 배우 | 4일째 | 115일째 | 729 |
| 예능 | 4일째 | 102일째 | 706 |
| 싱어송라이터 | 4일째 | 95일째 | 663 |

이는 도달 가능성과 경제의 막힘을 확인하는 집중 진행 검사다. 아이의 읽기·꾸미기·휴식·미니게임 시간을 포함하지 않는다. 기획의 월드스타 160~260일 예상보다 빠르므로 이를 검증된 실제 플레이 기간으로 제시하지 않는다. 현재는 지루하게 능력치를 반복해서 올리는 부담을 늘리지 않고, 첫 체험 이후 성장 속도를 조정한다.

## 실제 기기에서 확인할 항목

- PC 브라우저에서 `index.html`을 실제 더블클릭해 실행·저장·재시작 확인. 브라우저 검증 도구가 `file://` 탐색을 금지하므로 파일 주소 자체의 브라우저 검증은 수행하지 못했다. 자동 실행 검사와 HTTP 브라우저 검증을 구분한다.
- iPad Safari 가로·세로 터치, 리듬 음향 지연, 화면 잠금·앱 전환 복귀.
- HTTPS 설치 주소에서 홈 화면 추가 후 비행기 모드 재시작.
- 오래된 iPad의 SVG·애니메이션 성능과 오디오 재개.
- 9세 사용자의 글 읽기 속도, 활동 반복의 재미, 미니게임 난이도.

뷰포트 크기 검사는 실제 iPad 하드웨어·Safari 검증과 구분한다. 캐릭터·배경·음향은 모두 게임 내부 코드로 생성하며 실제 아이돌 사진이나 외부 음원은 쓰지 않는다.

## 구현 범위에 관한 메모

- 일정을 한 칸씩 고르고 실행하는 흐름이다. 여러 미실행 일정을 미리 묶어 편집하는 시간표 편집기는 없다.
- 일반 활동은 세 번의 수동 입력으로 진행되며 대기 시간을 강제하지 않는다.
- 의상은 전신 의상·신발·소품 단위다. 상의·하의를 각각 고르는 기능은 없다.
- 사건은 준비한 13종을 조건에 따라 제공한다. 새 이야기를 무한 생성하지 않는다.
- 장기 진행은 기존 도시·의상·작품 틀을 재사용하며, 새 지역·새 작품 대본이 해마다 자동 추가되지는 않는다.
- 게임 기획과 개발 계획의 상태를 구현 승인 완료로 갱신했다. 성장 수치 등 기획 초안의 추정은 위 실측 기록과 함께 검토한다.
