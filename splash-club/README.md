# 첨벙클럽

귀여운 사람 선수와 함께하는 성장형 리듬 수영 웹게임. 외부 패키지 설치 없이 실행합니다.

## 실행

`index.html`을 더블클릭하면 서버 없이 바로 실행됩니다. `style.css`와 `game.bundle.js`를 같은 폴더에 유지하세요.

웹서버로 실행할 수도 있습니다.

```sh
node server.mjs
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 같은 주소와 브라우저를 사용해야 저장을 이어갈 수 있습니다.

직접 연 파일(`file://`)과 웹서버(`http://`)의 저장 공간은 별개입니다. 직접 열기 방식의 저장은 브라우저 설정과 파일 위치에 따라 달라질 수 있습니다.

## 코드 수정 후

`core.js`, `character.js`, `app.js`를 수정했다면 `node build.mjs`로 실행용 `game.bundle.js`를 다시 생성하세요. 생성된 파일을 함께 배포합니다. `npm start`는 빌드 후 서버를 실행합니다.

## 플레이

- 새로 하기에서 이름과 수영복 색을 선택합니다. 기존 저장이 있으면 이어서 하기를 사용할 수 있습니다.
- 집: 10슬롯 저장과 7가지 생활 활동.
- 상점: 마을이나 이동 메뉴에서 방문하여 100종 장비 구매·장착.
- 연습장: 혼자 50m 수영 후 경험치·코인 획득.
- 경기장: AI 4명과 100m 경기. 선수 레벨에 따라 패턴과 AI가 어려워집니다.
- Q 왼팔 / W 왼다리 / O 오른팔 / P 오른다리. 노트가 초록 선에 닿을 때 누릅니다.
- 콤보당 속도 +0.5%, 40콤보 이상 +20%. ESC로 일시정지합니다.
- 이어서 하기와 새로 하기에서 10개 슬롯 중 하나를 선택합니다. 집에서는 다른 슬롯에 복사 저장할 수도 있어요.
- 저장 키는 `splash-club-save-v2-slot-1`~`splash-club-save-v2-slot-10`입니다. 기존 v1 저장은 1번 슬롯에서 이어갈 수 있으며, 50m 최고 기록만 초기화됩니다. 경기 중 진행도는 저장하지 않습니다.
- 집 활동은 활력(최대 100)만 사용해 다음 수영 3회에 작은 부스트를 줍니다. 같은 활동은 3회로 갱신, 서로 다른 활동은 함께 적용됩니다. 수영을 시작하면 1회를 사용하며 포기해도 돌아오지 않습니다.
- 먹기·자기·TV·태블릿·목욕·놀기·쉬기를 선택할 수 있어요. 자고 나면 다음 날이 됩니다.
- 연습 완주 시 활력 +30, 대회 완주 시 +50. 활력이 없어도 수영할 수 있어요.
- 판정은 Perfect ±140ms, Good ±240ms, Bad ±320ms로 여유로워졌어요. 연습은 80 BPM, 대회는 80~96 BPM입니다. 초록 영역에 노트가 들어오면 눌러주세요.
- 상점은 4부위 × 25종이며 부위별 1개만 장착합니다. 부위·보유 필터와 페이지 이동으로 찾아보세요.

## 검증

```sh
node --test --test-isolation=none tests/*.test.mjs
```

현재 버전은 SVG/CSS 캐릭터와 수영장, 합성 박자음을 사용한 플레이 가능한 프로토타입입니다. 온라인 대전과 정식 배경 음악은 포함하지 않습니다. Google Fonts를 사용할 수 없는 환경에서는 시스템 글꼴로 표시됩니다.

- 수영 화면에 적용 중인 생활 부스트와 이후 남은 횟수를 표시합니다.
- 내 선수가 완주하면 바로 결과가 나옵니다. 아직 도착하지 않은 AI는 미완주로 표시됩니다.
