# 첨벙첨벙! 리듬 수영 대회

웹게임 기획서 v0.3 · 2026-10-01

## 1. 게임의 핵심

귀여운 여자아이 수영 선수 5명이 수영장에서 겨루는 리듬 수영 레이싱 게임이다. 선수는 서로 다른 수영복 색으로 구분한다. 캐릭터의 기본 스탯으로 수영 능력이 결정되고, 플레이어가 Q·W·O·P를 리듬에 맞춰 누르면 더 빠르게 전진한다. 연속으로 리듬을 맞춰 콤보를 쌓을수록 추가 속도 보너스를 얻는다.

**핵심 재미:** 네 팔다리로 헤엄치는 손맛, 정확한 리듬이 속도로 바뀌는 쾌감, 결승선까지 이어지는 접전.

| 항목 | 기획 방향 |
|---|---|
| 플랫폼 | PC 웹브라우저, 키보드 조작 |
| 장르 | 리듬 액션 + 수영 레이싱 |
| 경기 인원 | 총 5명, 선수별 독립 레인 |
| 첫 버전 | 플레이어 1명 + AI 4명 |
| 경기 규칙 | 직선 100m 경기, 먼저 완주한 선수가 우승 |
| 목표 플레이 시간 | 한 경기 약 90~150초 (장비·부스트·입력에 따라 달라짐) |
| 시각적 방향 | 파스텔 컬러, 둥글고 짧은 팔다리, 표정이 풍부한 여자아이 캐릭터, 선수별로 다른 수영복 색 |

100m와 경기 시간은 실제 수영 기록을 재현하기보다 게임의 템포에 맞춘다. 온라인 5인 대전은 확장 기능으로 분리한다. 이는 이번 초안의 범위 가정이며, 반드시 5명의 실제 플레이어가 필요한 경우 별도 멀티플레이 기획이 필요하다.

## 2. 한 판의 흐름

1. **캐릭터 선택:** 외형, 기본 속도, 추진력, 안정성을 확인한다.
2. **짧은 연습:** Q·W·O·P와 동시 입력을 익힌다. 이후 건너뛸 수 있다.
3. **출발 준비:** 다섯 선수가 출발대에 서고, 네 박자의 카운트인 이후 함께 출발한다.
4. **레이스:** 리듬 노트를 맞추면서 자신의 레인에서 전진한다.
5. **마지막 구간:** 선두가 80m를 지나면 결승선과 순위를 강조한다. 조작 규칙은 유지한다.
6. **결과:** 순위, 기록, 정확도, 최대 콤보와 이전 개인 기록을 보여준다.
7. **재도전:** 같은 캐릭터로 즉시 다시 하거나 캐릭터 선택으로 돌아간다.

## 3. 네 팔다리 조작

왼손은 Q·W, 오른손은 O·P를 담당한다. 각 키는 캐릭터의 신체 부위와 고정 연결한다.

| 키 | 신체 부위 | 시각적 반응 |
|---|---|---|
| Q | 왼팔 | 왼팔로 물을 밀며 큰 물방울 발생 |
| W | 왼다리 | 왼발 킥과 작은 거품 발생 |
| O | 오른팔 | 오른팔로 물을 밀며 큰 물방울 발생 |
| P | 오른다리 | 오른발 킥과 작은 거품 발생 |

캐릭터는 입력하지 않아도 낮은 속도로 계속 헤엄친다. 유효한 입력은 해당 팔다리의 동작과 추진 효과를 강화한다. 잘못 눌러도 작은 동작은 보여주되 추가 추진력을 주지 않는다. 실제 수영의 생체역학보다는 조작의 직관성과 귀여운 동작을 우선한다.

### 리듬 패턴

첫 버전은 **4/4박자의 합성 박자음**으로 제작한다. 연습과 입문 리그는 80 BPM, 도전 리그는 108 BPM, 챔피언 리그는 116 BPM을 사용한다. 같은 모드와 레벨에서는 같은 패턴을 사용해 연습과 기록 개선이 가능하게 한다.

- 입문: `Q → O → Q → O`로 양팔의 박자를 익힌다.
- 기본: `Q → W → O → P`로 네 팔다리를 번갈아 사용한다.
- 교차: `(Q+P) → 쉼 → (O+W) → 쉼`으로 팔과 반대쪽 다리를 함께 움직인다.
- 응용: Lv.10부터 간헐적인 두 키 동시 입력을 넣고, 빠른 8분음표는 제외한다.

괄호는 동시 입력, 화살표는 다음 박자를 뜻한다. 한 번에 최대 두 키만 요구하며 Q+W나 O+P처럼 한 손의 두 키를 동시에 누르는 패턴은 초기 버전에서 제외한다. 패턴 변경 전에는 짧은 예고를 표시한다.

노트는 화면 아래 네 개의 세로 트랙에서 판정선으로 내려온다. 트랙 순서는 키보드와 동일한 `Q / W / O / P`이며, 색상 외에도 키 문자와 팔·다리 아이콘으로 구별한다.

## 4. 판정과 속도

### 입력 판정

아래 수치는 첫 구현을 위한 초기값이며, 플레이 테스트로 조정한다.

| 판정 | 목표 시각과 입력의 차이 | 리듬 점수 |
|---|---|---|
| Perfect | ±140ms 이내 | 1.0 |
| Good | ±240ms 이내 | 0.7 |
| Bad | ±320ms 이내 | 0.3 |
| Miss | ±320ms 밖 또는 미입력 | 0 |

각 입력은 같은 트랙의 가장 가까운 미처리 노트 한 개만 판정한다. 동시 입력은 두 노트를 각각 판정하며, 누르고 있는 키의 자동 반복 입력은 무시한다. Bad와 Miss는 콤보를 끊고, 연속으로 아무 키나 누르는 행위는 추가 가속을 발생시키지 않는다. 판정 대상이 없는 입력은 안내만 표시하고 콤보는 유지한다. 추가 가속은 발생하지 않는다.

### 캐릭터 스탯

| 스탯 | 효과 | 설계 의도 |
|---|---|---|
| 기본 속도 | 자동 수영 속도 | 입력이 서툴러도 완주 가능 |
| 추진력 | 정확한 리듬으로 얻는 최대 가속량 | 숙련 플레이 보상 |
| 안정성 | 실수 이후 리듬 보너스를 유지하는 정도 | 초보 플레이어 부담 완화 |

활력(0~100)은 집 활동에 쓰는 생활 자원이며 수영 입장에는 필요하지 않다. 집 활동으로 얻는 일시 부스트를 지원하며, 확률형 효과는 제외한다. 기본 스탯은 레벨 상승으로 성장하고 장착 아이템의 보너스를 추가한다. 판정 시간은 모든 캐릭터에 동일하게 적용한다. 현금 결제는 없으며 아이템은 플레이로 얻는 코인으로 구매한다.

### 속도 계산 방향

리듬 판정 → 리듬 게이지와 콤보 변화 → 목표 속도 변화 → 부드러운 가감속 순서로 처리한다.

```text
콤보 보너스 = min(현재 콤보 × 0.005, 0.20)
목표 속도 = 기본 속도 × (1 + 추진 계수 × 리듬 게이지) × (1 + 콤보 보너스)
```

- 기본 속도 초기 범위: 0.65~0.72m/s.
- 추진 계수 초기 범위: 0.55~0.80.
- 리듬 게이지 범위: 0~1, 출발 시 0.5.
- 판정마다 게이지를 해당 판정의 리듬 점수 쪽으로 이동시킨다.
- 상승 시 변화율은 0.25로 동일하게 적용한다.
- 하락 시 변화율은 안정성이 낮으면 0.30, 높으면 0.18을 사용한다.
- 갱신식: `새 게이지 = 기존 게이지 + 변화율 × (리듬 점수 - 기존 게이지)`.
- 헛입력은 리듬 게이지를 0.01 낮추고 콤보는 유지한다. 같은 180ms 구간에서는 한 번만 적용한다.
- 실제 속도는 약 0.3초에 걸쳐 목표 속도에 접근해 움직임이 튀지 않게 한다.

동일 시각의 동시 노트는 두 판정 점수의 평균으로 게이지를 한 번 갱신한다.

### 콤보 가속

Perfect 또는 Good을 연속으로 맞추면 콤보가 1씩 증가한다. 같은 시각의 동시 입력은 두 노트가 모두 Perfect 또는 Good일 때 콤보를 1 올린다. 둘 중 하나라도 Bad 또는 Miss이면 콤보는 0으로 초기화한다. 동시 입력의 콤보 처리는 두 노트의 판정이 확정된 뒤 한 번 수행한다.

| 현재 콤보 | 리듬 가속 적용 후 추가 속도 보너스 |
|---|---|
| 0 | 0% |
| 10 | +5% |
| 20 | +10% |
| 30 | +15% |
| 40 이상 | +20% |

보너스는 구간별로 뛰는 방식이 아니라 콤보 1마다 0.5%p씩 증가한다. 예를 들어 리듬 가속이 적용된 속도가 1m/s라면 20콤보에서 1.1m/s, 40콤보에서 1.2m/s가 된다. 40콤보 이후에도 콤보 기록은 계속 증가하지만 속도 보너스는 20%로 제한한다.

Bad 또는 Miss가 발생하면 콤보와 목표 속도의 콤보 보너스가 초기화된다. 실제 속도는 기존의 약 0.3초 가감속 규칙에 따라 부드럽게 줄어들고, 다시 리듬을 맞추면 콤보를 쌓을 수 있다. 안정성 스탯은 리듬 게이지의 하락에만 영향을 주며 콤보 초기화를 막지는 않는다.

화면에 현재 콤보와 추가 속도 비율을 함께 표시한다. 10·20·30·40콤보 도달 시 짧은 효과음과 물보라 강화로 가속을 알리고, 노트나 판정선을 가리지 않게 한다. AI도 동일한 콤보 규칙과 최대 보너스를 적용받는다.

**밸런스 목표:** 비슷한 실력이면 캐릭터 특성이 느껴지고, 리듬을 확실히 더 잘 맞추는 플레이어는 기본 속도가 느린 캐릭터로도 이길 수 있게 한다. 콤보를 오래 유지할수록 기록이 단축되어야 한다. 90~150초는 일반적인 입력을 하는 경기의 목표이며, 높은 콤보를 유지하면 더 일찍 완주할 수 있다. 무입력 상태에서는 약 140~154초로 더 오래 걸릴 수 있다. 콤보 가속을 포함한 실제 완주 시간을 확인하며 속도 수치를 조정한다.

## 5. 귀여운 선수 5종

모든 캐릭터는 큰 머리와 작고 둥근 몸, 짧은 팔다리를 가진 귀여운 2~3등신 여자아이 수영 선수로 만든다. 수영모와 물안경을 공통으로 착용하고, 선수 구분의 주된 기준은 수영복 색으로 통일한다. 앞머리와 짧게 묶은 양갈래 머리, 반짝이는 눈과 발그레한 볼로 귀여움을 표현한다. 수영복은 몸통까지 덮는 원피스 스포츠형 디자인으로 색이 충분히 드러나게 하며, 물속에서도 색이 선명하게 보이도록 표현한다. 수영모에는 수영복과 같은 색을 보조적으로 사용한다.

| 이름 | 수영복 색 | 성격과 외형 | 스탯 성향 |
|---|---|---|---|
| 모찌 | 민트 | 동그란 얼굴, 수줍은 미소 | 균형형, 첫 추천 캐릭터 |
| 콩이 | 코랄 | 자신감 있는 눈썹, 활짝 웃는 표정 | 추진력 높음, 안정성 낮음 |
| 삐오 | 라벤더 | 통통한 볼, 커다란 물안경 | 안정성 높음, 추진력 낮음 |
| 토토 | 레몬 | 밝은 미소, 활발한 준비 동작 | 기본 속도 높음, 추진력 낮음 |
| 두부 | 하늘색 | 둥근 얼굴, 진지한 표정 | 기본 속도 낮음, 추진력·안정성 높음 |

순위표와 진행도 표시에도 각 선수의 수영복 색을 동일하게 적용한다. 색 구별이 어려운 경우를 위해 선수 이름과 레인 번호를 함께 표시한다.

수중에서도 네 팔다리의 움직임이 읽히도록 몸통 주변의 물을 반투명하게 표현한다. 플레이어는 머리 위 화살표와 강조된 레인으로 항상 식별된다.

필수 애니메이션은 대기, 출발, 기본 수영, 네 부위별 입력 반응, 실수, 완주, 우승이다. Perfect는 반짝이는 물보라, 실수는 잠깐 당황한 표정으로 표현한다. 과장된 실패 동작으로 경기 진행을 방해하지 않는다.

## 6. 경기 화면과 사운드

가로 화면에 적합한 비스듬한 탑뷰를 사용하고, 선수들은 왼쪽에서 오른쪽으로 헤엄친다. 위쪽에는 다섯 레인의 경기를, 아래쪽에는 리듬 트랙을 배치한다. 리듬에 집중하면서도 주변 시야로 순위 변화를 읽을 수 있어야 한다.

| 영역 | 표시 정보 |
|---|---|
| 상단 | 현재 순위, 경과 시간, 남은 거리, 전체 선수 진행도 |
| 중앙 | 수영장 5개 레인, 선수, 물보라, 출발·결승선 |
| 하단 | Q·W·O·P 트랙, 판정선, 콤보와 추가 속도 비율, 리듬 게이지 |
| 우측 위 | 일시정지, 소리 설정 |

첫 버전은 전체 코스를 한 화면에 표시하는 고정 카메라로 선수들의 위치를 보여준다. 경기 순위는 이동 거리로 산정하고 완주 이후에는 결승선 통과 시각으로 확정한다. 0.01초 단위 기록이 같은 선수는 공동 순위로 처리한다. 플레이어를 따라가는 카메라는 후속 연출 개선으로 검토한다.

음악은 박자가 명확한 밝은 분위기로 구성한다. Perfect, Good, 실수의 효과음을 구별하되 음악을 가리지 않게 한다. 물소리와 관중 응원은 보조 음향으로 사용한다. 화면 흔들림과 강한 번쩍임은 기본적으로 사용하지 않는다.

## 7. AI와 난이도

AI도 동일한 스탯과 속도 공식을 사용하고, 가상의 리듬 판정 결과를 생성한다. 위치를 순간 이동시키거나 플레이어의 실수에 맞춰 속도를 조작하지 않는다.

| 난이도 | 플레이어 패턴 | AI 목표 정확도 |
|---|---|---|
| 쉬움 | 단일 입력 중심, 4분음표 위주 | 55~65% |
| 보통 | 단일 입력 중심, 조금 빠른 박자 | 70~80% |
| 어려움 | Lv.10부터 간헐적인 교차 동시 입력 | 85~93% |

정확도는 `판정 점수 합계 ÷ 전체 노트 수 × 100`으로 정의한다. AI 수치는 개별 노트의 성공 확률이 아니라 경기 전체의 목표 판정 평균이다. 경기 시작 시 AI별 판정 분포를 정하고, 짧은 실수 구간과 회복 구간으로 자연스러운 변동을 만든다.

첫 구현은 선수 레벨에 따라 대회 난이도를 자동 조정한다. Lv.1~2는 입문(80 BPM), Lv.3~5는 도전(88 BPM), Lv.6 이상은 챔피언(96 BPM)이다. Lv.9까지 단일 입력만 사용하고 Lv.10부터 간헐적인 2키 동시 입력을 추가한다. 빠른 8분음표는 사용하지 않는다. AI 능력과 정확도는 단계적으로 상승하며 최대값을 제한한다. 연습은 80 BPM의 기본 패턴으로 혼자 진행한다.

## 8. 첫 버전 개발 범위

**포함**

- 캐릭터 5종 선택과 스탯 차이.
- 플레이어 1명과 AI 4명의 100m 경기.
- Q·W·O·P 단일·동시 입력, 리듬 판정, 콤보 누적에 따른 추가 가속.
- 합성 박자 음원, 레벨별 패턴, 화면 내 조작 안내.
- 순위·기록·정확도·최대 콤보와 결과 화면.
- 일시정지, 재시작, 음량, 입력 타이밍 보정.
- 로컬스토리지에 선수, 레벨, 경험치, 기본 스탯, 코인, 보유·장착 아이템, 기록, 설정 저장.
- 첫 진입의 이어서 하기·새로 하기와 집·수영연습장·수영경기장 이동.

**후속 확장**

- 실제 플레이어 5명의 온라인 대전과 방 만들기.
- 새로운 곡, 수영장, 추가 장비 디자인.
- 턴 동작, 다른 영법, 추가 거리 선택.
- 모바일 터치 조작과 키 재설정.

## 9. 구현 시 중요한 기준

- 음악 재생 시간을 기준으로 노트와 입력을 판정한다. 화면 프레임 수를 판정 기준으로 사용하지 않는다.
- 브라우저의 오디오 시작을 위해 시작 버튼 입력 후 음악을 재생한다.
- 간단한 박자 맞추기 화면에서 입력 타이밍 오프셋을 보정할 수 있게 한다.
- 창이 비활성화되면 AI를 포함한 경기와 음악을 함께 멈추고, 복귀 시 카운트인 후 재개한다.
- 단일 경기의 오디오와 노트 시계를 같은 시간축으로 유지하고 일시정지 시간은 기록에서 제외한다.
- 노트 색상만으로 의미를 전달하지 않고 키 문자와 신체 아이콘을 함께 사용한다.
- 개발용 고정 AI 시드를 제공해 같은 조건에서 캐릭터 밸런스를 비교한다.

## 10. 제작 순서와 완성 판단

1. **조작 프로토타입:** 임시 도형으로 네 키 입력, 동시 입력, 판정, 음악 동기화를 확인한다.
2. **레이싱 프로토타입:** 다섯 레인과 AI, 속도 계산, 결승선과 기록 판정을 연결한다.
3. **캐릭터 적용:** 수영복 색이 서로 다른 여자아이 선수 5명과 팔다리 동작, 물보라, 표정을 제작한다.
4. **한 판 완성:** 선택 → 연습 → 경기 → 결과 → 재도전을 연결한다.
5. **밸런스 조정:** 실제 플레이로 패턴 가독성, 피로도, 캐릭터별 승률을 확인한다.

초기 완성 여부는 다음으로 판단한다.

- 처음 하는 사람도 짧은 연습 후 네 키와 신체 부위의 관계를 이해한다.
- 같은 캐릭터와 조건에서 리듬 정확도가 높을수록 완주 기록이 좋아진다.
- 리듬 게이지와 캐릭터가 같을 때 0~40콤보 구간에서는 콤보가 높을수록 목표 속도가 증가하고, 40콤보 이상에서는 추가 보너스가 20%로 유지된다.
- 모든 키를 무작정 누르는 전략이 리듬을 맞추는 전략보다 유리하지 않다.
- 한두 번의 실수 뒤에도 리듬을 회복하면 경쟁을 이어갈 수 있다.
- 화면 크기나 프레임률 변화가 판정과 이동 거리를 바꾸지 않는다.
- 플레이어가 경기 중 자신의 위치와 다음에 누를 키를 쉽게 찾는다.

## 11. 다음 단계에서 확정할 항목

현재 초안으로 조작 프로토타입 제작을 시작할 수 있다. 정식 아트 제작 전에는 비스듬한 탑뷰에서 팔다리가 잘 읽히는지 확인하고, 반복 플레이 후에는 스탯 수치와 판정 범위를 조정한다. 온라인 대전 도입 여부는 첫 버전의 리듬 조작을 검증한 뒤 결정한다.

## 12. 저장과 생활 공간 — v0.3 구현 기준

진입 화면 → 슬롯 선택 → 이어서 하기 또는 새 선수 만들기 → 수영 마을 → 집 / 상점 / 수영연습장 / 수영경기장 → 결과 → 마을로 순환한다.

### 10개 저장 슬롯

- 1~10번 슬롯에 각각 독립된 선수를 저장한다. 이어서 하기에는 이름·레벨·날짜·코인·저장 시각을 표시한다. 빈 슬롯 및 손상된 슬롯은 불러올 수 없다.
- 새로 하기는 슬롯을 먼저 선택한다. 기존 저장이나 손상된 데이터가 있으면 명시적인 덮어쓰기 확인 후 새 선수를 만든다. 다른 슬롯에는 영향을 주지 않는다.
- 새 선수: Lv.1, 경험치 0, 120코인, 활력 60/100, 1일째, 부스트 없음.
- 집에서 현재 슬롯에 수동 저장하거나 다른 슬롯에 복사 저장할 수 있다. 다른 슬롯에 저장이 성공하면 그 슬롯이 이후 자동 저장 대상이 된다. 실패하면 현재 슬롯을 유지한다.
- 새 선수 생성, 장소 이동, 구매·장착, 집 활동, 수영 시작의 부스트 사용, 결과 보상 후 자동 저장한다. 경기 중 거리·노트 진행은 저장하지 않는다.
- 키는 `splash-club-save-v2-slot-1`부터 `splash-club-save-v2-slot-10`까지. 선수 정보에 `version: 2`, `day`, `energy`, `buffs: [{id, remaining}]`를 포함한다. 데이터 검사 및 저장 실패 안내를 제공한다.
- 1번 슬롯이 비어 있으면 기존 `splash-club-save-v1`을 읽어 변환한다. 기존 선수·코인·장비·레벨·경험치·플레이 횟수는 유지하며 활력 60, 1일째, 부스트 없음으로 시작한다. 기존 50m 최고 기록만 초기화하여 새 100m 기록과 섞이지 않게 한다. 원본 v1 키는 삭제하거나 수정하지 않는다.
- 저장은 같은 브라우저·주소에서 사용한다. 브라우저 데이터 삭제 시 저장도 삭제된다.

| 장소 | 제공 기능 |
|---|---|
| 집 | 10슬롯 저장, 일지, 활력·날짜·부스트, 7가지 생활 활동 |
| 상점 | 100종 장비 구매·장착, 부위·내 장비 필터, 페이지 이동 |
| 수영연습장 | 혼자 50m 수영, 경험치·코인·활력 30 획득 |
| 수영경기장 | AI 4명과 100m 경기, 경험치·코인·활력 50 획득 |

### 활력과 생활 활동

활력은 수영을 **완주했을 때** 채워지며 100을 넘지 않는다. 포기에는 코인·경험치·활력 보상이 없다. 활력이나 코인이 0이어도 수영은 무료로 시작할 수 있다. 활동 버튼에는 활력 비용과 부스트 효과를 미리 표시하며, 활력이 부족하면 비활성화한다. 집 활동에는 코인을 소모하지 않는다.

| 활동 | 활력 | 일시 효과 |
|---|---:|---|
| 먹기 | 15 | 추진력 +0.040 |
| 자기 | 20 | 기본 속도 +0.025 m/s, 날짜 +1 |
| TV 보기 | 10 | 안정성 +0.040 |
| 태블릿 보기 | 12 | 추진력 +0.035 |
| 목욕하기 | 15 | 기본 속도 +0.020 m/s |
| 놀기 | 12 | 추진력 +0.030 |
| 쉬기 | 8 | 안정성 +0.035 |

- 모든 부스트는 다음 수영 **3회**에 적용된다. 같은 활동을 다시 하면 효과가 배로 쌓이지 않고 남은 횟수를 3회로 갱신한다. 다른 활동의 효과는 함께 적용한다.
- 수영 시작 시 현재 부스트를 경기용 스탯에 반영하고 횟수를 1 줄여 저장한다. 마지막 1회도 해당 수영이 끝날 때까지 효과가 유지된다. 중단·재시작해도 사용한 횟수는 돌아오지 않는다. 실시간 대기나 일시정지는 추가로 소모하지 않는다.
- 자기는 즉시 다음 날로 이동한다. 다른 활동은 날짜를 변경하지 않으며, 수면으로 활력이 자동 회복되지는 않는다.
- 집에 날짜·활력 게이지·남은 부스트를 표시하고, 결과에 실제로 회복된 활력을 표시한다.

### 성장과 100종 장비

- 다음 레벨 경험치: `80 + (현재 레벨 - 1) × 40`, 최대 Lv.20.
- 레벨업마다 기본 속도 +0.012m/s, 추진력 +0.012, 안정성 +0.008.
- 연습 보상: 경험치 `25 + 반올림(정확도 × 0.35)`, 코인 `15 + 반올림(정확도 × 0.15)`.
- 대회 보상: 경험치 `45 + (5 - 순위) × 12 + 반올림(정확도 × 0.25)`, 코인 `25 + (5 - 순위) × 15`.
- 완주 결과 보상은 한 번만 지급한다.
- 수영모·수영복·물갈퀴·수영안경 각 25종, 총 100종. 구름, 딸기, 복숭아, 레몬, 민트, 라벤더, 하늘, 무지개, 별빛, 달빛, 오리, 토끼, 고양이, 곰돌이, 수달, 돌고래, 조개, 산호, 진주, 물방울, 벚꽃, 해바라기, 솜사탕, 오로라, 은하수 테마를 쓴다. 기존 4종의 ID·가격·효과는 유지한다.
- 각 부위의 0~24번째 아이템 가격은 `기존 가격 + 순번 × 20`. 5개씩 1~5단계로 나뉜다. 이름·색상·단계·가격·수치를 표시한다.
- 기본 수영모: 80코인, 안정성 +0.04. 수영복: 140코인, 속도 +0.04m/s. 물갈퀴: 180코인, 추진력 +0.12. 수영안경: 100코인, 안정성 +0.06.
- 다음 단계마다 수영복은 속도 +0.008m/s, 나머지는 해당 스탯 +0.015를 추가한다. 단계 내 테마 선택은 취향에 따른다.
- 구매하면 같은 부위의 기존 장비를 해제하고 새 장비를 장착한다. 해제한 장비는 소유 목록에 남는다. 부위마다 한 개, 총 네 개만 장착 가능하다. 보너스 무제한 누적 및 중복 구매를 막는다.
- 상점은 전체·부위·내 장비 필터와 페이지당 12개 목록을 제공한다. 선수의 고유 수영복 색은 유지하며, 부위별 장착 표현을 사용한다.

### 검증 기준

- 10개 슬롯을 각각 저장·복구하고 덮어쓰기와 복사 저장이 다른 슬롯을 변경하지 않는다.
- 기존 저장 변환, 손상된 슬롯 격리, 저장 실패, 날짜·활력·부스트의 재로딩을 검증한다.
- 총 100개의 고유 ID와 이름, 부위별 25종, 장착 교체 및 잔액 부족을 검증한다.
- 모든 활동의 활력 비용 및 코인 미소모, 수면의 날짜 변경, 부스트 갱신·중첩·3회 만료를 검증한다.
- 수영 완주 활력 회복, 상한 100, 무료 입장, 포기 시 무보상을 검증한다.
- 판정 경계 ±140/240/320ms, 인접 노트 선택, 중복 판정 방지, 길어진 경기 전체의 노트 생성을 검증한다.

### 독립 상점 화면

마을의 상점 건물 또는 이동 메뉴의 상점 버튼으로 입장한다. 집에서는 생활 활동과 저장을 제공하고, 아이템 구매·장착은 상점에서 제공한다. 상점 안에서 필터 변경·페이지 이동·구매·장착을 해도 상점 화면을 유지한다. 마지막 장소가 상점인 저장은 이어하기 시 상점으로 복귀한다.

### 생활 부스트 표시와 즉시 종료

- 연습·대회 화면에 시작 시 적용한 생활 부스트의 활동명·효과·이번 수영 이후 남은 횟수를 표시한다. 마지막 1회도 이번 수영이 끝날 때까지 표시하고 적용한다. 부스트가 없으면 없다는 안내를 표시한다.
- 플레이어가 결승선을 통과하는 즉시 수영을 종료하고 결과·보상을 표시한다. 다른 선수의 완주를 기다리지 않는다.
- 플레이어보다 먼저 완주한 선수만 순위 계산에 포함한다. 완주자의 기록은 0.01초 단위 공동 순위 규칙을 유지한다. 아직 완주하지 않은 AI는 결과에 순위 대신 ‘—’, 기록 대신 ‘미완주’로 표시한다. 미완주 기록은 추정하거나 0초로 계산하지 않는다.
