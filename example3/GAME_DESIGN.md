## 1. 게임 개요

정원 소녀 모모를 조작해 움직이는 검은 발판을 피하고, 아이템과 동물 친구의 도움으로 모든 파스텔 발판을 누르는 1인용 웹게임이다. 1~10단계를 차례로 진행하며 게임판과 위험 요소가 단계마다 커진다.

| 항목 | 현재 규칙 |
| --- | --- |
| 장르 | 격자 이동 기반 캐주얼 회피·수집 |
| 플랫폼 | PC·모바일 웹브라우저 |
| 목표 | 각 단계의 모든 기본 발판 방문, 10단계 최종 완료 |
| 시작 라이프 / 최대 라이프 | 10 / 10 |
| 실패 조건 | 라이프 0 |
| 제한 시간 | 없음. 누적 플레이 시간만 기록 |
| 저장 | 브라우저 최고 점수와 소리 설정 |

## 2. 스테이지와 난이도

| 스테이지 | 게임판 크기 | 기본 발판 수 | 검은 발판 수 | 검은 발판 이동 간격 |
| --- | --- | ---: | ---: | ---: |
| 1 | 7 × 7 | 49 | 3 | 1.00초 |
| 2 | 9 × 9 | 81 | 5 | 0.93초 |
| 3 | 11 × 11 | 121 | 7 | 0.86초 |
| 4 | 13 × 13 | 169 | 9 | 0.79초 |
| 5 | 15 × 15 | 225 | 11 | 0.72초 |
| 6 | 17 × 17 | 289 | 13 | 0.65초 |
| 7 | 19 × 19 | 361 | 15 | 0.58초 |
| 8 | 21 × 21 | 441 | 17 | 0.51초 |
| 9 | 23 × 23 | 529 | 19 | 0.44초 |
| 10 | 25 × 25 | 625 | 21 | 0.37초 |

- 한 변은 단계마다 2칸, 검은 발판은 2개씩 증가한다. 검은 발판의 이동 간격은 단계마다 0.07초씩 줄어든다.
- 캐릭터는 매 단계 중앙에서 시작한다. 시작 칸은 방문 처리하지만 점수는 지급하지 않는다. 새 게임은 방문 수 1/49, 점수 0, 라이프 10으로 시작한다.
- 초기 검은 발판은 캐릭터 주변 가로·세로 각각 2칸 범위 밖에 서로 겹치지 않게 배치한다.
- 1~9단계 완료 시 시뮬레이션을 멈추고 다음 단계 시작 버튼을 표시한다. 자동으로 다음 단계로 넘어가지 않는다.
- 다음 단계 시작 시 라이프를 10개로 모두 회복한다. 누적 점수·총 플레이 시간은 유지한다. 맵 방문 기록, 캐릭터 위치, 아이템, 동물, 도토리, 활성 효과, 피해 무적, 이동 예고와 생성 타이머는 초기화한다.
- 10단계 완료 시 최종 승리하고 정원 엔딩을 표시한다. 결과 화면에서 재시작하거나 처음 화면으로 돌아갈 수 있다. 재시작은 항상 1단계부터다.

## 3. 조작과 시간

- PC: 방향키 또는 WASD로 상하좌우 이동, Esc로 일시정지·재개.
- 모바일: 화면 아래 방향 패드로 이동, 별도 버튼으로 일시정지·재개.
- 한 번 누르면 한 칸, 누르고 있으면 초당 최대 6칸 이동한다. 여러 방향 입력 시 마지막 방향을 사용하며 대각선 이동과 맵 밖 이동은 허용하지 않는다.
- 캐릭터 그림은 부드럽게 보간하지만 이동·충돌·방문 판정은 격자 기준이다.
- 시간은 활성 플레이 시간으로 계산한다. 일시정지, 창 포커스 이탈, 탭 비활성화 시 입력을 비우고 게임을 멈춘다. 복귀 후 재개해야 진행된다.
- 일시정지·단계 완료·최종 결과 화면에서는 이동, 아이템 생성·노출·효과, 동물, 도토리, 피해 무적 및 총 플레이 시간이 모두 멈춘다.

## 4. 발판과 피해

### 파스텔 발판

기본 발판은 각 칸의 방문 여부를 따로 저장한다. 처음 누르면 꺼진 색과 완료 표시로 바뀌며, 사라지거나 구멍이 되지 않는다. 재방문은 안전하고 점수·진행도를 중복 지급하지 않는다. 색상별 기능 차이는 없다.

검은 발판과 아이템은 기본 발판 위에 놓이는 별도 요소다. 이동하거나 사라져도 아래 발판의 방문 기록과 전체 목표 수는 바뀌지 않는다.

### 검은 발판

- 단계별 간격에 따라 유효한 상하좌우 중 무작위로 한 칸 이동한다. 이동 0.2초 전에 목적지를 예고한다.
- 맵 밖, 다른 검은 발판의 현재 칸, 바닥 아이템이 있는 칸으로는 이동하지 않는다. 이미 방문한 칸으로는 이동할 수 있다.
- 목적지가 겹치면 하나만 이동하고 나머지는 대기한다. 서로 자리 바꾸기는 허용하지 않으며 유효한 방향이 없을 때도 대기한다.
- 캐릭터가 활성 검은 발판을 직접 밟거나 발판이 캐릭터에게 접근하면 라이프가 1 줄고 1초간 피해 무적이 된다. 계속 겹치면 피해 무적 종료 후 다시 피해를 받는다.
- 피해 무적이나 실드는 피해만 막는다. 활성 검은 발판 아래의 직접 방문 처리는 황금 모드일 때만 가능하다.
- 부스터의 주변 칸 누르기, 토끼, 도토리로 무력화된 발판은 아래의 별도 규칙을 따른다.

## 5. 아이템 공통 규칙

| 아이템 | 표시 | 생성 간격 | 바닥 노출 시간 | 획득 효과 |
| --- | --- | ---: | ---: | --- |
| 황금 보너스 | ✦ | 일반 상태 15초 | 3초 | +100점, 5초 황금 모드 |
| 회복 하트 | ♥ | 10초 | 10초 | 라이프 +1, 최대 10 |
| 부스터 | ⚡ | 25초 | 10초 | 10초 동안 십자 범위 누르기 |
| 토끼 | 🐰 | 30초 | 10초 | 토끼 한 마리, 30초 활동 |
| 실드 | 🛡 | 25초 | 10초 | 10초 무적 |
| 다람쥐 | 🐿 | 35초 | 10초 | 다람쥐 한 마리, 30초 활동 |

- 각 단계 시작부터 생성 시간을 센다. 각 종류는 바닥에 최대 하나씩 존재하며, 종류가 다르면 동시에 등장할 수 있다.
- 캐릭터, 검은 발판, 이동 예고 목적지, 다른 아이템, 현재 동물 위치를 제외한 무작위 칸에 생성한다. 이미 방문한 칸에도 등장한다. 빈 칸이 없으면 해당 생성은 건너뛴다.
- 캐릭터가 직접 같은 칸에 들어가야 획득한다. 부스터의 주변 누르기나 동물 이동으로 아이템을 획득하지 않는다.
- 획득하지 못하면 노출 시간 후 사라진다. 획득이 다음 생성 시각을 앞당기지는 않는다.
- 황금 보너스 외 아이템은 황금 모드 중에도 생성된다. 여러 효과와 두 동물은 동시에 유지할 수 있다.
- 부스터·실드는 재획득 시 획득 시점부터 10초로 갱신한다. 토끼·다람쥐는 개체 수를 늘리지 않고 캐릭터 위치에서 30초로 갱신한다.
- 황금 보너스 외에는 획득 자체의 점수가 없다. 아이템 아래 미방문 발판의 점수는 방문 규칙대로 별도 지급한다.

### 5.1 황금 보너스

획득 즉시 +100점과 5초 황금 모드를 적용한다. 모든 기본 발판이 황금빛으로 변하며 활성 검은 발판 아래도 피해 없이 방문할 수 있다. 첫 방문 점수는 칸당 +20점이다. 검은 발판은 계속 단계별 속도로 이동하고, 도토리가 올라간 발판은 정지 상태를 유지한다.

황금 모드 중 새 황금 보너스는 생성하지 않는다. 효과 종료 후 15초부터 다음 생성을 센다. 종료 1초 전 경고를 표시하고, 종료 순간 활성 검은 발판 위에 있으면 1초 피해 유예를 준다. 기존 방문 기록은 유지한다.

### 5.2 회복 하트

10초마다 생성한다. 획득 시 라이프 1개를 회복하되 10개를 넘지 않는다. 라이프가 가득 차 있어도 획득한 하트는 사라진다. 미획득 하트는 10초 뒤 사라지고 다음 생성 주기로 이어진다.

### 5.3 부스터

회복 아이템과 구분하도록 번개 아이콘을 사용한다. 획득 후 10초 동안 캐릭터 칸과 상하좌우, 최대 5칸을 함께 누른다. 대각선과 맵 밖은 포함하지 않는다.

- 주변 검은 발판 아래도 방문 처리하며 주변 칸 때문에 피해를 받지 않는다.
- 캐릭터가 직접 서 있는 칸의 피해와 방문 제한은 기존 규칙대로 적용한다. 부스터 자체는 무적 효과가 아니다.
- 각 미방문 칸에 일반 +10점, 황금 모드 +20점을 지급하며 중복 채점하지 않는다.
- 현재 십자 범위와 효과 남은 시간을 표시한다.

### 5.4 토끼

획득하면 캐릭터 위치에서 토끼가 나타나 30초 동안 1초마다 한 칸 이동한다. 유효한 상하좌우 중 미방문 칸을 우선 선택하고, 그런 칸이 없으면 유효한 이웃 칸 중 무작위로 이동한다.

토끼가 도착한 발판은 방문 처리한다. 검은 발판 위에서도 페널티 없이 아래 발판을 누르고, 일반 +10점 또는 황금 모드 +20점을 지급한다. 이미 방문한 칸은 중복 점수가 없다. 토끼는 부스터 범위를 적용받지 않으며 아이템을 수집하지 않는다. 토끼가 마지막 미방문 칸을 누르면 단계가 완료된다.

### 5.5 실드

획득 후 10초 동안 캐릭터의 피해를 막는다. 보호막과 남은 시간을 표시한다. 점수 배수, 발판 색 변경, 활성 검은 발판 아래의 직접 방문 권한은 추가하지 않는다. 황금 모드·부스터·동물 효과와 독립적으로 함께 작동한다.

실드 자체에는 종료 시 피해 유예가 없다. 종료 후에는 다른 무적 효과가 남아 있지 않으면 일반 피해 규칙을 즉시 적용한다.

### 5.6 다람쥐와 도토리

획득하면 캐릭터 위치에서 다람쥐가 나타나 30초 동안 1초마다 한 칸 이동한다. 가까운 활성 검은 발판까지의 거리가 줄어드는 방향을 우선하며, 활성 검은 발판이 없으면 유효한 이웃 칸 중 무작위로 이동한다.

- 다람쥐는 일반 발판과 검은 발판 모두 방문 처리하지 않으며 점수도 얻지 않는다. 아이템을 수집하지 않는다.
- 다람쥐가 검은 발판에 도착하거나 검은 발판이 다람쥐에게 이동해 오면 도토리를 올린다.
- 도토리는 해당 발판의 이동과 피해를 15초 동안 막는다. 이미 예고된 이동도 취소하며, 다른 검은 발판은 그 칸으로 이동하지 못한다.
- 무력화된 검은 발판 아래는 캐릭터가 안전하게 방문할 수 있다. 발판 위에 도토리와 남은 초를 표시한다.
- 도토리 효과가 유지되는 동안 시간을 계속 갱신하지 않는다. 만료되면 피해가 다시 활성화되고 이동 주기에 따라 움직인다. 이후 다람쥐와 다시 만나면 새 도토리를 올릴 수 있다.
- 다람쥐가 사라져도 기존 도토리는 남은 시간 동안 유지된다. 단계 전환·재시작 시에는 모두 제거한다.

## 6. 점수와 승패

| 행동 | 점수 |
| --- | ---: |
| 일반 상태에서 미방문 칸 누르기 | 칸당 +10 |
| 황금 모드에서 미방문 칸 누르기 | 칸당 +20 |
| 황금 보너스 획득 | +100 |
| 재방문·다람쥐 이동·도토리 설치 | 0 |
| 10단계 최종 승리 | 남은 라이프당 +100 |

- 토끼와 부스터도 같은 방문 점수를 사용한다. 황금 모드의 +20은 일반 +10을 대체한다.
- 미방문 칸에서 황금 보너스를 얻으면 획득 +100과 해당 칸 +20을 함께 지급한다.
- 피해에 따른 점수 차감은 없다. 1~9단계 완료에는 남은 라이프 보너스를 지급하지 않는다.
- 라이프 0이면 즉시 게임오버다. 같은 갱신에서 방문 완료 가능성이 있어도 치명적 피해가 먼저 발생하면 게임오버가 우선한다.
- 결과 화면에 누적 점수, 총 플레이 시간, 남은 라이프, 현재 단계의 방문 수를 표시한다. 최종 승리·게임오버에서 최고 점수를 갱신한다.

## 7. 화면 구성과 음향

### 게임 화면

- 현재 단계와 게임판 크기, 하트, 점수, 누적 시간, 일시정지·음소거 버튼을 표시한다.
- PC는 현재 단계의 전체 게임판을 보여준다. 모바일은 최대 11 × 11칸 시점으로 캐릭터를 따라가며, 작은 단계는 전체를 보여준다.
- 모바일 미니맵은 현재 게임판 크기에 맞춰 방문 상태, 검은 발판, 아이템, 동물, 카메라와 캐릭터 위치를 표시한다. 무력화된 발판은 별도 색상으로 구분한다.
- 바닥 아이템은 노출 시간 게이지를 표시한다. 모바일에서 화면 밖 아이템은 가장자리 표시로 위치를 알린다.
- 황금·부스터·실드·토끼·다람쥐의 남은 시간은 게임판 아래 별도 ‘사용 중인 아이템’ 영역에 표시한다. PC·모바일 모두 발판을 가리지 않으며 여러 효과는 자동으로 줄바꿈한다. 실드는 캐릭터 보호막, 부스터는 십자 범위를 함께 보여준다.
- 하단에 방문 수/전체 수와 진행률을 표시한다. 마지막 미방문 칸이 10개 이하이면 테두리를 강조한다.
- 아이템 등장·획득·효과 종료·피해·도토리 설치를 짧은 알림과 효과음으로 알린다.

### 오른쪽 간소 안내

하나의 ‘효과 한눈에 보기’ 목록에 아이콘·이름·핵심 효과를 표시한다. 생성 주기 등의 긴 설명은 생략한다.

| 항목 | 안내 |
| --- | --- |
| 파스텔 발판 | 처음 밟으면 +10점 |
| 검은 발판 | 닿으면 하트 −1, 현재 개수·이동 간격 |
| 황금 | 5초 무적 · 방문 점수 2배 |
| 회복 하트 | 라이프 +1 · 최대 10개 |
| 부스터 | 10초 동안 상하좌우도 함께 누르기 |
| 토끼 | 30초 동안 발판 대신 누르기 |
| 실드 | 10초 동안 피해 방어 |
| 다람쥐 | 30초 활동 · 검은 발판 15초 정지·무피해, 발판은 누르지 않음 |

별도로 황금 보너스 상태·카운트다운과 개인 최고 점수를 표시한다.

### 시각·음향

밝은 파스텔 정원과 오리지널 캐릭터 모모를 사용한다. 완료 표시, 위험 느낌표, 아이템 모양과 색을 함께 사용해 상태를 구분한다.

발판 이동·새 방문에는 짧고 귀여운 ‘뾱뾱’ 소리를 재생한다. 부드러운 음높이가 빠르게 올라갔다 내려가고 걸음마다 약간 달라진다. 초기 효과음보다 볼륨을 높였으며, 같은 갱신에서 여러 칸이 눌려도 발판 소리는 한 번만 재생한다. 피해·획득·완료에는 별도 효과음이 있다. 사용자의 시작 입력 이후 오디오를 활성화하며 음소거와 움직임 줄이기 설정을 지원한다.

## 8. 구현 구조와 판정 순서

외부 라이브러리 없이 HTML·CSS·JavaScript, Canvas 2D, Web Audio로 구현한다. index.html을 직접 열거나 선택적 로컬 서버 serve.cjs로 실행할 수 있다.

| 파일 | 역할 |
| --- | --- |
| engine.js | 설정값, 단계, 이동·충돌·방문, 아이템·동물·도토리, 점수·승패 |
| game.js | 화면 렌더링, 입력, 카메라·미니맵, 효과음, 로컬 저장 |
| index.html / styles.css | 한국어 UI, 간소 안내, 반응형 배치 |
| character.svg | 모모 캐릭터 |
| engine.test.cjs | 게임 규칙 자동 검증 |
| serve.cjs | 선택적 로컬 미리보기 서버 |

게임 상태는 시작 전, 플레이 중, 일시정지, 단계 완료, 최종 승리, 게임오버로 구분한다. 로컬 저장소에 접근할 수 없어도 게임은 동작한다. 진행 중인 게임을 저장·복원하는 기능, 로그인, 서버 랭킹, 멀티플레이는 현재 구현 범위에 포함하지 않는다.

한 번의 규칙 갱신은 다음 순서로 처리한다.

1. 활성 시간 증가 및 효과·아이템·동물 만료 처리.
2. 다람쥐 이동·도토리 설치, 검은 발판 예고·이동, 이동 후 다람쥐 접촉 처리.
3. 아이템 생성, 캐릭터 이동, 직접 획득 효과 적용.
4. 캐릭터 피해 판정. 라이프 0이면 즉시 종료.
5. 캐릭터·부스터 방문 처리, 토끼 이동·방문 처리.
6. 전체 방문 여부에 따라 단계 완료 또는 최종 승리 판정.

## 9. 검증 현황

현재 규칙 테스트 33개가 통과한 상태다. 자동 검증과 별개로 실제 기기의 체감 음량·음색과 화면 배치는 플레이 테스트에서 확인한다.

| 검증 영역 | 확인 내용 |
| --- | --- |
| 단계 진행 | 10개 맵 크기·위험 개수·속도, 상태 승계, 최종 승리 |
| 이동·방문 | 경계, 입력 속도, 첫 방문·재방문 점수 |
| 위험 발판 | 직접 접촉·접근 피해, 무적, 예고, 겹침·경계 방지 |
| 황금 | 생성·소멸, 점수, 무적, 종료 유예 |
| 회복 | 10초 생성, 회복 상한, 중복 획득 방지 |
| 부스터 | 십자 범위, 주변 위험 무피해, 가장자리, 황금 병용 |
| 토끼 | 생성·소멸, 1초 이동, 30초 활동, 위험 칸 방문, 단계 완료 |
| 실드 | 10초 피해 방어, 갱신, 종료, 다른 효과와의 병용 |
| 다람쥐·도토리 | 1초 이동, 방문·점수 없음, 예고 취소, 접근 접촉, 15초 정지·무피해 및 복구 |
| 공통 수명 | 일시정지, 단계 전환, 재시작 초기화 |

검증 명령은 example3 폴더에서 실행한다.

```powershell

node --check engine.js
node --check game.js
```

## 10. 정원 엔딩

- 10단계의 모든 발판을 방문하면 모모와 토끼, 다람쥐가 꽃밭에서 공을 가지고 함께 노는 애니메이션을 표시한다. 동물 아이템의 활성 여부와 관계없이 세 친구가 모두 등장한다.
- 정원에는 꽃, 나비, 울타리와 햇살을 배치하며 캐릭터의 움직임과 공의 이동을 반복한다. 움직임 줄이기 설정에서는 정지 장면을 표시한다.
- 실제 클리어에서는 최종 점수·시간·남은 라이프·방문 수와 재시작·처음으로 버튼을 함께 표시한다.
- 검토용으로 URL에 ?ending=preview를 붙이면 같은 엔딩 장면을 바로 볼 수 있다. 미리보기는 게임 상태나 최고 점수를 조작하지 않으며 결과 수치를 숨기고 미리보기임을 표시한다.
