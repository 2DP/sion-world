# 웹게임 기획서 — 파스텔 스텝 (가제)

> 상태: 최초 기획안
> 작성일: 2026-09-27
> 목표: 귀여운 여자 캐릭터를 조작해 움직이는 검은색 발판을 피하면서 모든 파스텔 발판을 밟는 웹게임.
> 사용자가 지정한 핵심 규칙을 기준으로 작성했으며, 미지정 수치와 세부 동작은 구현을 위한 초기 제안이다.

## 1. 게임 개요

| 항목 | 기획 |
| --- | --- |
| 장르 | 격자 이동 기반 캐주얼 회피·수집 게임 |
| 플랫폼 | PC 및 모바일 웹브라우저 |
| 플레이 | 1인 플레이 |
| 기본 맵 | 25 × 25칸, 총 625칸 |
| 캐릭터 | 파스텔 의상과 큰 표정이 특징인 귀여운 여자 캐릭터 |
| 목표 | 모든 파스텔 발판을 한 번 이상 밟기 |
| 실패 | 라이프 10개를 모두 잃으면 게임오버 |
| 제한 시간 | 없음. 경과 시간은 기록용으로 표시 |

핵심 재미는 아직 밟지 않은 발판까지 가는 경로를 찾고, 매초 움직이는 검은색 발판을 피하다가, 짧게 나타나는 황금색 보너스로 안전하게 진행하는 데 있다.

## 2. 확정할 핵심 규칙

- 파스텔 발판은 처음 밟으면 꺼진다.
- 검은색 발판은 밟으면 라이프를 깎는다.
- 라이프는 10개이며, 0개가 되면 게임오버다.
- 검은색 발판은 1초마다 무작위 방향으로 이동한다.
- 황금색 보너스 발판은 잠깐 나타났다가 사라진다.
- 황금색 보너스를 밟으면 모든 발판이 일시적으로 황금색이 되고 안전하게 밟을 수 있으며 점수가 오른다.
- 모든 파스텔 발판을 밟으면 승리한다. 검은색 발판 자체는 별도의 수집 대상이 아니다.

## 3. 맵과 발판 구조

검은색 발판 이동 때문에 목표 발판이 사라지거나 승리 조건이 바뀌지 않도록, 각 칸의 기본 발판과 그 위의 위험·보너스를 구분한다.

- 기본 맵의 625칸은 모두 파스텔 발판이며, 각각 방문 여부를 저장한다.
- 검은색 발판은 기본 발판 위를 이동하는 위험 요소다. 이동해도 아래 칸의 방문 여부는 유지된다.
- 황금색 보너스는 한 칸 위에 잠시 나타나는 획득 요소다.
- 캐릭터 시작 칸은 게임 시작과 함께 방문 처리한다. 진행도는 1/625에서 시작하며 시작 칸 점수는 지급하지 않는다.
- 검은색 발판이 덮고 있는 미방문 칸도 최종 방문 대상이다. 검은색 발판이 이동한 뒤 방문하거나 황금 효과 중 방문할 수 있다.

### 3.1 파스텔 발판

- 연분홍, 민트, 연보라, 하늘색, 크림색 등을 사용한다. 색상별 기능 차이는 없다.
- 처음 안전하게 밟으면 짧게 빛난 뒤 어두운 저채도 색상으로 꺼진다.
- 꺼진 발판은 사라지거나 구멍이 되지 않는다. 이후에도 안전하게 이동할 수 있다.
- 꺼진 발판을 다시 밟아도 진행도나 방문 점수를 중복 지급하지 않는다.
- 초기 상태와 꺼진 상태는 테두리와 표시도 다르게 하여 색상 외에도 구분할 수 있게 한다.

### 3.2 검은색 발판

- 초기 제안: 기본 맵에 12개 배치한다.
- 시작 칸과 그 주변 2칸 이내에는 배치하지 않는다.
- 매 1초마다 상·하·좌·우 중 유효한 방향을 무작위로 골라 한 칸 이동한다. 대각선 이동은 없다.
- 맵 바깥, 다른 검은색 발판, 황금색 보너스가 있는 칸으로는 이동하지 않는다.
- 여러 검은색 발판이 같은 목적지를 선택하면 하나만 이동하고 나머지는 해당 주기에 대기한다. 서로 자리를 맞바꾸는 이동도 허용하지 않는다.
- 유효한 방향이 없으면 해당 주기에 대기한다.
- 이미 꺼진 칸 위로도 이동할 수 있다.
- 캐릭터가 검은색 발판에 들어가거나 검은색 발판이 캐릭터 위치로 이동하면 라이프 1개를 잃는다.
- 피해 직후 1초간 무적 상태가 되어 중복 피해를 막는다. 계속 겹쳐 있으면 무적이 끝난 뒤 다시 피해를 받으므로 빠져나와야 한다.
- 일반 상태에서 검은색 발판이 덮은 칸을 밟으면 아래 파스텔 발판의 방문 처리는 하지 않는다. 피해 무적 중에도 동일하다.
- 이동 0.2초 전에 목적지에 작은 테두리 예고를 표시한다.

### 3.3 황금색 보너스 발판

- 초기 제안: 일반 상태에서 15초마다 하나 생성하며, 3초 동안 유지한다.
- 캐릭터나 검은색 발판이 없는 칸 중 무작위로 생성한다. 꺼진 칸에도 생성할 수 있다.
- 남은 노출 시간을 원형 게이지로 표시하며, 획득하지 못하면 사라진다.
- 획득 즉시 보너스 점수를 지급하고 5초 동안 황금 모드를 활성화한다.
- 황금 모드 중에는 새 보너스를 생성하지 않으며, 종료 후 15초부터 다음 생성 주기를 센다.

### 3.4 황금 모드

- 파스텔·검은색·꺼진 발판이 모두 황금빛으로 변한다.
- 모든 칸을 피해 없이 밟을 수 있다. 검은색 발판이 덮은 미방문 칸도 정상적으로 방문 처리한다.
- 검은색 발판은 계속 1초마다 이동한다. 황금빛 위에 진한 테두리를 남겨 효과 종료 후 위험 위치를 예상할 수 있게 한다.
- 미방문 칸은 밝은 황금색, 방문 완료 칸은 어두운 황금색과 완료 표시로 구분한다.
- 효과가 끝나면 원래 발판 표현으로 돌아온다. 황금 모드 중 방문한 칸은 꺼진 상태로 유지한다.
- 종료 1초 전부터 화면 타이머와 효과음으로 알린다.
- 종료 순간 검은색 발판 위에 있으면 1초의 피해 유예를 제공한다. 그 이후에도 겹쳐 있으면 일반 피해 규칙을 적용한다.
- 황금 모드는 기존 방문 기록을 초기화하거나 꺼진 발판을 새 점수 대상으로 만들지 않는다.

## 4. 캐릭터와 조작

- 둥근 실루엣, 큰 눈, 작은 리본, 파스텔 의상을 가진 오리지널 여자 캐릭터를 사용한다.
- 대기, 이동, 피해, 황금 보너스 획득, 승리, 게임오버 상태를 표정과 동작으로 보여준다.
- PC: 방향키 또는 WASD로 상·하·좌·우 이동, Esc로 일시정지.
- 모바일: 화면 하단 방향 패드로 이동하고 별도 일시정지 버튼을 제공한다.
- 한 번 누르면 한 칸 이동하며, 누르고 있으면 초당 최대 6칸 이동한다.
- 대각선 이동은 지원하지 않는다. 여러 방향을 누르면 마지막 입력 방향을 적용한다.
- 맵 밖으로 나가는 입력은 무시한다.
- 움직임은 부드럽게 보간하되 판정은 격자 칸 단위로 처리한다.

## 5. 점수와 승패

다음 점수는 초기 제안값이다.

| 행동 | 점수 |
| --- | ---: |
| 일반 상태에서 미방문 발판 첫 방문 | +10 |
| 황금색 보너스 획득 | +100 |
| 황금 모드에서 미방문 발판 첫 방문 | +20 |
| 방문 완료 발판 재방문 | 0 |
| 승리 시 남은 라이프 | 1개당 +100 |

- 황금 모드 방문 점수 +20은 일반 +10을 대체한다.
- 미방문 칸에서 보너스를 획득하면 황금 모드를 먼저 활성화하고, 획득 +100과 첫 방문 +20을 함께 지급한다.
- 피해에 따른 별도 점수 차감은 없다.
- 방문 완료 수가 전체 기본 발판 수에 도달하면 즉시 승리한다.
- 라이프가 0이 되면 즉시 게임오버다.
- 같은 게임 갱신에서 이동과 효과 종료가 겹치면 효과 만료 → 이동 및 보너스 획득 → 피해 → 안전한 발판 방문 → 승패 순으로 처리한다. 피해로 라이프가 0이 되면 게임오버가 우선한다.
- 결과 화면에서 최종 점수, 경과 시간, 남은 라이프, 방문 수를 보여준다.

## 6. 화면과 플레이 흐름

### 시작 화면

게임 제목, 캐릭터, 시작 버튼, 조작 설명, 세 가지 발판 설명을 표시한다. “검은 발판을 피하고 파스텔 발판을 모두 밝혀보세요!” 대신 실제 동작에 맞게 “파스텔 발판을 모두 밟아 꺼주세요!”라는 안내를 사용한다.

### 플레이 화면

- 상단: 하트 10개, 현재 점수, 방문 수/전체 수, 진행률, 경과 시간, 일시정지 버튼.
- 중앙: 격자 맵과 캐릭터. PC에서는 25 × 25 전체 맵을 기본으로 표시한다.
- 황금 모드 중: 눈에 잘 띄는 남은 시간 게이지와 화면 가장자리의 은은한 황금빛 효과.
- 모바일: 캐릭터를 따라가는 확대 시점과 전체 진행 상황을 보여주는 미니맵, 하단 방향 패드.
- 마지막 미방문 발판이 10개 이하이면 해당 칸의 테두리를 천천히 점멸시켜 찾기 쉽게 한다.

### 플레이 순서

1. 시작 버튼을 누르면 맵을 생성하고 라이프 10개, 점수 0으로 시작한다.
2. 파스텔 발판을 방문하면서 검은색 발판의 이동을 피한다.
3. 황금색 보너스가 나타나면 경로와 남은 시간을 보고 획득을 시도한다.
4. 황금 모드에서 위험한 칸을 안전하게 방문하고 추가 점수를 얻는다.
5. 모든 발판을 방문하면 승리 화면, 라이프를 모두 잃으면 게임오버 화면을 표시한다.
6. 결과 화면에서 다시 시작하거나 시작 화면으로 돌아갈 수 있다.

일시정지 또는 브라우저 탭 비활성화 시 캐릭터, 검은색 발판, 보너스 및 황금 효과 타이머, 경과 시간을 모두 멈춘다. 복귀 시 재개 버튼으로 이어서 플레이한다.

## 7. 시각·음향 방향

- 전체 분위기: 밝고 포근한 파스텔 장난감 정원.
- 맵과 캐릭터의 대비를 확보하고, 캐릭터가 발판 상태를 완전히 가리지 않게 한다.
- 검은색 발판은 둥근 모서리와 작은 위험 아이콘으로 표시한다.
- 황금색 발판에는 반짝임과 별 모양 아이콘을 사용한다.
- 첫 방문에는 가벼운 음, 피해에는 짧은 경고음, 황금 획득에는 맑은 종소리, 승리에는 짧은 팡파르를 사용한다.
- 음소거 버튼을 제공하고, 브라우저 정책에 맞게 사용자의 시작 입력 이후 오디오를 재생한다.
- 화면 흔들림과 강한 점멸은 최소화한다.

## 8. 초기 구현 범위 및 기술 방향

### 1차 구현 범위

- 25 × 25 기본 맵 한 종류와 오리지널 여자 캐릭터 한 명.
- 키보드 및 모바일 방향 패드 조작.
- 방문 상태, 검은색 발판 이동과 피해, 황금 보너스와 효과.
- 점수, 라이프, 진행도, 시작·일시정지·승리·게임오버·재시작 화면.
- 브라우저 로컬 저장소에 최고 점수 저장. 저장 실패 시에도 플레이는 가능하게 한다.
- 서버, 로그인, 온라인 랭킹, 멀티플레이는 후속 확장 항목으로 둔다.

### 구현 제안

- HTML, CSS, JavaScript 또는 TypeScript와 Canvas 2D를 사용한다.
- 맵 크기, 위험 발판 수, 이동 간격, 보너스 주기, 효과 시간, 점수를 설정값으로 분리한다.
- 각 칸의 방문 상태와 검은색 발판 위치, 보너스 위치를 별도로 관리한다.
- 게임 상태는 시작 전, 플레이 중, 일시정지, 승리, 게임오버로 구분한다.
- 시간은 프레임 수가 아닌 활성 플레이 시간으로 계산하여 화면 주사율에 따른 차이를 방지한다.
- 재시작 시 입력 상태, 모든 타이머, 보너스, 방문 기록, 점수와 라이프를 초기화한다.

## 9. 검증 기준

| 검증 상황 | 기대 결과 |
| --- | --- |
| 새 게임 시작 | 라이프 10, 점수 0, 방문 수 1/625 |
| 파스텔 발판 첫 방문 및 재방문 | 첫 방문만 꺼지고 진행도와 점수가 증가 |
| 꺼진 칸 통과 | 추락 없이 이동 가능 |
| 검은색 발판에 진입 또는 검은색 발판이 접근 | 라이프 1 감소, 1초 무적 적용 |
| 검은색 발판과 계속 겹침 | 무적 종료 후 다시 피해 발생 |
| 검은색 발판 이동 | 1초마다 유효한 한 칸 이동, 겹침·경계 이탈 없음 |
| 황금 보너스 미획득 | 3초 뒤 사라짐 |
| 황금 보너스 획득 | 점수 증가, 5초 동안 모든 발판 황금색·무피해 |
| 황금 모드에서 위험 칸 방문 | 아래 미방문 발판 방문 처리 및 +20점 |
| 황금 효과 종료 | 기존 방문 기록 유지, 위험 규칙 복구 및 종료 유예 적용 |
| 마지막 목표 방문 | 승리 및 결과 화면 표시 |
| 마지막 라이프 소진 | 게임오버 및 플레이 중단 |

## 10. 플레이 테스트에서 조정할 항목

25 × 25 맵은 이동량이 많으므로 첫 구현 후 완료 시간과 피로도를 확인한다. 초기 검은색 발판 수 12개, 캐릭터 이동 속도 초당 6칸, 보너스 주기 15초, 노출 3초, 황금 효과 5초를 우선 적용하고 난이도를 조정한다. 작은 연습 맵이나 여러 난이도는 기본 규칙 검증 후 추가할 수 있다.
