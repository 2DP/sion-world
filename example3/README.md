# 파스텔 스텝 · Pastel Step

귀여운 정원 소녀 모모와 25 × 25칸을 산책하는 브라우저 게임입니다.

## 실행

이 폴더의 `index.html`을 브라우저에서 열면 바로 실행됩니다. 외부 라이브러리, 빌드, 서버, 네트워크 연결이 필요하지 않습니다.

로컬 HTTP 미리보기를 원하면 이 폴더에서 다음 명령을 실행하세요.

```powershell
node serve.cjs
```

브라우저에서 http://127.0.0.1:8133 을 엽니다. 서버는 로컬 주소에만 바인딩됩니다. 종료는 Ctrl+C입니다.

정적 호스팅에서는 이 폴더를 그대로 제공하면 됩니다. 저장소 루트 기준 경로는 `/example3/`입니다.

## 조작과 규칙

- **방향키 / WASD**: 한 칸 이동. 누르고 있으면 초당 최대 6칸 이동합니다.
- **모바일 방향 패드**: 누르면 이동하고, 꾹 누르면 계속 이동합니다.
- **Esc / 일시정지 버튼**: 일시정지 또는 재개. 탭을 벗어나면 자동으로 멈춥니다.
- **음표 버튼**: 효과음 켜기/끄기.
- 파스텔 발판은 첫 방문 시 꺼지고 +10점. 꺼진 칸도 안전하게 지날 수 있습니다.
- 12개의 검은색 발판이 매초 무작위 방향으로 이동합니다. 닿으면 하트 1개가 줄고 1초간 피해를 받지 않습니다.
- 황금 발판은 일반 상태에서 15초마다 등장해 3초 후 사라집니다.
- 황금 발판을 밟으면 +100점, 5초 동안 무적이며 첫 방문 점수가 +20점이 됩니다.
- 황금 모드 종료 시 검은 발판 위에 있다면 1초 동안 빠져나올 시간이 주어집니다.
- 625칸을 모두 방문하면 승리하고 남은 하트당 +100점. 하트 10개를 모두 잃으면 게임오버입니다.
- 최고 점수와 소리 설정을 로컬 저장소에 저장합니다. 저장소 사용이 불가능해도 게임은 동작합니다.
- 모바일은 11 × 11칸 시점으로 캐릭터를 따라가며, 오른쪽 아래에 전체 맵을 표시합니다.

## 파일

- `index.html`, `styles.css`: 한국어 인터페이스와 반응형 화면
- `character.svg`: 직접 제작한 오리지널 캐릭터
- `engine.js`: UI와 분리한 게임 규칙. 상단 DEFAULTS에서 수치 조정
- `game.js`: Canvas 렌더링, 입력, 효과음, 브라우저 저장
- `engine.test.cjs`: Node 기본 테스트 러너로 실행하는 규칙 검증
- `serve.cjs`: 선택적으로 사용하는 로컬 미리보기 서버
- `GAME_DESIGN.md`: 원본 기획서

## 검증

```powershell
node --test engine.test.cjs
node --check game.js
```

경계 이동, 중복 점수 방지, 위험 발판 충돌과 이동, 보너스 수명, 황금 효과 및 종료 유예, 일시정지, 승패, 재시작을 검증합니다.
