# 블록 봄버 · Block Bomber 게임 기획서

> 최초 작성: 2026-10-16 · 업데이트: 2026-10-18 · 버전: v1.1
> 상태: 로컬 구현 완료. 현재 구현 규칙을 정리한 문서다.
> 변경 사항: 단판 1대1 초안을 스테이지마다 컴퓨터가 한 명씩 늘어나는 5단계 생존전으로 확장했다.
> 아이템 확장: 최대 폭발 거리 6칸, 슈퍼 불꽃(+2칸), 1회용 실드 추가. 아이템은 총 5종이다.

## 1. 게임 개요

블록 미로에서 폭탄으로 길을 만들고, 아이템을 모으면서 컴퓨터 상대를 모두 쓰러뜨리는 1인용 웹게임이다. 컴퓨터끼리도 서로 공격하며 자신의 폭탄에도 피해를 받는다. **설치할 위치와 도망갈 길을 함께 생각하는 것**이 핵심이다.

| 항목 | 구현 내용 |
| --- | --- |
| 플랫폼 | PC·모바일 웹브라우저, 정적 HTML·CSS·JavaScript |
| 인원 | 플레이어 1명 + 스테이지별 컴퓨터 1~5명 |
| 진행 | 총 5스테이지, 단계별 제한 시간 180초 |
| 목표 | 플레이어가 생존한 상태에서 모든 컴퓨터 탈락 |
| 난이도 | 쉬움·보통·어려움, 최초 기본값은 쉬움 |
| 분위기 | 민트색 캐릭터, 장난감 블록, 따뜻한 크림·녹색 계열 |
| 게임 위치 | `bomberman/index.html` |
| 진입 | SION WORLD 루트 `index.html`의 블록 봄버 아이콘·카드 |

## 2. 스테이지 진행

| 스테이지 | 이름 | 컴퓨터 수 | 맵 크기 |
| --- | --- | ---: | --- |
| 1 | 첫 번째 불꽃 | 1명 | 13 × 11 |
| 2 | 두근두근 삼각 대결 | 2명 | 13 × 11 |
| 3 | 네 모서리의 소동 | 3명 | 13 × 11 |
| 4 | 넓어진 놀이터 | 4명 | 17 × 13 |
| 5 | 마지막 불꽃 축제 | 5명 | 17 × 13 |

- 시작 화면에서 난이도를 고르고, 해금한 스테이지 중 하나를 선택한다. 처음에는 1단계만 열린다.
- 시작 버튼을 누르면 새 맵을 만들고 3초 카운트다운 후 경기한다.
- 컴퓨터를 모두 쓰러뜨리면 스테이지 클리어 화면을 표시하고 다음 단계를 해금한다. 다음 스테이지 버튼을 눌러 진행한다.
- 5단계에서 모든 컴퓨터를 쓰러뜨리면 최종 우승이다. 1단계부터 다시 하거나 해금된 단계를 골라 재도전할 수 있다.
- 패배·무승부 후에는 같은 스테이지를 새 맵으로 재도전한다. 앞 단계부터 다시 할 필요가 없다.
- 새 경기마다 폭탄·화력·속도를 기본값으로 초기화하고 실드·피격 후 보호를 제거한다. 다음 단계로 아이템을 승계하지 않는다.
- 최고 해금 단계는 난이도와 관계없이 공유하고, 승·패·무승부 기록은 난이도별로 저장한다.

## 3. 맵과 배치

좌상단이 `(0, 0)`인 격자다. 테두리와 내부의 x·y가 모두 짝수인 칸은 고정 벽이다. 나머지 배치 가능 칸 약 55%에 파괴 블록을 놓는다. 블록과 숨은 아이템은 맵 중심 기준 180도 회전 대칭으로 생성한다.

캐릭터는 플레이어 좌상단, 첫 컴퓨터 우하단, 이후 우상단·좌하단·상단 중앙 부근·하단 중앙 부근 순서로 추가한다. 4~5단계 중앙 부근 시작 x좌표는 9다. 실제 맵 크기에 맞춰 경계 안쪽에 놓는다.

각 시작점 주변 3 × 3 영역에서 고정 벽을 제외한 칸과 그 회전 대칭 영역을 비워 둔다. 첫 폭탄을 놓고 모퉁이로 피할 공간이 있으며, 모든 파괴 블록을 제거하면 경기장이 연결된다. 전체 맵을 한 화면에 표시한다.

| 칸 | 이동·폭발 규칙 |
| --- | --- |
| 빈 바닥 | 이동 가능, 폭발 통과 |
| 고정 벽 | 이동 불가, 파괴되지 않고 폭발 차단 |
| 파괴 블록 | 이동 불가, 한 번 맞으면 파괴, 해당 폭발은 뒤로 통과하지 않음 |
| 폭탄 | 원칙적으로 이동 불가, 다른 폭발에 닿으면 즉시 연쇄 폭발 |
| 바닥 아이템 | 밟으면 획득, 노출된 뒤 폭발에 닿으면 소멸 |
| 잔불 | 이동할 수 있지만 실드나 피격 후 보호가 없으면 닿는 즉시 탈락 |

## 4. 조작과 시간

| 기능 | PC | 모바일 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 방향 패드 |
| 폭탄 | Space | 폭탄 놓기 버튼 |
| 일시정지·재개 | Esc / 화면 버튼 | 화면 버튼 |
| 소리·움직임 줄이기 | 화면 버튼 | 화면 버튼 |

- 상하좌우 한 칸 단위 판정이며 그림은 부드럽게 보간한다. 대각선 이동은 없다.
- 키를 누르면 한 번 이동하고 누르고 있으면 속도에 따라 반복한다. 여러 방향은 마지막 입력을 우선한다.
- 짧게 누른 키가 프레임 사이에서 사라지지 않도록 다음 이동 시점까지 최대 0.3초간 보관한다.
- 폭탄은 누른 순간 한 번만 설치한다. 길게 눌러도 반복 설치하지 않는다.
- 모바일에서는 서로 다른 손가락으로 이동과 폭탄을 동시에 조작할 수 있다. 방향 버튼의 터치 영역은 최소 48 × 48px이다.
- 캐릭터끼리는 서로 이동을 막지 않으며 접촉 피해가 없다.
- 일시정지와 창·탭 비활성화에서는 입력을 비우고 모든 게임 시간을 멈춘다. 복귀 후 명시적으로 재개한다.
- 경기 시작 시 경기장으로 스크롤하며, PC에서는 화면 높이에 맞춰 게임판 크기를 제한한다.

## 5. 폭탄과 폭발

| 항목 | 기본값 | 최대값 |
| --- | ---: | ---: |
| 동시 설치 한도 | 1개 | 3개 |
| 폭발까지 | 2초 | 고정 |
| 폭발 거리 | 상하좌우 각각 2칸 | 각각 6칸 |
| 잔불 | 0.4초 | 고정 |
| 이동 속도 | 초당 4칸 | 초당 6칸 |
| 생명 | 보호 없이 1회 피격 시 탈락 | 실드 1회 보관 가능, 부활 없음 |

- 폭발은 중심과 상하좌우의 십자 모양이다. 기본 거리에서 막힘이 없으면 총 9칸이다.
- 폭탄이 없는 안전한 바닥에만 설치한다. 한도가 찼거나 잔불이 있는 칸에서는 설치하지 않는다.
- 설치 순간 같은 칸에 있던 캐릭터는 나갈 수 있지만, 나간 뒤에는 그 폭탄 칸에 재진입할 수 없다.
- 폭탄의 화력은 설치 시점에 고정한다. 이후 아이템으로 늘어난 화력을 소급하지 않는다.
- 폭탄이 터지면 설치 한도를 즉시 돌려준다. 잔불 위에는 여전히 설치할 수 없다.
- 폭발이 다른 폭탄에 닿으면 해당 방향은 그 칸에서 멈추고, 맞은 폭탄은 자신의 화력으로 즉시 연쇄 폭발한다.
- 같은 갱신에 터지는 모든 폭탄은 파괴 전 지형으로 범위를 계산한다. 같은 순간 먼저 깨진 블록을 다른 폭발이 뚫고 지나가지 않는다.
- 겹친 잔불은 모두 끝나야 안전해진다. 자신의 폭탄과 상대의 폭탄은 같은 피해 규칙을 따른다.
- 같은 칸에 대한 동시 설치·획득은 갱신마다 바뀌는 정방향·역방향 처리 순서로 한 명에게만 허용한다. 실패한 설치는 한도를 쓰지 않는다.
- 남은 시간 원형 게이지와 마지막 0.5초의 색상 변화로 폭발 시점을 알린다.

## 6. 아이템

파괴 블록의 약 45%에 아이템이 들어 있다. 아이템이 있는 블록의 종류 비율은 폭탄 추가 25%, 범위 강화 25%, 이동 강화 15%, 1회용 실드 25%, 슈퍼 불꽃 10%다. 아이템 위치와 종류는 회전 대칭으로 생성한다.

| 아이템 | 효과 |
| --- | --- |
| 폭탄 추가 | 동시 설치 한도 +1, 최대 3개 |
| 범위 강화 | 각 방향 거리 +1칸, 최대 6칸 |
| 슈퍼 불꽃 | 각 방향 거리 +2칸, 최대 6칸 |
| 이동 강화 | 초당 이동 +1칸, 최대 6칸 |
| 1회용 실드 | 다음 폭발 피해 1회 자동 방어, 최대 1회 보관 |

블록 속 아이템은 해당 칸의 모든 잔불이 끝난 뒤 노출한다. 노출 후에는 다음 폭발에 사라질 수 있다. 노출 시간 제한은 없고 직접 밟아서 획득한다. 능력치가 최대여도 아이템은 소모하며 추가 효과는 없다. 피격을 획득보다 먼저 처리한다. 컴퓨터에도 같은 효과와 한도를 적용한다.

- 실드는 획득 시 파란 보호막과 숫자 1로 표시하고, 화면의 실드 보유 상태를 갱신한다.
- 피격하면 실드 1회를 소모하고 0.8초간 피해를 막는다. 같은 갱신의 이동 전·후 피격이나 겹치는 연쇄 폭발에 중복 소모되지 않는다. 자기 폭탄에도 적용된다.
- 보호 시간에도 이동할 수 있다. 시간이 끝난 후 위험한 칸에 머물거나 다시 폭발에 닿으면 일반 피해 규칙을 적용한다. 일시정지 중 보호 시간은 흐르지 않는다.
- 실드는 중첩되지 않는다. 보호 시간 중 다시 얻은 실드는 최대 1회로 보관하며 남은 보호 시간을 연장하지 않는다.
- 보호막이 없는 상태에서 치명적 피해와 실드 획득이 겹치면 피격이 먼저이므로 구제되지 않는다.
- 범위 강화는 새로 설치한 폭탄부터 적용하며, 이미 놓인 폭탄의 범위는 바뀌지 않는다. 슈퍼 불꽃도 고정 벽·블록을 관통하지 않는다.
- 아이템 획득 시 실제 강화된 범위·폭탄 수 또는 실드 안내를 표시한다. 상한에 도달한 경우에는 이미 최대라는 안내를 표시한다.

## 7. 컴퓨터 행동

브라우저 내부에서 실행하는 규칙 기반 AI다. 외부 AI 서비스나 서버는 사용하지 않는다.

1. 폭탄·잔불로 현재 위치가 위험하면 안전한 경로로 대피한다.
2. 상대를 맞히거나 블록을 부술 수 있고 탈출 경로가 있으면 폭탄을 놓는다.
3. 안전한 길로 아이템을 얻고, 블록을 부숴 통로를 넓힌다.
4. 자신 이외의 생존 캐릭터에게 접근한다. 컴퓨터도 다른 컴퓨터를 공격한다.

위험 예측은 시간순 폭발·연쇄·잔불을 계산하며, 먼저 깨진 블록 때문에 나중의 폭발이 멀리 퍼지는 경우도 반영한다. 위치뿐 아니라 도착 시각을 함께 탐색한다. 새 폭탄을 놓을 때는 판단 지연 이후에도 탈출 가능한지 확인한다. 대피 경로의 방향 전환은 캐릭터 이동 속도에 맞춰 실행한다.

숨은 아이템이나 미래 입력을 읽지 않으며 이동·설치·피격은 플레이어와 같은 엔진을 사용한다. 최근 방문한 칸에는 불이익을 주어 제자리 왕복을 줄인다. 상대의 새 폭탄으로 경로가 막히면 컴퓨터도 탈락할 수 있다.

컴퓨터도 실드와 슈퍼 불꽃을 유용한 아이템으로 평가해 획득한다. 실드가 있어도 위험을 무시하거나 탈출 불가능한 곳에 폭탄을 놓지 않는다. 강화된 실제 폭발 거리를 사용해 위험을 예측한다.

| 난이도 | 전략 판단 간격 | 차이 |
| --- | ---: | --- |
| 쉬움 | 0.40초 | 블록 개척 우선, 공격 기회를 일부 넘김 |
| 보통 | 0.25초 | 현재 상대 위치를 겨냥하고 아이템과 개척을 병행 |
| 어려움 | 0.12초 | 더 잦은 판단, 상대의 현재 이동 방향 앞 칸도 공격 대상으로 고려 |

## 8. 승패와 저장

- 플레이어 생존 + 남은 컴퓨터 0명: 스테이지 클리어, 5단계는 최종 우승.
- 플레이어 탈락 + 생존 컴퓨터 있음: 즉시 패배. 컴퓨터끼리의 남은 경기는 계속하지 않는다.
- 같은 갱신에서 마지막 컴퓨터들과 플레이어가 모두 탈락: 무승부.
- 180초까지 플레이어와 컴퓨터가 함께 생존: 무승부. 마감 시각과 겹친 폭발 피해를 먼저 판정한다.
- 결과를 확정하면 폭탄·시간·입력을 멈추고 전적을 한 번만 저장한다.
- 결과에는 플레이 시간, 플레이어의 블록 파괴 수와 아이템 획득 수를 표시한다. 참고 기록은 승패를 바꾸지 않는다.
- 같은 블록을 여러 소유자의 폭탄이 동시에 맞히면 각 소유자에게 파괴 수 1개를 기록한다. 연쇄 폭탄도 원래 소유자 기준이다.
- 최고 해금 단계, 난이도별 전적, 마지막 난이도, 음소거·움직임 설정을 `sion-world-block-bomber-v1` 키로 로컬 저장한다.
- 진행 중 경기 저장은 없다. 저장소가 차단되거나 손상되어도 기본값으로 정상 플레이한다. 중도 이탈은 전적에 포함하지 않는다.

## 9. 화면과 음향

상단에 게임 제목과 스테이지별 컴퓨터 수, 경기장에 타이머·생존 컴퓨터·민트색 플레이어를 표시한다. 오른쪽에는 목표, 컴퓨터별 생존 상태, 폭탄·범위·속도·실드와 조작법을 배치한다. 펼쳐 보는 아이템 5종 안내에 효과와 한도를 표시한다. 모바일은 전체 게임판 아래 터치 조작과 상태 카드를 둔다.

시작·일시정지·패배·무승부·스테이지 클리어·최종 우승 화면을 제공한다. 고정 벽, 나무 블록, 폭탄, 아이템은 모양을 구분한다. 플레이어에는 `나`, 컴퓨터에는 번호를 표시한다. 효과음은 시작 입력 후 활성화하고 음소거를 지원한다. 움직임 줄이기에서는 이동 보간·폭탄 맥동·장식 입자를 줄이되 위험 게이지를 유지한다.

## 10. 구현과 판정 순서

| 파일 | 역할 |
| --- | --- |
| `index.html`, `styles.css` | 한국어 화면, 시작·결과, 반응형 배치, 터치 입력 |
| `engine.js` | 맵·이동·폭탄·아이템·피격·스테이지 결과 |
| `ai.js` | 미래 위험 예측, 시간별 경로 탐색, CPU 판단 |
| `game.js` | 렌더링, 입력, 오디오, UI 상태 전환, 해금·저장 |
| `assets/icon.svg`, `preview.svg` | 게임 아이콘과 메인 목록 썸네일 |
| `tests/` | 엔진·AI·스테이지 UI 흐름·연결 검증 |
| `serve.cjs` | 선택적 로컬 서버, `/sion-world/` 경로 검증 지원 |

60Hz 고정 규칙 갱신과 화면 렌더링을 분리한다. 각 갱신에서 시간·잔불을 처리하고, 폭발과 연쇄를 일괄 계산한 뒤 현재 위치 피격 → 생존자 이동 → 이동 후 피격 → 아이템 노출·획득 → 폭탄 설치 → 결과 순서로 처리한다. 정확히 폭발 시각까지 위험 칸에 있었다면 그 갱신의 이동으로 피할 수 없다.

## 11. 검증과 확장

규칙·스테이지 연결 자동 테스트 40개를 통과했다. 100개 시드 맵의 대칭·탈출·연결과 모든 난이도·스테이지의 AI 경기를 검사한다. 실제 UI 핸들러로 1→5단계 증가, 해금, 최종 승리, 중복 기록 방지와 재도전을 별도로 검증한다. 아이템 5종 생성, 최대 범위, 실드 소모·중첩 방지·보호 만료·일시정지, CPU 획득과 HUD·알림도 검증한다.

브라우저에서는 PC 키보드, 모바일 크기에서의 방향·폭탄 버튼, 카운트다운·일시정지·재개·패배·재시작과 오류 로그를 확인한다. 실제 스마트폰의 두 손가락 조작감과 음량은 추가 기기 확인 항목이다. 상세 기록은 [TESTING.md](TESTING.md)에 둔다.

후속 후보는 맵 테마, 캐릭터 외형, 연습 모드, 특수 폭탄, 같은 기기 2인 대전이다. 온라인 대전과 외부 서버는 현재 범위에 포함하지 않는다.
