## 게임 목표

플레이어와 아군 컴퓨터가 협력해 적 팀을 이긴다. 플레이어 개인의 생존이 아니라 **우리 팀의 생존**으로 승패를 정한다. 한 판의 시간 제한은 없으며 타이머는 플레이 시간을 표시한다. 기존 난이도 선택, 아이템, 효과음, 시작 보상은 유지한다.

## 팀·피해·AI

- 플레이어와 아군은 팀 0, 적은 팀 1이다. 번호와 색 외에 ‘나’, ‘아군’, ‘적’ 표기를 제공한다.
- 같은 팀의 다른 캐릭터가 설치한 폭탄에는 피해를 받지 않고 실드도 소모하지 않는다. 자신의 폭탄과 적의 폭탄은 위험하다. 폭탄은 팀과 관계없이 이동을 막고 서로 연쇄 폭발한다.
- 연쇄 폭탄은 원래 설치자의 팀과 소유권을 유지한다. 처치 수는 실제로 탈락시킨 상대에게 한 번만 기록하며 자기 피해를 처치로 세지 않는다.
- 양 팀의 AI는 반대 팀만 공격 대상으로 삼는다. 공격형은 접근, 수집형은 유효 아이템·개척, 함정형은 적 근처의 좁은 길목을 선호한다.
- 아군은 안전할 때 활동 80%, 아이템 관심 80%, 공격 계수 70%, 설치 대기 1.5초, 추가 판단 지연 0.15초로 고정한다. 초반부터 도움이 되면서 후반 적의 성장도 체감하도록 한다.
- 적 AI의 아래 값은 12단계에 걸쳐 선형으로 변한다. 쉬움/보통/어려움의 기본 판단 간격 0.4/0.25/0.12초에 추가 지연을 더한다. 쉬움의 직접 공격 계수는 추가로 0.55배이며, 어려움의 한 칸 앞 공격 예측은 9단계부터 적용한다.

## 맵과 조작

- 테두리와 내부 짝수 x·y 교차 칸은 고정 벽이다. 나머지 배치 가능한 칸의 약 55%에 파괴 블록을 생성한다. 블록과 숨은 아이템은 180도 회전 대칭이다.
- 우리 팀은 왼쪽, 적 팀은 오른쪽과 중앙에 분산해 시작한다. 모든 시작점 주변 3×3과 그 대칭 영역을 비우고 첫 폭탄을 피할 통로를 확보한다.
- 방향키/WASD 또는 모바일 방향 패드로 이동하고 Space/폭탄 버튼으로 설치한다. 같은 캐릭터끼리 이동을 막지 않는다. 설치한 폭탄 칸에서 나갈 수 있지만 재진입은 안 된다.
- 전체 맵 보기와 확대·따라가기를 전환한다. 확대 시 칸 크기는 최소 28px, 스크롤 창은 화면 높이에 맞춘다. 플레이어가 탈락하면 살아 있는 아군을 따라간다. 모바일의 너비 19칸 이상 맵은 확대를 기본 적용한다.
- Esc/화면 버튼으로 일시정지한다. 탭 이탈에도 입력·시간·음향을 멈춘다.

## 폭탄·아이템

폭탄은 2초 뒤 십자로 폭발하고 불꽃은 0.4초 지속된다. 벽은 폭발을 차단하고 블록은 맞은 칸까지만 파괴한다. 연쇄는 즉시 발생하며 같은 시각 폭발은 파괴 전 지형을 공유한다. 폭탄의 거리는 설치 당시 값으로 고정한다.

블록 45%에 숨은 아이템이 있다. 폭탄 추가 25%, 범위 강화 25%, 이동 강화 15%, 실드 25%, 슈퍼 불꽃 10%다. 불꽃이 모두 끝난 뒤 노출하며 노출된 아이템은 후속 폭발에 사라진다.

| 종류 | 효과 |
| --- | --- |
| 폭탄 추가 | 동시 설치 +1, 최대 3개 |
| 범위 강화 | 거리 +1칸, 최대 6칸 |
| 슈퍼 불꽃 | 거리 +2칸, 최대 6칸 |
| 이동 강화 | 초당 +1칸, 최대 6칸 |
| 실드 | 폭발 피해 1회 방어 후 0.8초 보호, 최대 1회 보관 |

## 경기 종료와 관전

1. 플레이어만 탈락하면 게임을 멈추지 않고 ‘관전 중’을 표시한다. 아군은 계속 이동·공격한다. 우리 팀 생존자 수를 표시한다.
2. 한쪽 팀이 전멸하면 마무리 대기 상태로 들어간다. 새 폭탄 설치를 금지하고, 이미 설치된 모든 폭탄·연쇄 폭발·불꽃은 그대로 처리한다. 생존자는 계속 이동하고 AI는 대피한다.
3. 폭탄과 불꽃이 모두 없어지면 우리 팀만 생존 시 승리, 적 팀만 생존 시 패배, 양쪽 모두 전멸 시 무승부로 확정한다. 죽은 적이 남긴 폭탄 때문에 잠정 승리가 무승부로 바뀔 수 있다.
4. 아군만 남아도 승리로 저장하고 다음 단계를 해금한다. 12단계 승리는 캠페인 완료다. 결과는 한 번만 저장한다.
5. 우리 팀이 패배한 직전 플레이어가 탈락했다면 사망 위치·위험 경로를 1.6초 보여 준 뒤 결과창을 연다. 이미 관전 중이었다면 바로 팀 결과를 표시한다.

## 외곽 축소

큰 맵에는 탐색 시간을 더 준다. 단계 표의 시작 시각 8초 전에 노란 느낌표와 초당 경고음으로 알린다. 시작 후 12초마다 외곽 한 줄이 붉은 위험 지대로 변한다. 양 팀 모두 즉시 탈락하며 실드로 막지 못한다. 새 벽으로 길을 끊지 않고 중앙 대결 공간을 남긴다. 시간 초과 종료는 없다.

## 보상·저장·효과음

1~11단계 클리어 시 다음 단계의 시작 보상으로 실드 1회 또는 폭탄 한도 +1을 선택한다. 해당 단계 재도전에도 유지하지만 다음 보상과 누적하지 않고 시작 화면 복귀 시 제거한다. 기본 능력과 나머지 아이템은 새 경기마다 초기화한다.

최고 해금 단계, 난이도별 승패, 난이도·단계별 최단 클리어 시간, 음소거·움직임 설정을 기존 sion-world-block-bomber-v1 키에 저장한다. 기존 1~5단계 해금과 기록을 보존하며 12단계까지 확장한다. 경기 중간 저장은 없다. 저장소 오류는 플레이를 막지 않는다.

설치·폭발·블록 파괴·아이템 5종·실드·처치·연속 처치·카운트다운·승패 효과음은 audio.js의 Web Audio 합성음이다. 음소거는 재생·예약 소리를 즉시 끈다. 처치는 2초 이내 연속 시 연속 처치로 알린다. 화면 결과에 시간·직접 처치·블록·아이템 수를 표시한다.

## 구현과 검증

engine.js는 팀·스테이지·폭탄·판정, ai.js는 팀별 전략·대피, game.js는 화면·입력·저장·관전·확대를 담당한다. index.html/styles.css와 원본 SVG 자산으로 렌더링하며 빌드나 외부 서비스 없이 실행한다.

자동 검증은 tests/ 아래에 있으며 단계별 맵·초기 탈출·팀 피해·아군 단독 승리·마지막 폭탄에 의한 결과 변화·마무리 대기·12단계 UI 해금·기존 아이템·효과음을 포함한다. 상세 실행 결과와 브라우저 검증 한계는 TESTING.md를 참고한다.
