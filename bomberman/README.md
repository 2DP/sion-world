# 블록 봄버

폭탄으로 블록을 부수고 아군 컴퓨터와 함께 적 팀을 이기는 1인용 웹게임이다. 12단계에 걸쳐 적 1~6명, 아군 1~2명과 대결하며 맵은 13×11에서 29×23칸까지 커진다.

## 실행

저장소의 루트 `index.html`을 열고 **블록 봄버** 카드를 선택하거나, 이 폴더의 `index.html`을 직접 연다. 별도 설치·빌드·외부 API가 필요 없다. GitHub Pages 등의 정적 호스팅에서는 `/sion-world/bomberman/` 경로로 접근한다.

선택적으로 저장소 루트에서 로컬 서버를 실행한다.

```powershell
node bomberman/serve.cjs
```

게임 목록: `http://127.0.0.1:8134/sion-world/`

게임: `http://127.0.0.1:8134/sion-world/bomberman/`

서버는 이 컴퓨터의 루프백 주소에만 바인딩한다. 터미널에서 Ctrl+C로 종료한다.

## 조작

- 방향키 / WASD: 이동
- Space: 폭탄 한 개 설치
- Esc: 일시정지·재개
- 모바일: 방향 패드와 폭탄 버튼, 동시에 누르기 지원

폭탄은 2초 뒤 십자로 터진다. **자신의 폭탄도 위험하므로 놓기 전에 모퉁이로 피할 길을 확보한다.** 블록 속 아이템은 다섯 종류다.

| 아이템 | 효과 |
| --- | --- |
| 폭탄 추가 | 동시에 설치할 수 있는 폭탄 +1, 최대 3개 |
| 범위 강화 | 폭발 거리 +1칸, 최대 6칸 |
| 슈퍼 불꽃 | 폭발 거리 +2칸, 최대 6칸 |
| 이동 강화 | 이동 속도 초당 +1칸, 최대 6칸 |
| 1회용 실드 | 폭발 피해 1회 방어, 최대 1회 보관 |

실드가 깨지면 0.8초간 보호된다. 그 사이 안전한 곳으로 이동한다. 컴퓨터도 같은 아이템을 사용하며, 화면의 ‘아이템 5종 알아보기’에서 효과와 한도를 확인할 수 있다.

적 팀을 전멸시키고 우리 팀이 살아남으면 다음 단계를 해금한다. 플레이어가 탈락해도 아군이 살아 있으면 관전하며 계속 진행한다. 남은 폭탄·연쇄 폭발·잔불이 모두 끝나야 결과를 확정한다. 패배·무승부는 같은 단계에서 재도전하며, 12단계에서 승리하면 최종 우승이다. 클리어 후 다음 단계의 시작 보상(실드 1회 또는 폭탄 +1)을 선택하며, 그 단계의 재도전에도 유지된다. 해금 기록·전적·단계별 최단 기록은 브라우저에 저장하고 진행 중인 경기는 저장하지 않는다.

## 달라지는 대결

- 초반 CPU는 쉬는 시간이 길고 아이템을 자주 지나친다. 12단계까지 활동·수집·공격 빈도가 점차 올라간다.
- 공격형·수집형·함정형 CPU가 서로 다른 우선순위로 움직인다.
- 외곽 위험은 1~2단계의 2분부터 11~12단계의 3분 15초까지 맵에 따라 늦춰진다. 8초 전 표시를 보고 중앙으로 이동한다. **외곽 위험은 실드로 막지 못한다.**
- 직접 처치·연속 처치 알림, 실제 사망 원인과 경로 표시, 단계별 최고 기록을 제공한다.

효과음 버튼으로 설치·폭발·아이템·처치·승패 소리를 켜거나 끌 수 있다. 일시정지 시 소리도 멈춘다. 시간 제한은 없으며 타이머는 플레이 시간을 표시한다. 남은 폭발이 끝났을 때 양 팀 모두 생존자가 없으면 무승부다.

아군의 폭탄에는 피해를 받지 않지만 **내 폭탄에는 피해를 받는다**. 적도 같은 팀 규칙을 따른다. 확대·따라가기 버튼으로 큰 맵을 확대할 수 있고, 관전 중에는 살아 있는 아군을 따라간다. 모바일의 19칸 이상 맵은 확대 보기가 기본이다.

## 검증

저장소 루트에서 실행한다.

```powershell
node --test --test-isolation=none bomberman/tests/*.test.cjs
node --check bomberman/engine.js
node --check bomberman/ai.js
node --check bomberman/audio.js
node --check bomberman/game.js
node --check bomberman/serve.cjs
```

규칙과 파일 구성은 [GAME_DESIGN.md](GAME_DESIGN.md), 확인한 범위와 제한은 [TESTING.md](TESTING.md)를 참고한다.
