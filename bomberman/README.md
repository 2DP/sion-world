# 블록 봄버

폭탄으로 블록을 부수고 컴퓨터를 모두 쓰러뜨리는 1인용 웹게임이다. 1~5단계에서 컴퓨터가 1명씩 늘어나 최대 5명과 겨룬다. 컴퓨터끼리도 공격한다.

## 실행

저장소의 루트 `index.html`을 열고 **블록 봄버** 카드를 선택하거나, 이 폴더의 `index.html`을 직접 연다. 별도 설치·빌드·외부 API가 필요 없다. GitHub Pages 등의 정적 호스팅에서는 `/sion-world/bomberman/` 경로로 접근한다.

선택적으로 저장소 루트에서 로컬 서버를 실행한다.

```powershell
node bomberman/serve.cjs
```

게임 목록: `http://127.0.0.1:8134/sion-world/`  
게임: `http://127.0.0.1:8134/sion-world/bomberman/`

서버는 이 컴퓨터의 루프백 주소에만 바인딩한다. 터미널에서 Ctrl+C로 종료한다.

## 조작

- 방향키 / WASD: 이동
- Space: 폭탄 한 개 설치
- Esc: 일시정지·재개
- 모바일: 방향 패드와 폭탄 버튼, 동시에 누르기 지원

폭탄은 2초 뒤 십자로 터진다. **자신의 폭탄도 위험하므로 놓기 전에 모퉁이로 피할 길을 확보한다.** 블록 속 아이템은 다섯 종류다.

| 아이템 | 효과 |
| --- | --- |
| 폭탄 추가 | 동시에 설치할 수 있는 폭탄 +1, 최대 3개 |
| 범위 강화 | 폭발 거리 +1칸, 최대 6칸 |
| 슈퍼 불꽃 | 폭발 거리 +2칸, 최대 6칸 |
| 이동 강화 | 이동 속도 초당 +1칸, 최대 6칸 |
| 1회용 실드 | 폭발 피해 1회 방어, 최대 1회 보관 |

실드가 깨지면 0.8초간 보호된다. 그 사이 안전한 곳으로 이동한다. 컴퓨터도 같은 아이템을 사용하며, 화면의 ‘아이템 5종 알아보기’에서 효과와 한도를 확인할 수 있다.

모든 컴퓨터를 쓰러뜨리면 다음 단계를 해금한다. 패배·무승부는 같은 단계에서 재도전하며, 5단계에서 승리하면 최종 우승이다. 해금 기록과 전적은 브라우저에 저장하고 진행 중인 경기는 저장하지 않는다.

## 검증

저장소 루트에서 실행한다.

```powershell
node --test bomberman/tests/*.test.cjs
node --check bomberman/engine.js
node --check bomberman/ai.js
node --check bomberman/game.js
node --check bomberman/serve.cjs
```

규칙과 파일 구성은 [GAME_DESIGN.md](GAME_DESIGN.md), 확인한 범위와 제한은 [TESTING.md](TESTING.md)를 참고한다.
