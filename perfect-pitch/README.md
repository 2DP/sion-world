# 음표 비행 (Pitch Flight)

SION WORLD의 마이크 기반 절대음감 게임. 설치나 빌드 없이 동작하는 HTML/CSS/Canvas/Web Audio 앱입니다.

저장소 루트에서 `node bomberman/serve.cjs`를 실행하고 `http://127.0.0.1:8134/sion-world/perfect-pitch/`로 접속하세요. 마이크는 HTTPS 또는 localhost 보안 컨텍스트와 사용자의 권한 허용이 필요합니다. 파일을 직접 열거나 일반 HTTP LAN 주소를 사용하는 방식은 권장하지 않습니다.

## 게임 방법

- 한 문마다 여러 음으로 구성된 멜로디가 나옵니다. 네 박자 준비 후, 음표 너비와 박자선을 따라 차례대로 부릅니다. 각 음을 정해진 구간 안에서 유지하고, 쉼표에서는 목소리를 멈춥니다. 한 음을 계속 내는 것만으로는 통과할 수 없습니다.
- 1스테이지(1~4문)는 84 BPM, 3~4음/4박. 2스테이지(5~8문)는 96 BPM, 6~7음/8박으로 반 박자와 긴 음, 쉼표가 섞입니다. 3스테이지(9~12문)는 108 BPM, 8~9음/8박으로 반 박자·1½박·쉼표를 다양하게 조합합니다.
- 총 12개 문, 하트 3개. 멜로디의 모든 음과 쉼표가 성공해야 문을 통과하고, 실패 시 하트 하나를 잃습니다. 쉬움은 도·레·미·솔 / ±50센트, 보통은 7개 자연음 / ±35센트, 어려움은 반음 포함 12개 음 / ±22센트입니다. 음별 유효 구간 중 각각 55%/65%/72% 이상을 맞춰야 하며, 음 전환을 위해 시작 65ms·끝 40ms는 판정에서 제외합니다.
- 배경에는 킥·스네어·하이햇 비트가 흐릅니다. 박자 표시·음표 판정·오디오는 동일한 Web Audio 시계를 사용합니다. 비트 끄기 및 음량 조절은 진행 시간에 영향을 주지 않습니다. 비트를 꺼도 연습용 멜로디 듣기는 들을 수 있습니다.
- 연습 모드의 ‘이번 멜로디 들어보기’는 네 박자와 전체 음 순서·길이를 재생합니다. 재생 중 음정 판정을 멈추고 잔향 대기 450ms 후 현재 문을 준비 박자부터 다시 시작합니다. 대기 화면에서 미리 들은 멜로디도 시작할 때 그대로 유지됩니다. 헤드폰과 조용한 환경이 가장 정확합니다.
- 도전 모드는 소리 힌트가 없습니다. 기본값인 ‘옥타브 자유’는 같은 음 이름이면 낮거나 높게 불러도 인정합니다. 끄면 C4~B4의 지정 높이까지 맞춰야 합니다.
- ‘먼저 둘러보기’는 마이크를 사용하지 않는 자동 시연이며 점수는 저장하지 않습니다. 실제 게임에서 키보드로 음정을 대신 입력할 수 없습니다.
- 일시정지 버튼 또는 Esc, 창 이탈, 페이지 숨김, 마이크 연결 중단 시 마이크와 예약된 비트를 모두 종료합니다. 이어하기 때 마이크를 재연결하고 현재 멜로디만 네 박자부터 다시 시작합니다. 이전에 완료한 문과 점수는 유지합니다. 렌더링 지연이 250ms를 넘으면 박자가 어긋나지 않도록 자동 정지합니다.

음성은 브라우저 메모리에서만 분석하며 녹음·업로드하지 않습니다. YIN 검출 범위는 65~1200Hz, 4096 샘플, 약 30회/초이며 조용한 입력과 비주기적 잡음을 거릅니다. 비트는 음정이 없는 잡음 기반 타악기로 합성하며 마이크 에코 제거를 요청합니다. 기기·마이크·주변 소음에 따라 정확도가 다르므로 헤드폰 사용, 비트 음량 및 마이크 감도 조절을 권장합니다. 설정별 최고 점수는 변경된 규칙에 맞춰 `sion-world-pitch-flight-rhythm-v2` localStorage에 따로 저장합니다. 이전 한 음 버전 기록은 덮어쓰지 않으며 저장소가 차단돼도 게임이 동작합니다. 웹 폰트 실패 시 시스템 글꼴로 표시합니다.

## 파일 및 검증

- `engine.js`: 음정 분석, 음 이름/센트 환산, 통과·점수·진행 규칙.
- `rhythm.js`: 단계별 비트/멜로디 스케줄, 오디오 시계, 타악기 합성, 음량 및 예약 소리 해제.
- `game.js`: 마이크 생명주기, Canvas, UI, 시연, 오디오 힌트, 최고 점수.
- `assets/`: 직접 작성한 SVG 아이콘과 홈 미리보기.
- 테스트: `node --test --test-isolation=none perfect-pitch/tests/*.test.cjs`
- Sites용 산출물은 `node perfect-pitch/package-site.cjs <출력 디렉터리>`로 생성합니다. 게임 소스와 `.openai/hosting.json`을 별도 배포 체크아웃으로 복사하며 원본 저장소 Git 상태를 바꾸지 않습니다.
