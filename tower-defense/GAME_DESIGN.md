# 별빛 타워 디펜스 — 승인된 계획과 구현

파스텔 정원에서 길을 따라오는 몬스터로부터 별빛 성을 지키는 싱글 플레이 웹게임. 기존 SION WORLD의 독립 정적 게임 구조에 통합합니다.

## 콘텐츠

- 풀빛 정원 / 라벤더 언덕 / 달빛 호수, 지도별 15웨이브.
- 쉬움: 생명력 30, 적 체력 78%. 보통: 생명력 20.
- 시작 골드 260. 화살 65, 대포 115, 얼음 90, 마법 135 골드.
- 타워 3단계 강화. 투자금 70% 판매 환급.
- 기본 / 고속 / 방어 / 무리 / 보스 5종. 5·10·15웨이브 보스 등장.
- 웨이브 사이 정비, 전투 중 건설·강화·판매 허용.
- 1배속 / 2배속, 일시정지, 탭 이탈 자동 정지.
- 지도 및 난이도별 최고 점수와 클리어 저장. 세션 중간 저장 없음.

## 구현

Canvas 960×576 논리 좌표, 48px 건설 격자. 반응형 크기에서 포인터 좌표를 논리 좌표로 변환합니다. 게임 엔진은 1/60초 고정 간격으로 실행합니다. SVG 아이콘과 미리보기, Canvas 타워·몬스터 및 Web Audio 효과음을 자체 제작했습니다.

## 밸런스 목표

한 판 10~15분. 경로 노출 시간을 기준으로 위치를 선택하고 골드 범위에서 강화하는 자동 전략은 6개 지도/난이도 조합 모두 15웨이브 승리했습니다. 실제 시뮬레이션 전투 시간 523~652초이며, 사용자의 정비 시간과 배속 선택에 따라 플레이 시간은 달라집니다. 사람의 반복 플레이에 따른 난이도 조정은 추가로 가능합니다.
